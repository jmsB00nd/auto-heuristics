Here is the implementation of the **Boltzmann Free Energy Routing (BFER)** heuristic:

```python
def qlosure_poly_heuristic(self, swap_gate):
    import math

    front_layer_size = max(len(self.front_layer), 1)
    extended_layer_size = max(len(self.extended_layer), 1)

    # ── Temperature Annealing ────────────────────────────────────────────
    # T decays as the circuit progresses (depth increases):
    # early → high T (entropy-dominated, exploratory)
    # late  → low  T (energy-dominated, exploitative)
    T_MAX = 3.0
    current_depth = self.get_circuit_depth()
    T = T_MAX / (1.0 + 0.1 * current_depth)

    # ── Energy E(φ): Weighted gate distances ─────────────────────────────
    # Front-layer contribution (highest urgency)
    E_front = 0.0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        if Q1 == -1 or Q2 == -1:
            continue
        deps = self.dag_dependencies_count[g]
        E_front += (deps + 1) * self.distance_matrix[Q1][Q2]

    # Extended-layer contribution (lookahead, discounted by depth)
    E_ext = 0.0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        if Q1 == -1 or Q2 == -1:
            continue
        layer_factor = self.extended_layer_index.get(g, 0) + 1
        deps = self.dag_dependencies_count[g]
        E_ext += (deps + 1) * self.distance_matrix[Q1][Q2] / layer_factor

    # Normalised total energy
    E = E_front / front_layer_size + 0.5 * E_ext / extended_layer_size

    # ── Entropy S(φ): Shannon entropy of gate-activity across qubits ─────
    # Activity weight of each physical qubit under the candidate mapping.
    # High S → load spread across chip → favourable (reduces free energy).
    qubit_activity = [0.0] * self.num_qubits

    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        if Q1 == -1 or Q2 == -1:
            continue
        w = float(self.dag_dependencies_count[g] + 1)
        qubit_activity[Q1] += w
        qubit_activity[Q2] += w

    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        if Q1 == -1 or Q2 == -1:
            continue
        layer_factor = self.extended_layer_index.get(g, 0) + 1
        w = (self.dag_dependencies_count[g] + 1) / layer_factor
        qubit_activity[Q1] += w
        qubit_activity[Q2] += w

    total_activity = sum(qubit_activity)
    S = 0.0
    if total_activity > 0.0:
        for act in qubit_activity:
            if act > 0.0:
                p = act / total_activity
                S -= p * math.log(p)   # Shannon entropy (nats)

    # ── Helmholtz Free Energy F = E − T·S ───────────────────────────────
    # max_decay penalises swaps on already-hot qubits (keeps E scale)
    max_decay = max(
        self.decay_parameter[swap_gate[0]],
        self.decay_parameter[swap_gate[1]]
    )

    F = max_decay * E - T * S

    return F
```

---

**Design rationale:**

| Component | Role |
|---|---|
| `E` | Normalised weighted-distance energy (front + lookahead). Criticality weight `(deps+1)` prioritises bottleneck gates. |
| `S` | Shannon entropy (nats) of the gate-activity distribution over physical qubits under `temp_mapping_dict`. High S → balanced load → lower free energy. |
| `T = T_MAX / (1 + 0.1 · depth)` | Inverse-linear decay. At depth 0: T = 3.0 (entropy dominates, exploration). As depth → ∞: T → 0 (energy dominates, exploitation). |
| `F = max_decay · E − T · S` | Helmholtz free energy. Swaps that concentrate activity on a few qubits pay an entropic penalty; the `max_decay` factor additionally penalises qubits already stressed by prior operations. |
