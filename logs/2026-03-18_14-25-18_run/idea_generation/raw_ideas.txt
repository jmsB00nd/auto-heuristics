IDEA_NAME: Fiedler-Vector Spectral Rank Alignment (FVSRA)
DESCRIPTION: Computes the Fiedler vector (2nd smallest eigenvector of the normalized Laplacian) for both the weighted logical interaction graph and the hardware graph. Logical qubits are sorted by their Fiedler component, physical qubits are independently sorted by their Fiedler component, and a rank-preserving bijection is constructed. The Fiedler vector encodes the graph's optimal bisection axis, so aligning both orderings maps interaction-clustered logical qubits to topologically-clustered physical qubits.
ALGORITHMIC_APPROACH:
1. Build weighted interaction frequency matrix `W_L[q1][q2]` from `self.access` (count of 2-qubit gates per pair).
2. Compute the normalized Laplacian `L_L = D_L^{-1/2}(D_L - W_L)D_L^{-1/2}`.
3. Extract the Fiedler vector `f_L` via numpy's `eigh` (eigenvalue index 1).
4. For the hardware graph, build adjacency matrix, compute its normalized Laplacian `L_H`, extract Fiedler vector `f_H`.
5. Sort logical qubit indices by `f_L` ascending → sorted list `ord_L`.
6. Sort physical qubit indices by `f_H` ascending → sorted list `ord_P`.
7. Assign `mapping_dict[ord_L[i]] = ord_P[i]` for all i.
COLLISION_PREVENTION: Both `ord_L` and `ord_P` are permutations of their respective index sets. The rank-matched bijection `ord_L[i] → ord_P[i]` is strictly 1-to-1 by construction: each logical index appears exactly once in `ord_L`, each physical index exactly once in `ord_P`.
WHY_NOVEL: Standard SOTA uses SABRE (routing-based), subgraph isomorphism, or noise-aware greedy. Applying Fiedler vector rank-alignment to match the natural bisection structure of both graphs simultaneously has not appeared in the quantum compilation literature. It differs from mere degree-sorting by using the full spectral geometry of both graphs.

IDEA_NAME: Interaction-Frequency Weighted BFS Anchor Placement (IFWBAP)
DESCRIPTION: Identifies the single most-interacting logical qubit (highest weighted degree in the interaction graph) and anchors it to the most globally-central physical qubit (lowest mean BFS distance to all others). Then expands outward via a dual BFS: each subsequent unplaced logical qubit — selected by maximum interaction weight to already-placed qubits — is placed on the unoccupied physical neighbor of the current placement that minimizes total weighted distance to its already-placed interaction partners. Remaining unplaced qubits fill remaining physical qubits by hardware degree order.
ALGORITHMIC_APPROACH:
1. Build `interaction_freq[(q1,q2)]` from `self.access`.
2. Compute weighted degree `WD[q] = sum_j interaction_freq[(q,j)]` for each logical qubit `q`.
3. Compute `mean_dist[p] = mean(distance_matrix[p])` for each physical qubit.
4. Anchor: `anchor_logical = argmax(WD)`, `anchor_physical = argmin(mean_dist)`.
5. `mapping_dict[anchor_logical] = anchor_physical`.
6. Priority queue of unplaced logical qubits ordered by `sum_{placed j} interaction_freq[(q,j)]` (descending).
7. For each popped logical qubit `q`: find `p* = argmin_{unoccupied p in backend neighbors of placed} sum_{placed j} freq[(q,j)] * distance_matrix[p][mapping[j]]`; assign `q → p*`.
8. Fill remaining unplaced logical with remaining physical sorted by hardware degree descending.
COLLISION_PREVENTION: Maintains a `placed_physical` set; each assigned physical qubit is immediately added and never reassigned. `mapping_dict` and `reverse_mapping_dict` are updated atomically. Final fill uses the complement set — guaranteed disjoint.
WHY_NOVEL: Combines interaction-frequency-weighted BFS expansion with hardware-centrality-driven anchoring into a single greedy pass. Unlike SABRE layout (which runs full routing simulations) or degree-sorted matching (which ignores topology structure), this propagates placement decisions through the interaction graph structure while respecting the hardware's local connectivity at each step.
