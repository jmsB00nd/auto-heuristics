## Analysis of IFWBAP

**Strengths:**
- Interaction-frequency weighted anchor selection is sound
- BFS expansion respects hardware topology (neighbors first)
- Weighted distance minimization for placement cost

**Weaknesses:**
1. **No temporal awareness**: All gates weighted equally regardless of when they execute. Early gates dominate swap costs, yet they receive no priority
2. **Zero lookahead**: Greedy expansion ignores how placing `next_lq` at a candidate constrains future neighbors' best achievable positions
3. **Anchor conflation**: Highest weighted-degree and most central physical are chosen independently — qubit *early activity* is ignored entirely
4. **No second-order tie-breaking** in next-qubit selection

## Strategy: Option A — Targeted Refinement

Three concrete improvements:
1. **Temporal decay weighting** — `weight(gate) ∝ exp(-α · gate_position/total_gates)`, making early gates dominant
2. **Two-hop lookahead** — for each candidate physical qubit, estimate the best achievable placement cost for the top-K future interaction neighbors of `next_lq`
3. **Composite anchor + tie-break** — combine early-activity score into anchor/next-qubit selection

```python
def init_mapping(self):
    from collections import defaultdict
    import math

    # --- Step 1: Temporally-weighted interaction graph ---
    # Earlier gates contribute exponentially more; they dominate immediate swap cost.
    gate_items = list(self.access.items())
    total_gates = max(len(gate_items), 1)
    try:
        gate_items_sorted = sorted(gate_items, key=lambda x: x[0])
    except TypeError:
        gate_items_sorted = gate_items

    DECAY = 2.0  # exp(-DECAY*t): first gate weight=1.0, last gate weight≈0.14
    interaction_weight = defaultdict(float)
    qubit_early_score = defaultdict(float)
    logical_qubit_set = set()

    for idx, (gate, qubits) in enumerate(gate_items_sorted):
        for q in qubits:
            logical_qubit_set.add(q)
        t = idx / total_gates
        tw = math.exp(-DECAY * t)
        for q in qubits:
            qubit_early_score[q] += tw
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            key = (min(q1, q2), max(q1, q2))
            interaction_weight[key] += tw

    weighted_degree = defaultdict(float)
    interaction_neighbors = defaultdict(dict)
    for (q1, q2), w in interaction_weight.items():
        weighted_degree[q1] += w
        weighted_degree[q2] += w
        interaction_neighbors[q1][q2] = interaction_neighbors[q1].get(q2, 0) + w
        interaction_neighbors[q2][q1] = interaction_neighbors[q2].get(q1, 0) + w

    logical_qubits = sorted(logical_qubit_set)
    physical_qubits = sorted(self.backend.keys())

    if not logical_qubits:
        self.mapping_dict = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # --- Step 2: Precompute physical centrality (mean BFS distance) ---
    phys_centrality = {}
    for p in physical_qubits:
        finite_dists = [
            self.distance_matrix[p][o]
            for o in physical_qubits
            if o != p and self.distance_matrix[p][o] != float('inf')
        ]
        phys_centrality[p] = (sum(finite_dists) / len(finite_dists)
                               if finite_dists else float('inf'))

    # --- Step 3: Anchor — combine weighted degree AND early activity ---
    anchor_logical = max(
        logical_qubits,
        key=lambda q: weighted_degree[q] + 0.3 * qubit_early_score[q]
    )
    anchor_physical = min(physical_qubits, key=lambda p: phys_centrality[p])

    lq_to_phys = {anchor_logical: anchor_physical}
    placed_phys = {anchor_physical}
    unplaced_set = {lq for lq in logical_qubits if lq != anchor_logical}
    unplaced = list(unplaced_set)

    # --- Step 4: BFS expansion with two-hop lookahead ---
    BETA = 0.2  # Lookahead weight relative to direct cost

    while unplaced:
        # Select next logical: max interaction with placed; tie-break by weighted degree
        def lq_priority(lq):
            conn = sum(interaction_neighbors[lq].get(plq, 0) for plq in lq_to_phys)
            return (conn, weighted_degree[lq])

        next_lq = max(unplaced, key=lq_priority)

        # Candidate physical: hardware neighbors of placed first, then all remaining
        candidates = list({
            nb for phys in placed_phys
            for nb in self.backend[phys]
            if nb not in placed_phys
        })
        if not candidates:
            candidates = [p for p in physical_qubits if p not in placed_phys]
        if not candidates:
            break

        # Top-4 future neighbors of next_lq (unplaced qubits it will interact with)
        top_future = sorted(
            [(lq, w) for lq, w in interaction_neighbors[next_lq].items()
             if lq in unplaced_set],
            key=lambda x: -x[1]
        )[:4]

        available_phys = [p for p in physical_qubits if p not in placed_phys]

        def score(phys_c):
            # Direct cost: weighted distance to already-placed interaction partners
            direct = 0.0
            for plq, ppq in lq_to_phys.items():
                w = interaction_neighbors[next_lq].get(plq, 0)
                if w > 0:
                    d = self.distance_matrix[phys_c][ppq]
                    direct += w * (d if d != float('inf') else 1e9)

            # Two-hop lookahead: for each top future neighbor, find the best physical
            # position it could take given next_lq lands at phys_c, and accumulate cost.
            lookahead = 0.0
            remaining = [p for p in available_phys if p != phys_c]
            for future_lq, w_fn in top_future:
                best_cost = float('inf')
                for p_f in remaining:
                    d_to_next = self.distance_matrix[p_f][phys_c]
                    cost_f = w_fn * (d_to_next if d_to_next != float('inf') else 1e9)
                    # future_lq's cost to already-placed qubits from position p_f
                    for plq, ppq in lq_to_phys.items():
                        w2 = interaction_neighbors[future_lq].get(plq, 0)
                        if w2 > 0:
                            d2 = self.distance_matrix[p_f][ppq]
                            cost_f += w2 * (d2 if d2 != float('inf') else 1e9)
                    if cost_f < best_cost:
                        best_cost = cost_f
                lookahead += 0.0 if best_cost == float('inf') else best_cost

            return direct + BETA * lookahead

        best_phys = min(candidates, key=score)
        lq_to_phys[next_lq] = best_phys
        placed_phys.add(best_phys)
        unplaced.remove(next_lq)
        unplaced_set.discard(next_lq)

    # --- Step 5: Fill remaining isolated logical qubits by hardware degree ---
    remaining_phys = sorted(
        [p for p in physical_qubits if p not in placed_phys],
        key=lambda p: len(self.backend[p]),
        reverse=True
    )
    for lq, phys in zip(unplaced, remaining_phys):
        lq_to_phys[lq] = phys

    # --- Step 6: Build strict 1-to-1 bijection via in-place swaps ---
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys:
            continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq

    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

**What changed and why:**

| Change | Rationale |
|---|---|
| `exp(-2.0·t)` temporal decay | Early gates determine first routing decisions; weighting them 7× over last gates directs placement where it matters most |
| `weighted_degree + 0.3·early_score` anchor | Qubit that is both highly connected AND active early is the strongest anchor candidate |
| `lq_priority` returns tuple `(conn, degree)` | Proper tie-breaking prevents arbitrary ordering from influencing greedy choices |
| Two-hop lookahead (top-4 future neighbors) | Evaluates how placing `next_lq` at each candidate constrains future neighbors' best achievable positions — avoids "cornering" high-interaction qubits |
| `BETA=0.2` lookahead weight | Conservative: lookahead is an approximation (it ignores inter-future-neighbor competition), so it should not dominate direct cost |
