```python
def init_mapping(self):
    """
    K-Core Decomposition Hierarchical Centrality Matching (KCDHCM)

    The k-core number of a node is the maximum k such that the node belongs to
    a subgraph where every node has degree >= k. It is a richer structural
    centrality measure than raw degree because it captures *density of the local
    cluster*, not just immediate neighbourhood size.

    Algorithm (all steps are polynomial):
      1. Build the logical interaction graph (LIG) from 2-qubit gates.
      2. Run the Batagelj-Zaversnik peeling algorithm (O(|V|+|E|)) to get
         k-core numbers for every node in the LIG and in the hardware graph.
      3. Sort logical qubits by (core_number DESC, degree DESC).
         Sort physical qubits by the same criteria on the hardware graph.
      4. Match rank-for-rank: the highest-core logical qubit lands on the
         highest-core physical qubit, and so on.
      5. Build a valid 1-to-1 bijection over all num_qubits indices via
         in-place swaps on an identity permutation.
    """
    from collections import defaultdict

    # --- Step 1: Build logical interaction graph ---
    logical_graph = defaultdict(set)
    logical_qubit_set = set()

    for gate, qubits in self.access.items():
        for q in qubits:
            logical_qubit_set.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            logical_graph[q1].add(q2)
            logical_graph[q2].add(q1)

    # Ensure isolated logical qubits (only single-qubit gates) are represented
    for q in logical_qubit_set:
        if q not in logical_graph:
            logical_graph[q] = set()

    # Fallback: trivial mapping for empty circuits
    if not logical_qubit_set:
        self.mapping_dict = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # --- Step 2: Batagelj-Zaversnik k-core decomposition (O(|V| + |E|)) ---
    def compute_kcore(graph, nodes):
        """
        Process nodes in non-decreasing degree order; set core[v] = current
        degree of v; reduce the current degree of each un-processed neighbour
        so that it cannot exceed core[v].
        Returns dict {node: core_number}.
        """
        degree = {v: len(graph[v]) for v in nodes}
        core = {}
        nodes_sorted = sorted(nodes, key=lambda v: degree[v])
        for v in nodes_sorted:
            core[v] = degree[v]
            for u in graph[v]:
                if u in degree and degree[u] > degree[v]:
                    degree[u] -= 1
        return core

    logical_nodes = list(logical_qubit_set)
    hw_nodes = list(self.backend.keys())

    logical_core = compute_kcore(logical_graph, logical_nodes)
    hw_core = compute_kcore(self.backend, hw_nodes)

    # --- Step 3: Rank by (k-core DESC, degree DESC) ---
    # Degree breaks ties: higher-degree nodes within the same core go first.
    logical_sorted = sorted(
        logical_nodes,
        key=lambda q: (logical_core.get(q, 0), len(logical_graph[q])),
        reverse=True
    )
    hw_sorted = sorted(
        hw_nodes,
        key=lambda q: (hw_core.get(q, 0), len(self.backend[q])),
        reverse=True
    )

    # --- Step 4: Build valid bijection via in-place swaps on the identity ---
    # Starting from the identity permutation guarantees every index is covered
    # and avoids gaps or collisions. Each target assignment displaces the
    # current occupant, keeping both dicts strictly consistent at all times.
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for rank, lq in enumerate(logical_sorted):
        if rank >= len(hw_sorted):
            break
        target_phys = hw_sorted[rank]
        current_phys = mapping_dict[lq]
        if current_phys == target_phys:
            continue
        # Displace the logical qubit currently occupying target_phys
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq

    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

**How it works and why it's sound:**

**K-core decomposition** (Batagelj-Zaversnik, 2003) assigns each node a *coreness* value — the largest `k` such that the node sits in a subgraph where every node has degree ≥ k. This differs from degree centrality in a critical way: a node can have high degree but a low core number if its neighbours are weakly connected to each other (a "hub-and-spoke" pattern). Conversely, a high core number signals a dense, mutually-connected cluster — exactly where quantum crosstalk and SWAP pressure concentrate.

**Matching strategy:** By sorting both the logical interaction graph and the hardware graph on `(core_number DESC, degree DESC)` and pairing them rank-for-rank, the densest interaction clusters in the circuit are placed into the densest regions of the hardware topology. This minimises the geodesic distances that will be traversed during routing for the highest-traffic qubit pairs.

**Complexity:** O(G + N log N), where G is the gate count and N is the qubit count — well within the polynomial constraint. The k-core computation itself is O(|V| + |E|).

**Validity guarantee:** The in-place swap technique on an identity permutation ensures the result is always a strict bijection over all `num_qubits` indices, with no unmapped or doubly-mapped qubits.
