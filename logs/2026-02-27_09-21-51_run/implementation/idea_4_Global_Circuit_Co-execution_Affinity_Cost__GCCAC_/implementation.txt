Here is the implementation of the **Global Circuit Co-execution Affinity Cost (GCCAC)**:

```python
def qlosure_poly_heuristic(self, swap_gate):
    # Lazily precompute global affinity A(q1, q2) = total 2-qubit gates
    # between logical qubit pair (q1, q2) across the ENTIRE circuit.
    # Cached after first call to avoid recomputation overhead.
    if not hasattr(self, '_global_affinity'):
        affinity = {}
        for qubits in self.access2q:
            if qubits is not None and len(qubits) == 2:
                q1, q2 = qubits[0], qubits[1]
                key = (min(q1, q2), max(q1, q2))
                affinity[key] = affinity.get(key, 0) + 1
        self._global_affinity = affinity

    affinity = self._global_affinity

    front_layer_size = max(len(self.front_layer), 1)
    extended_layer_size = len(self.extended_layer)

    # Front layer: weight physical distance by global affinity of the pair.
    # High-affinity pairs penalized more when physically far — drives proximity.
    f_cost = 0.0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        if Q1 == -1 or Q2 == -1:
            continue
        aff = affinity.get((min(q1, q2), max(q1, q2)), 1)
        f_cost += aff * self.distance_matrix[Q1][Q2]

    f_cost /= front_layer_size

    # Extended layer: same affinity-weighted distance, decayed by lookahead depth.
    e_cost = 0.0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        if Q1 == -1 or Q2 == -1:
            continue
        aff = affinity.get((min(q1, q2), max(q1, q2)), 1)
        depth_factor = self.extended_layer_index.get(g, 0) + 1
        e_cost += aff * self.distance_matrix[Q1][Q2] / depth_factor

    if extended_layer_size > 0:
        e_cost /= extended_layer_size

    # Apply qubit heat/noise penalty via decay parameter
    max_decay = max(
        self.decay_parameter[swap_gate[0]],
        self.decay_parameter[swap_gate[1]]
    )

    return max_decay * (f_cost + e_cost)
```

**Key design decisions:**

| Aspect | Baseline | GCCAC |
|---|---|---|
| Gate weight | `dag_dependencies_count[g]` (local DAG criticality) | `A(q1,q2)` — global interaction frequency across full circuit |
| Precomputation | None | One-time scan of `self.access2q`, cached via `hasattr` |
| Routing intuition | Prioritize structurally critical gates | Prioritize pairs that interact most globally — keep them physically close throughout the entire execution |

**How it works:**
1. **Global affinity** `A(q1,q2)` counts every 2-qubit gate involving the pair `(q1,q2)` across the whole circuit, not just the current window.
2. This affinity becomes the routing weight — pairs that interact hundreds of times globally get a much higher penalty when physically distant, pulling them toward adjacency early.
3. The lookahead depth decay (`1/depth_factor`) and `max_decay` are preserved to maintain noise-awareness and temporal prioritization.
