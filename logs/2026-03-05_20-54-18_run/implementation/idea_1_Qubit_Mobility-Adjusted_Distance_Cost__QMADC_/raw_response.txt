Now I have everything I need. The backend is a `defaultdict(set)` adjacency list, so `len(self.backend[Q])` gives the degree of physical qubit Q. Here's the QMADC implementation:

```python
def qlosure_poly_heuristic(self, swap_gate):
    W = 1
    front_layer_size = len(self.front_layer)
    extended_layer_size = len(self.extended_layer)

    max_decay = max(self.decay_parameter[swap_gate[0]], self.decay_parameter[swap_gate[1]])

    # Precompute average degree once over all physical qubits in the coupling graph
    all_phys = list(self.backend.keys())
    avg_deg = sum(len(self.backend[q]) for q in all_phys) / len(all_phys)

    def mobility_adjusted_distance(Q1, Q2):
        """
        Replace raw hop-count d(Q1,Q2) with topology-adjusted distance.
        Adjustment = avg_deg / geom_mean(deg(Q1), deg(Q2)):
          - high-degree (hub) pair  -> factor < 1  -> discounted cost (flexible routing)
          - low-degree (leaf) pair  -> factor > 1  -> amplified cost (bottleneck penalty)
          - average-degree pair     -> factor = 1  -> unchanged
        """
        d = self.distance_matrix[Q1][Q2]
        deg1 = len(self.backend[Q1])
        deg2 = len(self.backend[Q2])
        geom_mean = math.sqrt(deg1 * deg2) if (deg1 > 0 and deg2 > 0) else 1.0
        return (avg_deg / geom_mean) * d

    f_distance = 0.0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        deps = self.dag_dependencies_count[g]
        f_distance += (deps + 1) * mobility_adjusted_distance(Q1, Q2)

    e_distance = 0.0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        layer_factor = self.extended_layer_index.get(g, 0) + 1
        deps = self.dag_dependencies_count[g]
        e_distance += (deps + 1) * mobility_adjusted_distance(Q1, Q2) / layer_factor

    H = max_decay * (f_distance / front_layer_size + W *
                     ((e_distance / extended_layer_size) if extended_layer_size else 0))

    return H
```

---

**How QMADC differs fundamentally from the baseline:**

| Aspect | Baseline | QMADC |
|---|---|---|
| Distance term | raw `d(Q1, Q2)` | `(avg_deg / √(deg(Q1)·deg(Q2))) · d(Q1, Q2)` |
| Topology awareness | none | encodes per-qubit routing flexibility |
| Bottleneck penalty | none | amplifies cost when both qubits are peripheral (low degree) |
| Hub discount | none | discounts cost when both qubits are well-connected |

**Mathematical intuition:**

The adjustment factor `avg_deg / √(deg(Q1)·deg(Q2))` is the ratio of the arithmetic mean degree to the geometric mean of the pair's degrees. By the AM-GM inequality, this is always ≥ 1 when one qubit is below-average and the other above — it penalizes asymmetric routing situations too. The factor:
- equals 1 exactly when both qubits have exactly `avg_deg` connections
- shrinks below 1 only when the geometric mean exceeds the arithmetic mean (both qubits are high-degree hubs)
- grows above 1 when at least one qubit is a leaf node, correctly flagging that SWAPs through degree-1 or degree-2 qubits are structurally expensive (few escape routes)
