**IDEA_NAME:** Optimal Transport (Wasserstein) Placement

**DESCRIPTION:** Model each logical qubit as a weighted point (weight = total interaction count) in an abstract metric space defined by the interaction graph shortest paths. Compute the optimal transport plan (Earth Mover's Distance) between these two distributions using the Wasserstein distance framework. The transport plan directly yields a soft assignment matrix, which is then discretized via the Hungarian algorithm to produce a valid 1-to-1 mapping. The key insight is that optimal transport naturally preserves neighborhood structure — heavily interacting logical qubits get mapped to physically proximate qubits because transporting "mass" over long distances is penalized.

**ALGORITHMIC_APPROACH:**

2. Compute interaction weights per qubit (sum of edge weights incident to each qubit).
3. Define a cost matrix C[i][j] = sum over logical neighbors k of i: interaction_weight(i,k) * hardware_distance(j, nearest_suitable_phys_for_k). This prevents the common greedy pitfall of making easy early decisions that constrain hard later decisions.

**ALGORITHMIC_APPROACH:**
