def init_mapping(self):

    from collections import deque

    n = self.num_qubits  # number of physical qubits

    # --- Step 1: Build weighted logical interaction graph ---
    interaction_weight = {}
    logical_qubits_used = set()
    for gate_id, qubits in self.access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            logical_qubits_used.add(q1)
            logical_qubits_used.add(q2)
            edge = (min(q1, q2), max(q1, q2))
            interaction_weight[edge] = interaction_weight.get(edge, 0) + 1
        elif len(qubits) == 1:
            logical_qubits_used.add(qubits[0])

    G_logical = nx.Graph()
    for (q1, q2), w in interaction_weight.items():
        G_logical.add_edge(q1, q2, weight=w)

    matching = nx.max_weight_matching(G_logical, maxcardinality=False)

    # Sort matched pairs by weight descending
    matched_pairs = []
    for u, v in matching:
        edge = (min(u, v), max(u, v))
        matched_pairs.append((u, v, interaction_weight.get(edge, 0)))
    matched_pairs.sort(key=lambda x: -x[2])

    G_hw = nx.Graph()
    for p in self.backend:
        for q in self.backend[p]:
            G_hw.add_edge(p, q)

    hw_centrality = nx.degree_centrality(G_hw)
    hw_edges = list(G_hw.edges())

                assigned_logical.add(lq2)

                occupied_physical.add(pq2)

            if (q1 == lq and q2 in assigned_logical) or (q2 == lq and q1 in assigned_logical):

        return -total

                    improved = True
                else:
                    # Swap back
                    logical_to_physical[lq_i], logical_to_physical[lq_j] = (
                        logical_to_physical[lq_j], logical_to_physical[lq_i]
                    )

    for lq in range(n):
        pq = logical_to_physical[lq]
        mapping_dict[lq] = pq
        reverse_mapping_dict[pq] = lq

## Algorithm Summary

The implementation follows all 7 steps from the algorithm idea:

1. **Build weighted interaction graph** from `self.access` — counts how many 2-qubit gates each logical qubit pair shares.

2. **Maximum weight matching** via NetworkX's `max_weight_matching` (Blossom algorithm) — identifies the most critical qubit pairs.

3. **Sort hardware edges** by sum of degree centrality of both endpoints — most connected/central edges are preferred.

4. **Greedy assignment** of matched pairs to hardware edges in weight-descending order. Each matched logical pair gets placed on adjacent physical qubits. Physical qubits are marked occupied immediately (collision prevention).

5. **BFS-expand** for unmatched qubits — finds the nearest unoccupied physical qubit to already-placed interaction neighbors.

6. **Trivial fill** for any remaining logical qubits not used in the circuit.

7. **2-opt local search** — iteratively swaps physical assignments of qubit pairs if it reduces total weighted interaction distance. Capped at 50 iterations.

**Validity guarantees**: Every logical qubit maps to exactly one unique physical qubit. The `assigned_logical` and `occupied_physical` sets enforce strict 1-to-1 throughout. Both `mapping_dict` (logical→physical) and `reverse_mapping_dict` (physical→logical) are populated as `list[int]`.
