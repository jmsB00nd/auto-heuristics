The key math for PCDC:
- `ALAP(g) = total_critical_path - cp_forward(g)` (latest executable depth)
- `slack(g) = ALAP(g) - ASAP(g) = (total_cp - cp_fwd(g)) - deps(g)`
- Pressure = `1 / slack^α` when slack > 0, exponential amplification when past deadline

This is fundamentally different from:
- **Baseline**: `(deps+1) * dist` — linear backward weight
- **CPGUC**: `cp_fwd/max_cp * dist` — forward CP proportional weight
- **PCDC**: `1/slack^α * dist` — nonlinear, bidirectional slack-derived pressure

```python
def qlosure_poly_heuristic(self, swap_gate):
    import math

    front_layer_size = len(self.front_layer)
    extended_layer_size = len(self.extended_layer)
    if front_layer_size == 0:
        return 0.0

    max_decay = max(self.decay_parameter[swap_gate[0]], self.decay_parameter[swap_gate[1]])

    # --- 1. Bounded forward CP within the visible window only ---
    # Restricting to front+extended avoids full-DAG DFS timeouts on large circuits.
    relevant = set(self.front_layer) | set(self.extended_layer)
    cp_fwd = {}

    for start in list(relevant):
        if start in cp_fwd:
            continue
        stack = [(start, False)]
        while stack:
            node, done = stack.pop()
            if node in cp_fwd:
                continue
            succs = [s for s in self.dag2q.get(node, set()) if s in relevant]
            if done:
                cp_fwd[node] = 1 + max((cp_fwd.get(s, 1) for s in succs), default=0)
            else:
                stack.append((node, True))
                for s in succs:
                    if s not in cp_fwd:
                        stack.append((s, False))

    all_gates = list(self.front_layer) + list(self.extended_layer)

    # --- 2. Estimate total critical path through each gate ---
    # total_cp = max over visible gates of (ASAP + CP_forward)
    # ASAP proxy = dag_dependencies_count (transitive predecessor count)
    total_cp = max(
        self.dag_dependencies_count[g] + cp_fwd.get(g, 1)
        for g in all_gates
    )
    if total_cp == 0:
        total_cp = 1

    # Pressure sharpness: higher alpha → gates near deadline get much higher weight
    alpha = 1.5

    # --- 3. Front layer: ALAP-slack deadline pressure ---
    # slack(g) = (total_cp - cp_fwd(g)) - deps(g)
    #   slack == 0  → gate is ON the critical path, must execute immediately
    #   slack >> 0  → gate has margin, low pressure
    #   slack < 0   → gate is overdue (critical path already extended), exponential penalty
    f_distance = 0.0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        dist = self.distance_matrix[Q1][Q2]

        deps = self.dag_dependencies_count[g]
        cp = cp_fwd.get(g, 1)
        slack = (total_cp - cp) - deps

        if slack > 0:
            # Inverse polynomial of slack: gates closer to deadline get higher urgency
            pressure = 1.0 / (slack ** alpha)
        else:
            # Past deadline: exponential amplification, capped to avoid overflow
            pressure = math.exp(min(-slack * 0.5, 10.0))

        f_distance += pressure * dist

    # --- 4. Extended layer: slack pressure decayed by lookahead depth ---
    # For extended gates, ASAP includes the layer offset: ASAP ~ deps + layer_idx
    # slack = (total_cp - cp_fwd) - (deps + layer_idx)
    e_distance = 0.0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        dist = self.distance_matrix[Q1][Q2]

        deps = self.dag_dependencies_count[g]
        cp = cp_fwd.get(g, 1)
        layer_idx = self.extended_layer_index.get(g, 0) + 1

        slack = (total_cp - cp) - (deps + layer_idx)

        if slack > 0:
            pressure = 1.0 / (slack ** alpha * layer_idx)
        else:
            # Overdue even accounting for future position: elevated urgency
            pressure = math.exp(min(-slack * 0.3, 8.0)) / layer_idx

        e_distance += pressure * dist

    H = max_decay * (
        f_distance / front_layer_size +
        (e_distance / extended_layer_size if extended_layer_size else 0.0)
    )
    return H
```

**Mathematical design summary:**

| Property | Baseline | CPGUC | **PCDC (this)** |
|---|---|---|---|
| Gate weight source | Predecessors (backward) | CP length (forward) | ALAP slack (bidirectional) |
| Weight formula | `deps + 1` | `cp_fwd / max_cp` | `1 / slack^1.5` |
| Past-deadline behavior | None | None | Exponential amplification |
| Critical path gate priority | Implicit via deps | Proportional to cp | `slack → 0 ⟹ pressure → ∞` |

The key equation is `slack(g) = (total_cp − cp_fwd(g)) − deps(g)`. This combines both the gate's position in the DAG (deps, ASAP proxy) and its remaining chain length (cp_fwd), yielding a true ALAP-derived slack. Gates on the critical path have `slack = 0` (highest urgency). The inverse polynomial `1/slack^α` creates a **progressive contraction**: as routing depth approaches a gate's deadline, the pressure curve steepens nonlinearly, focusing SWAP choices on the most time-critical placements.
