Good — the existing `RCIFC` used BFS over the full DAG (causing timeouts). My implementation stays within `front_layer + extended_layer` only, avoids BFS, and uses **per-qubit normalized pressure** rather than per-pair frequency:

```python
def qlosure_poly_heuristic(self, swap_gate):
    all_gates = list(self.front_layer) + list(self.extended_layer)
    total_gates = len(all_gates)
    front_layer_size = len(self.front_layer)
    extended_layer_size = len(self.extended_layer)

    if total_gates == 0 or front_layer_size == 0:
        return 0.0

    # Step 1: Compute interaction pressure per qubit
    # pressure[q] = fraction of remaining (approx) gates that involve q
    # This is a global, normalized, qubit-centric property — unlike deps which
    # is a local per-gate DAG attribute.
    qubit_gate_count = {}
    for g in all_gates:
        q1, q2 = self.access2q[g]
        qubit_gate_count[q1] = qubit_gate_count.get(q1, 0) + 1
        qubit_gate_count[q2] = qubit_gate_count.get(q2, 0) + 1

    # Normalize: pressure in [0, 1] relative to total remaining gate count
    pressure = {q: cnt / total_gates for q, cnt in qubit_gate_count.items()}

    max_decay = max(
        self.decay_parameter[swap_gate[0]],
        self.decay_parameter[swap_gate[1]]
    )

    # Step 2: Front layer — amplify distance by combined qubit pressure
    # Gates whose qubits are "globally busy" get stronger routing signal
    f_distance = 0.0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        p1 = pressure.get(q1, 0.0)
        p2 = pressure.get(q2, 0.0)
        # Weight = 1 + sum of pressures: high-pressure qubits amplify urgency
        pressure_weight = 1.0 + p1 + p2
        f_distance += pressure_weight * self.distance_matrix[Q1][Q2]

    # Step 3: Extended layer — same pressure amplification + depth decay
    e_distance = 0.0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        p1 = pressure.get(q1, 0.0)
        p2 = pressure.get(q2, 0.0)
        pressure_weight = 1.0 + p1 + p2
        layer_factor = self.extended_layer_index.get(g, 0) + 1
        e_distance += pressure_weight * self.distance_matrix[Q1][Q2] / layer_factor

    H = max_decay * (
        f_distance / front_layer_size +
        (e_distance / extended_layer_size if extended_layer_size else 0.0)
    )

    return H
```

**Key differences from baseline:**

| Property | Baseline | RCIPC |
|---|---|---|
| Weight source | `deps+1` (per-gate DAG property) | `1 + p1 + p2` (global qubit-level fraction) |
| Normalization | None — raw dependency count | Divided by `total_gates` → pressure ∈ [0,1] |
| Scope | Each gate is weighted independently | Qubits carry global circuit-wide load signal |
| Semantic | "urgent gates get more weight" | "busy qubits get proactive repositioning pressure" |

The pressure `p_q = count_q / total_gates` captures *how congested* each qubit is relative to the entire remaining workload. When both qubits of a gate have high pressure (both appear in many future gates), `pressure_weight` rises toward 3.0, strongly incentivizing SWAP choices that reduce their physical distance early.
