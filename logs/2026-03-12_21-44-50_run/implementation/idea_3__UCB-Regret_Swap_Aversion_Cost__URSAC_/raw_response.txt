```python
def qlosure_poly_heuristic(self, swap_gate):
    # ── UCB-Regret Swap Aversion Cost (URSAC) ────────────────────────────────
    #
    # Frames each hardware edge as a multi-armed bandit "arm". Regret
    # accumulates permanently whenever committing a swap on edge e results
    # in a cost *increase* (max(0, cost_after - cost_before)). A UCB-style
    # term adds a small, shrinking penalty for under-explored edges. Together
    # these form an additive correction on top of the baseline f/e distance
    # score that statistically discourages oscillating or unproductive edges.
    #
    # Oscillation convergence guarantee:
    #   An oscillating pair (e, ē) that repeatedly increases cost by δ has
    #   regret[e] growing linearly. The regret_density = regret/(usage+1)
    #   converges to δ > 0, permanently inflating the cost of that edge above
    #   any neutral or improving alternative → oscillation is self-defeating.
    # ─────────────────────────────────────────────────────────────────────────

    W    = 0.5    # extended-layer weight: < 1 keeps front-layer dominant
    BETA = 0.05   # UCB exploration coefficient: keeps penalty as tie-breaker

    p1, p2 = swap_gate

    # ── Lazy URSAC state init ─────────────────────────────────────────────
    if not hasattr(self, '_ursac'):
        self._ursac = {
            'regret':        {},    # canonical_edge -> cumulative float regret
            'usage':         {},    # canonical_edge -> int use count
            'total':         0,     # total committed swaps seen so far
            'prev_decay':    None,  # decay snapshot at last round boundary
            'prev_baseline': 0.0,  # baseline cost just before last committed swap
            'round_key':     None,  # (mapping_hash, fl_hash) of current round
        }
    st = self._ursac

    # ── Local helper: compute baseline with an arbitrary mapping ──────────
    # Used to measure cost_before and cost_after around a committed swap.
    # O(|F| + |E|) — called at most once per round boundary.
    def _baseline(mapping):
        fl_sz = len(self.front_layer)
        el_sz = len(self.extended_layer) if self.extended_layer else 0

        f = 0.0
        for g in self.front_layer:
            qa, qb = self.access2q[g]
            f += (self.dag_dependencies_count[g] + 1) * \
                 self.distance_matrix[mapping[qa]][mapping[qb]]
        f_score = f / fl_sz if fl_sz else 0.0

        e = 0.0
        if el_sz > 0:
            for g in self.extended_layer:
                qa, qb = self.access2q[g]
                lf = self.extended_layer_index.get(g, 0) + 1
                e += (self.dag_dependencies_count[g] + 1) * \
                     self.distance_matrix[mapping[qa]][mapping[qb]] / lf
            e_score = e / el_sz
        else:
            e_score = 0.0

        return f_score + W * e_score

    # ── Round-boundary detection and regret update ────────────────────────
    # round_key changes whenever mapping OR front_layer changes, i.e. exactly
    # once per committed swap or gate-execution event.  On transition we:
    #   • detect which event occurred via the decay_parameter delta
    #   • if a SWAP was committed: accumulate regret for that edge
    #   • refresh prev_baseline for the next comparison window
    #
    # Committed-SWAP signature (from routing.py L241-242):
    #   exactly 2 physical qubits gain +0.001; everything else unchanged.
    # Gate-execution signature (routing.py L136):
    #   decay resets uniformly to 1.0 for ALL qubits (neg delta on >2 entries).
    round_key = (hash(tuple(self.mapping_dict)), hash(frozenset(self.front_layer)))

    if round_key != st['round_key']:
        cur_decay = self.decay_parameter

        if st['prev_decay'] is not None:
            prev_decay  = st['prev_decay']
            pos_changed = [q for q in range(len(cur_decay))
                           if cur_decay[q] - prev_decay[q] >  1e-7]
            neg_changed = [q for q in range(len(cur_decay))
                           if cur_decay[q] - prev_decay[q] < -1e-7]

            if len(pos_changed) == 2 and not neg_changed:
                # ── SWAP committed on {pos_changed[0], pos_changed[1]} ────
                # self.mapping_dict already reflects the post-swap state.
                # Compare post_baseline (now) with prev_baseline (before swap).
                q0, q1 = pos_changed[0], pos_changed[1]
                edge   = (min(q0, q1), max(q0, q1))

                post_baseline = _baseline(self.mapping_dict)
                regret_delta  = max(0.0, post_baseline - st['prev_baseline'])

                st['regret'][edge] = st['regret'].get(edge, 0.0) + regret_delta
                st['usage'][edge]  = st['usage'].get(edge, 0)    + 1
                st['total']       += 1
                st['prev_baseline'] = post_baseline

            else:
                # ── Gate execution: decay reset → new scheduling context ──
                # No swap to charge; just re-anchor the baseline reference.
                st['prev_baseline'] = _baseline(self.mapping_dict)

        else:
            # First-ever call: anchor the initial baseline
            st['prev_baseline'] = _baseline(self.mapping_dict)

        st['prev_decay'] = list(cur_decay)
        st['round_key']  = round_key

    # ── Baseline score for this candidate (uses temp_mapping_dict) ────────
    front_layer_size    = len(self.front_layer)
    extended_layer_size = len(self.extended_layer) if self.extended_layer else 0

    f_distance = 0.0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        deps = self.dag_dependencies_count[g]
        f_distance += (deps + 1) * self.distance_matrix[Q1][Q2]
    f_score = f_distance / front_layer_size if front_layer_size else 0.0

    e_score = 0.0
    if extended_layer_size > 0:
        e_distance = 0.0
        for g in self.extended_layer:
            q1, q2 = self.access2q[g]
            Q1 = self.temp_mapping_dict[q1]
            Q2 = self.temp_mapping_dict[q2]
            lf = self.extended_layer_index.get(g, 0) + 1
            deps = self.dag_dependencies_count[g]
            e_distance += (deps + 1) * self.distance_matrix[Q1][Q2] / lf
        e_score = e_distance / extended_layer_size

    baseline = f_score + W * e_score

    # ── UCB-Regret penalty ─────────────────────────────────────────────────
    edge_key = (min(p1, p2), max(p1, p2))
    regret   = st['regret'].get(edge_key, 0.0)
    usage    = st['usage'].get(edge_key, 0)
    t        = st['total'] + 1          # +1: t >= 1 always (log safe)

    # regret_density: average cost-increase per committed use of this edge.
    # An oscillating edge that raises cost by δ each time converges to δ.
    regret_density = regret / (usage + 1)   # (usage+1): no div/0

    # UCB uncertainty term: shrinks as edge is used more, resolves ties for
    # edges with equal regret by preferring better-explored ones.
    ucb_term = BETA * math.sqrt(math.log(t + 1) / (usage + 1))

    ucb_penalty = regret_density + ucb_term

    # ── Decay multiplier (anti-hotspot, inherited from base Qlosure) ──────
    max_decay = max(self.decay_parameter[p1], self.decay_parameter[p2])

    # UCB penalty is an absolute edge-quality correction; not scaled by decay.
    cost = max_decay * baseline + ucb_penalty
    return cost
```

## Design decisions explained

**State detection without modifying `apply_qlosure_heuristic`**

The implementation borrows the OSHB trick: `decay_parameter` is a free side-channel. A committed swap raises exactly 2 entries by `+0.001`; a gate-execution event resets everything to `1.0` (negative delta). Checking `pos_changed`/`neg_changed` at each `round_key` transition gives a clean, zero-interface-change hook for regret updates.

**`round_key = (hash(tuple(mapping_dict)), hash(frozenset(front_layer)))`**

Triggers exactly once per event, same as QMRP. The `_baseline()` helper is only ever called once per round boundary (not per candidate), keeping the overhead to O(|F|+|E|) per swap step.

**`max_decay * baseline + ucb_penalty`**

The UCB penalty is an *absolute* edge-quality signal — scaling it by `max_decay` would tie its magnitude to qubit activity, which is undesirable. Keeping it additive preserves the tie-breaking semantics.

**Convergence proof sketch for oscillation**

Let edge `e` oscillate: at step 2k cost increases by δ (swap worsens mapping). Then `regret[e] += δ` each bad step. After K worsening uses: `regret_density → δ`. Any other edge with `regret_density < δ` and equal baseline will be strictly preferred, breaking the oscillation after at most K/BETA rounds.

**Numerical safety**

- `usage + 1` in all denominators → no div/zero  
- `t + 1 ≥ 2` before `log` → `log(t+1) > 0` always  
- `regret_delta = max(0, ...)` → regret is monotonically non-decreasing  
- `_baseline()` returns 0 when `front_layer` or `extended_layer` are empty
