IDEA_NAME: Spectral Fiedler Qubit Alignment (SFQA)
DESCRIPTION: Exploit the algebraic structure of both the logical interaction graph and the hardware topology graph via their Laplacian Fiedler vectors (second-smallest eigenvectors). The Fiedler vector encodes the "spectral geometry" of a graph — nodes with similar Fiedler values are algebraically close. By independently computing Fiedler vectors for both graphs and assigning logical qubits to physical qubits in sorted Fiedler-value order, structurally similar positions in both graphs get paired.
ALGORITHMIC_APPROACH:
1. Build weighted logical interaction graph G_L: nodes = logical qubits, edge weight = interaction frequency between qubit pairs (count occurrences in `self.access`)
2. Build hardware graph G_H from `self.backend` adjacency list
3. Compute Laplacian L_L = D_L - A_L and L_H = D_H - A_H
4. Extract Fiedler vector v_L (2nd eigenvector of L_L) and v_H (2nd eigenvector of L_H) via `numpy.linalg.eigh`
5. Sort logical qubit indices by v_L values → sorted_logical
6. Sort physical qubit indices by v_H values → sorted_physical
7. Assign: `mapping[sorted_logical[i]] = sorted_physical[i]` for all i
COLLISION_PREVENTION: The sorted-order bijection construction inherently assigns exactly one physical qubit per logical qubit. Uses `set()` of remaining physical qubits as a pool; once assigned, removed.
WHY_NOVEL: Prior spectral methods for quantum mapping compute Fiedler on one graph and embed into a metric space. SFQA performs *dual Fiedler alignment* — spectral sorting on both graphs simultaneously — exploiting that the Fiedler vector captures the natural "bipartition spine" of any connected graph.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 9
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.5

```python
# Integration in init_mapping():
# Available: self.access, self.backend, self.num_qubits
import numpy as np
from collections import defaultdict

def sfqa_initial_mapping(access, backend, num_qubits):
    # Build interaction frequency matrix
    freq = defaultdict(int)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = sorted(qubits)
            freq[(q1, q2)] += 1
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    n_log = len(logical_qubits)
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    # Logical Laplacian
    A_L = np.zeros((n_log, n_log))
    for (q1, q2), w in freq.items():
        i, j = lq_idx[q1], lq_idx[q2]
        A_L[i, j] = A_L[j, i] = w
    D_L = np.diag(A_L.sum(axis=1))
    L_L = D_L - A_L
    # Hardware Laplacian
    phys_nodes = list(backend.keys())
    n_phys = len(phys_nodes)
    ph_idx = {p: i for i, p in enumerate(phys_nodes)}
    A_H = np.zeros((n_phys, n_phys))
    for p, neighbors in backend.items():
        for nb in neighbors:
            A_H[ph_idx[p]][ph_idx[nb]] = 1.0
    D_H = np.diag(A_H.sum(axis=1))
    L_H = D_H - A_H
    # Fiedler vectors
    _, V_L = np.linalg.eigh(L_L)
    fiedler_L = V_L[:, 1]  # second eigenvector
    _, V_H = np.linalg.eigh(L_H)
    fiedler_H = V_H[:, 1]
    sorted_logical = [logical_qubits[i] for i in np.argsort(fiedler_L)]
    sorted_physical = [phys_nodes[i] for i in np.argsort(fiedler_H)]
    mapping_dict = {}
    for lq, pq in zip(sorted_logical, sorted_physical[:n_log]):
        mapping_dict[lq] = pq
    return mapping_dict

IDEA_NAME: Critical Path Hardware Spine Alignment (CPHSA)
DESCRIPTION: The critical (longest dependency) path of the circuit DAG constrains routing most severely — its qubits must interact in strict sequence and any SWAP inflates circuit depth multiplicatively. CPHSA finds this critical path in the DAG, extracts the unique hardware "spine" (longest induced shortest-path chain in the hardware topology), and aligns them. Remaining qubits are placed greedily in a BFS wave from their already-placed interacting partners.
ALGORITHMIC_APPROACH:
1. Using `self.dag_dependencies_count`, find the gate with the highest dependency count → this is near the circuit's critical bottleneck
2. Trace back through DAG predecessors to extract the full critical path as an ordered list of gates
3. Extract the unique logical qubit sequence that appears along this critical path
4. Find the hardware "spine": compute all-pairs shortest paths on `self.backend`, find the pair of nodes with maximum distance → the path between them is the hardware diameter path
5. Align critical logical qubits to hardware spine nodes (first ↔ first, last ↔ last, middle ↔ middle via interpolation)
6. Place remaining logical qubits using BFS from already-mapped qubits, assigning the nearest unoccupied hardware neighbor to each unplaced qubit's most frequent interacting partner
COLLISION_PREVENTION: Maintain a `placed_physical = set()` pool. Critical path assigns from spine (distinct nodes). BFS greedily picks from `set(backend[already_placed]) - placed_physical`, falling back to global minimum-distance unoccupied node.
WHY_NOVEL: No existing placement algorithm explicitly aligns the DAG critical path to the hardware diameter path. This directly minimizes the irreducible depth overhead on the highest-latency dependency chain.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.5

            pq = nearest_unoccupied(partners, backend, placed_physical)

IDEA_NAME: Front-Layer Lookahead Simulated Annealing (FLLSA)
DESCRIPTION: Uses a fast "micro-routing" simulation restricted to only the first K DAG layers as the energy function for Simulated Annealing over the placement space. Rather than scoring placements analytically, it literally runs a stripped-down version of the swap selection loop and counts swaps incurred. This gives SA a routing-realistic cost signal instead of a proxy.
ALGORITHMIC_APPROACH:
1. Extract the first K layers of the DAG (gates with DAG depth ≤ K) using `dag_dependencies_count`
2. Define energy E(placement) = swap count incurred by the Qlosure heuristic on this K-layer prefix
3. Initialize SA from SFQA or CPHSA placement (warm start)
4. SA move: swap two random logical-to-physical assignments in `mapping_dict`
5. Accept/reject via Metropolis criterion: accept if ΔE < 0, else accept with probability exp(-ΔE / T)
6. Cool temperature T geometrically: T ← α·T per iteration
7. Return best placement found
COLLISION_PREVENTION: Every SA move is a transposition (swap two existing entries in `mapping_dict`), which preserves bijectivity by construction. No new entries added, no entries removed.
WHY_NOVEL: Instead of proxy cost functions (distance sums, centrality), it uses actual routing simulation as the SA objective — capturing correlations between gate parallelism, hardware topology, and SWAP cascades that no analytic proxy can.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 8
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.0

# Access: self.access, self.access2q, self.front_layer, self.distance_matrix
# self.mapping_dict after init gets mutated by SA

def fllsa_initial_mapping(mapping_dict, access, access2q, distance_matrix,
                          backend, k_layers=3, n_iter=500, T0=10.0, alpha=0.98):
    import math, random
    best_mapping = dict(mapping_dict)
    best_score = _micro_route_score(best_mapping, access2q, distance_matrix, k_layers)
    current = dict(best_mapping)
    T = T0
    logical_qubits = list(current.keys())
    for _ in range(n_iter):
        # Move: swap two logical qubits' physical assignments
        lq1, lq2 = random.sample(logical_qubits, 2)
        current[lq1], current[lq2] = current[lq2], current[lq1]
        score = _micro_route_score(current, access2q, distance_matrix, k_layers)
        delta = score - best_score
        if delta < 0 or random.random() < math.exp(-delta / T):
            if score < best_score:
                best_score = score
                best_mapping = dict(current)
        else:
            current[lq1], current[lq2] = current[lq2], current[lq1]  # revert
        T *= alpha
    return best_mapping

def _micro_route_score(mapping, access2q, distance_matrix, k_layers):
    # Score = sum of pairwise hardware distances for first k_layers of 2q gates
    score = 0
    for gate, (q1, q2) in list(access2q.items())[:k_layers * 10]:
        p1, p2 = mapping.get(q1), mapping.get(q2)
        if p1 is not None and p2 is not None:
            score += distance_matrix[p1][p2]
    return score
```

IDEA_NAME: PageRank Dual Rank Matching (PRDM)
DESCRIPTION: Compute PageRank on both the directed logical interaction graph (edges weighted by gate order/frequency, direction from earlier to later gate) and the hardware graph. High-PageRank logical qubits act as "hubs" in the circuit flow and should land on high-PageRank hardware qubits (high connectivity = routing flexibility). Match by rank descending.
ALGORITHMIC_APPROACH:
1. Build directed interaction graph G_L: for each 2-qubit gate (q1, q2) in temporal order, add directed edge q1→q2 and q2→q1 with weight = 1/gate_layer_index (earlier gates = higher weight)
2. Run PageRank on G_L (power iteration, 50 iters, damping=0.85) → `pr_logical[q]`
3. Build undirected hardware graph G_H from `self.backend`, compute PageRank → `pr_hardware[p]`
4. Sort logical qubits descending by `pr_logical`, sort physical qubits descending by `pr_hardware`
5. Assign in sorted order: `mapping_dict[sorted_logical[i]] = sorted_physical[i]`
COLLISION_PREVENTION: Sorted-order bijection: both lists have equal length (logical qubits ≤ physical qubits). If more physical qubits exist, only the top-N physical nodes are used. Unassigned physical qubits are simply unused.
WHY_NOVEL: Standard approaches use degree or betweenness. PageRank on the *directed temporal* interaction graph captures the asymmetric flow of quantum information through the circuit, weighting early hub qubits more heavily — this temporal directionality is unexploited in existing placement methods.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 9
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.25

```python
def prdm_initial_mapping(access, backend, num_qubits, damping=0.85, n_iter=50):
    from collections import defaultdict
    # Build logical interaction graph (directed, temporally weighted)
    out_edges = defaultdict(dict)
    gate_list = sorted(access.keys())  # temporal order
    for rank, gate in enumerate(gate_list):
        qubits = access[gate]
        if len(qubits) == 2:
            q1, q2 = qubits
            w = 1.0 / (rank + 1)
            out_edges[q1][q2] = out_edges[q1].get(q2, 0) + w
            out_edges[q2][q1] = out_edges[q2].get(q1, 0) + w
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    # PageRank on logical graph
    pr_l = {q: 1.0 / len(logical_qubits) for q in logical_qubits}
    for _ in range(n_iter):
        new_pr = {}
        for q in logical_qubits:
            incoming = sum(pr_l[src] * w / sum(out_edges[src].values())
                           for src, neighbors in out_edges.items()
                           for tgt, w in neighbors.items() if tgt == q)
            new_pr[q] = (1 - damping) / len(logical_qubits) + damping * incoming
        pr_l = new_pr
    # PageRank on hardware graph
    phys_nodes = list(backend.keys())
    pr_h = {p: 1.0 / len(phys_nodes) for p in phys_nodes}
    for _ in range(n_iter):
        new_pr = {}
        for p in phys_nodes:
            deg = len(backend[p])
            incoming = sum(pr_h[nb] / len(backend[nb]) for nb in backend[p])
            new_pr[p] = (1 - damping) / len(phys_nodes) + damping * incoming
        pr_h = new_pr
    sorted_logical = sorted(logical_qubits, key=lambda q: pr_l[q], reverse=True)
    sorted_physical = sorted(phys_nodes, key=lambda p: pr_h[p], reverse=True)
    return {lq: pq for lq, pq in zip(sorted_logical, sorted_physical)}
```

IDEA_NAME: Token Sliding Conflict Resolution (TSCR)
DESCRIPTION: Start from a good seed placement (e.g., SFQA). Identify "conflict pairs" — logical qubit pairs that interact frequently but whose mapped physical qubits are far apart in the hardware. Resolve conflicts iteratively by sliding tokens (logical qubit assignments) along hardware paths toward each other, accepting slides that strictly reduce total conflict cost. Stop when no improving slide exists.
ALGORITHMIC_APPROACH:
1. Initialize from seed placement (trivial or spectral)
2. Build conflict list: for each pair (q1, q2) with interaction frequency f(q1,q2), define conflict_cost = f(q1,q2) × distance_matrix[mapping[q1]][mapping[q2]]
3. Sort conflicts descending by conflict_cost
4. For each conflict (q1, q2), enumerate all hardware paths between mapping[q1] and mapping[q2]
5. Try sliding q1 toward q2 by one hop: swap q1's assignment with the qubit currently at the intermediate node
6. Accept the slide if total conflict cost decreases (greedy local search)
7. Repeat until convergence or max iterations
COLLISION_PREVENTION: Every "slide" is implemented as a transposition between two logical qubits' physical assignments. The bijection is maintained at every step since we swap existing valid entries, never introduce duplicates.
WHY_NOVEL: Token sliding is a well-known framework in combinatorics (e.g., 15-puzzle, token swapping), but applying it to quantum placement as a conflict-resolution mechanism — where "tokens" are logical qubits sliding along hardware topology paths — is entirely novel.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.25

```python
def tscr_initial_mapping(seed_mapping, access, distance_matrix, backend, max_iters=100):
    from collections import defaultdict
    mapping = dict(seed_mapping)
    rev = {v: k for k, v in mapping.items()}
    # Build interaction frequency
    freq = defaultdict(int)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1

    def total_cost():
        return sum(f * distance_matrix[mapping[q1]][mapping[q2]]
                   for (q1, q2), f in freq.items()
                   if q1 in mapping and q2 in mapping)

    for _ in range(max_iters):
        improved = False
        # Sort conflicts by cost
        conflicts = sorted(freq.items(), key=lambda x: x[1] * distance_matrix.get(
            mapping.get(x[0][0], 0), {}).get(mapping.get(x[0][1], 0), 0), reverse=True)
        for (q1, q2), f in conflicts[:10]:  # focus on top-10 conflicts
            p1, p2 = mapping[q1], mapping[q2]
            # Try sliding q1 one hop toward q2
            for nb in backend.get(p1, []):
                if nb == p2:
                    continue
                # Swap q1's physical with whoever is at nb
                lq_at_nb = rev.get(nb)
                if lq_at_nb is None:
                    continue
                old_cost = total_cost()
                mapping[q1], mapping[lq_at_nb] = nb, p1
                rev[nb], rev[p1] = q1, lq_at_nb
                if total_cost() < old_cost:
                    improved = True
                    break
                else:  # revert
                    mapping[q1], mapping[lq_at_nb] = p1, nb
                    rev[p1], rev[nb] = q1, lq_at_nb
        if not improved:
            break
    return mapping
```

IDEA_NAME: Dependency Mass Gravity Simulation (DMGS)
DESCRIPTION: Treat logical qubits as particles with "mass" proportional to their total DAG dependency count (from `dag_dependencies_count`). Treat hardware qubits as gravity wells with attraction proportional to their degree. Simulate a force-directed placement where massive logical qubits are pulled toward high-degree hardware nodes, and inter-qubit interaction forces attract frequently-interacting pairs. Resolve to a discrete assignment via greedy matching of the resulting continuous embedding.
ALGORITHMIC_APPROACH:
1. Assign mass m_q = sum of `dag_dependencies_count[g]` for all gates g involving qubit q
2. Embed hardware nodes in 2D via Fruchterman-Reingold or coordinate from their adjacency spectrum
3. Place logical qubits at random 2D positions, apply forces each step:
   - Attraction to hardware centroid weighted by degree: F_gravity = m_q × (hardware_centroid - pos_q)
   - Pairwise attraction between interacting qubits: F_pair = freq(q1,q2) × (pos_q2 - pos_q1)
4. Simulate for T steps with cooling step size
5. After simulation, assign each logical qubit to its nearest hardware node via greedy NN matching
COLLISION_PREVENTION: After continuous simulation, use greedy nearest-neighbor assignment with a `used_physical = set()` — assign each logical qubit (sorted by mass descending) to its closest unoccupied hardware node.
WHY_NOVEL: Combines two novel dimensions: (1) qubit "mass" derived from transitive closure dependency counts (which measures quantum information criticality), and (2) hardware "gravitational wells" defined by degree. Neither standard force-directed layout nor existing quantum placement uses this dependency-mass framework.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 6
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.5

```python
def dmgs_initial_mapping(access, dag_dependencies_count, distance_matrix, backend, steps=50):
    import numpy as np
    from collections import defaultdict
    # Compute qubit masses
    qubit_mass = defaultdict(float)
    for gate, count in dag_dependencies_count.items():
        for q in access.get(gate, []):
            qubit_mass[q] += count + 1
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    phys_nodes = list(backend.keys())
    n_log, n_phys = len(logical_qubits), len(phys_nodes)
    # Hardware 2D embedding via adjacency spectrum
    A = np.zeros((n_phys, n_phys))
    pi = {p: i for i, p in enumerate(phys_nodes)}
    for p, nbs in backend.items():
        for nb in nbs:
            A[pi[p]][pi[nb]] = 1
    _, V = np.linalg.eigh(np.diag(A.sum(1)) - A)
    hw_coords = V[:, 1:3]  # 2D Fiedler embedding of hardware
    # Initialize logical qubit positions randomly within hardware bounds
    pos = np.random.uniform(hw_coords.min(), hw_coords.max(), (n_log, 2))
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1
    lr = 0.1
    for step in range(steps):
        forces = np.zeros((n_log, 2))
        # Gravity toward high-degree hardware centroid
        hw_centroid = hw_coords.mean(axis=0)
        for lq in logical_qubits:
            forces[lq_idx[lq]] += qubit_mass[lq] * (hw_centroid - pos[lq_idx[lq]]) * 0.01
        # Pairwise interaction forces
        for (q1, q2), f in freq.items():
            i1, i2 = lq_idx[q1], lq_idx[q2]
            forces[i1] += f * (pos[i2] - pos[i1]) * 0.1
            forces[i2] += f * (pos[i1] - pos[i2]) * 0.1
        pos += lr * forces
        lr *= 0.95
    # Greedy NN matching (heaviest qubit first)
    used = set()
    mapping_dict = {}
    for lq in sorted(logical_qubits, key=lambda q: qubit_mass[q], reverse=True):
        best_pq = min((p for p in phys_nodes if p not in used),
                      key=lambda p: np.linalg.norm(pos[lq_idx[lq]] - hw_coords[pi[p]]))
        mapping_dict[lq] = best_pq
        used.add(best_pq)
    return mapping_dict
```

IDEA_NAME: Hungarian Assignment with Layer-Decay Cost Matrix (HADLC)
DESCRIPTION: Formulates placement as a linear assignment problem (LAP) solvable in O(n³) with the Hungarian algorithm. The cost matrix C[i,j] = expected hardware routing cost if logical qubit i is placed at physical qubit j, computed as the sum over all gates involving qubit i of: (interaction frequency with each partner) × (distance_matrix[j][best_physical_for_partner]) × (layer_decay_factor), where earlier gates receive exponentially higher weight.
ALGORITHMIC_APPROACH:
1. For each logical qubit q_i, compute its "interaction profile": a vector of (partner_qubit, frequency, avg_layer_depth) tuples from `self.access`
2. For each candidate physical assignment (q_i → p_j), estimate cost as: C[i,j] = Σ_{partners p of q_i} freq(q_i,p) × min_{p' ∈ hardware} dist(p_j, p') × exp(-λ × layer_depth)
3. Build n_logical × n_physical cost matrix C
4. Solve with `scipy.optimize.linear_sum_assignment` (Hungarian algorithm)
5. Extract bijection from solution
COLLISION_PREVENTION: The Hungarian algorithm produces a perfect matching in a bipartite graph — by definition it assigns exactly one physical qubit per logical qubit. If n_physical > n_logical, add dummy logical qubits with zero-cost rows.
WHY_NOVEL: Existing LAP-based quantum placement uses flat interaction frequency. HADLC introduces a temporal layer-decay exponential weight, meaning gates appearing in earlier circuit layers (which constrain routing earlier and compound over depth) contribute proportionally more to the cost — a theoretically grounded formulation.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.0

```python
def hadlc_initial_mapping(access, distance_matrix, backend, decay_lambda=0.1):
    import numpy as np
    from scipy.optimize import linear_sum_assignment
    from collections import defaultdict
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    phys_nodes = sorted(backend.keys())
    n_log, n_phys = len(logical_qubits), len(phys_nodes)
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    # Build layer-decay weighted interaction profile
    # gate index as proxy for layer depth
    gate_list = sorted(access.keys())
    interactions = defaultdict(list)  # (q1,q2) -> [(layer, freq_weight)]
    for layer, gate in enumerate(gate_list):
        qubits = access[gate]
        if len(qubits) == 2:
            q1, q2 = qubits
            w = np.exp(-decay_lambda * layer)
            interactions[(q1, q2)].append(w)
            interactions[(q2, q1)].append(w)
    # Build cost matrix
    C = np.zeros((n_log, n_phys))
    pi = {p: i for i, p in enumerate(phys_nodes)}
    for (q1, q2), weights in interactions.items():
        if q1 not in lq_idx or q2 not in lq_idx:
            continue
        total_w = sum(weights)
        i = lq_idx[q1]
        # For each physical assignment of q1, best reachable node for q2
        for j, pq1 in enumerate(phys_nodes):
            best_dist = min(distance_matrix[pq1][pq2]
                            for pq2 in phys_nodes if pq1 != pq2)
            C[i][j] += total_w * best_dist
    # Solve LAP
    row_ind, col_ind = linear_sum_assignment(C[:n_log, :n_phys])
    return {logical_qubits[r]: phys_nodes[c] for r, c in zip(row_ind, col_ind)}
```

IDEA_NAME: Causal Cone Cohesion Placement (C3P)
DESCRIPTION: For each gate in the front layer, compute its "causal cone" — the set of all logical qubits that are transitively reachable via DAG successors. Qubits in the same causal cone will need to interact (directly or indirectly) in the future. C3P groups logical qubits by causal cone membership, then uses a Steiner-tree-inspired assignment to place each cone group onto a connected sub-region of the hardware topology, minimizing the maximum pairwise hardware distance within each group.
ALGORITHMIC_APPROACH:
1. For each front-layer gate g, compute causal_cone(g) = {all logical qubits in g's transitive DAG successors} using BFS on `self.dag2q`
2. Build qubit-cone affinity matrix: A[q1][q2] = number of shared cones (captures future co-interaction likelihood)
3. Cluster logical qubits by affinity matrix using agglomerative clustering (or k-means)
4. For each cluster, find the minimum hardware Steiner subtree (approximate via Prim's on the hardware graph restricted to cluster size)
5. Assign cluster members to the Steiner subtree nodes via Hungarian matching on intra-cluster interaction frequency
COLLISION_PREVENTION: Each cluster is assigned to a disjoint set of hardware nodes (Steiner subtrees are constrained to be node-disjoint across clusters). Within a cluster, Hungarian matching guarantees injectivity. Pool of unused nodes maintained via `used_physical`.
WHY_NOVEL: Causal cones are used in circuit simulation (e.g., Clifford simulation, tensor networks) but never applied to placement. Using shared-cone membership as a proxy for future interaction affinity, combined with Steiner-tree placement, is a fundamentally new paradigm.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 7
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.75

```python
def c3p_initial_mapping(access, access2q, dag2q, distance_matrix, backend, front_layer):
    from collections import defaultdict, deque
    import numpy as np
    # Step 1: Compute causal cones from front layer
    def causal_cone(gate, dag2q, access):
        visited_gates, cone_qubits = set(), set()
        queue = deque([gate])
        while queue:
            g = queue.popleft()
            if g in visited_gates:
                continue
            visited_gates.add(g)
            cone_qubits.update(access.get(g, []))
            queue.extend(dag2q.get(g, []))
        return cone_qubits
    # Step 2: Affinity matrix
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    n = len(logical_qubits)
    affinity = np.zeros((n, n))
    for g in front_layer:
        cone = causal_cone(g, dag2q, access)
        cone_list = [q for q in cone if q in lq_idx]
        for i, q1 in enumerate(cone_list):
            for q2 in cone_list[i+1:]:
                affinity[lq_idx[q1]][lq_idx[q2]] += 1
                affinity[lq_idx[q2]][lq_idx[q1]] += 1
    # Step 3: Greedy cluster assignment (simplified: sort by affinity, assign nearby)
    phys_nodes = list(backend.keys())
    used = set()
    mapping_dict = {}
    assigned_order = sorted(logical_qubits,
        key=lambda q: affinity[lq_idx[q]].sum(), reverse=True)
    for lq in assigned_order:
        if lq in mapping_dict:
            continue
        if not used:
            pq = phys_nodes[0]
        else:
            # Assign near most-affine already-mapped partner
            partners = sorted(logical_qubits,
                key=lambda p: affinity[lq_idx[lq]][lq_idx[p]] if p in mapping_dict else -1,
                reverse=True)
            anchor = next((p for p in partners if p in mapping_dict), None)
            anchor_pq = mapping_dict[anchor] if anchor else phys_nodes[0]
            pq = min((p for p in backend.get(anchor_pq, []) if p not in used),
                     key=lambda p: distance_matrix[anchor_pq][p], default=
                     min((p for p in phys_nodes if p not in used),
                         key=lambda p: distance_matrix[anchor_pq][p]))
        mapping_dict[lq] = pq
        used.add(pq)
    return mapping_dict
```

IDEA_NAME: Hierarchical Interaction Graph Coarsening (HIGC)
DESCRIPTION: A multilevel/multigrid approach inspired by algebraic multigrid methods. Iteratively coarsen the logical interaction graph by merging the most frequently interacting qubit pairs into "super-qubits." Solve a simplified placement at the coarsest level, then refine back by splitting super-qubits and locally optimizing the sub-qubit placement within the hardware subgraph allocated to the parent super-qubit.
ALGORITHMIC_APPROACH:
1. Build weighted interaction graph G_0 with edge weights = interaction frequency
2. Coarsen: merge pairs (q1, q2) with highest edge weight → super-qubit [q1,q2], edge weights to neighbors are summed. Repeat until ≤ some threshold size
3. Solve trivial placement at coarsest level (few super-qubits → few hardware nodes needed)
4. Uncoarsen level by level: split each super-qubit [q1,q2] → assign q1 to current hardware node, q2 to nearest available neighbor
5. Apply local optimization at each level: swap adjacent assignments if it reduces weighted distance sum
COLLISION_PREVENTION: At the coarsest level, direct bijection. During uncoarsening, q2 always picks from `available_physical_neighbors - already_used`. Fallback: global minimum-distance unoccupied node.
WHY_NOVEL: Multilevel graph partitioning (METIS-style) is used in classical EDA placement but not in quantum initial mapping. The key novelty is the coarsening strategy guided by temporal interaction frequency from the circuit DAG, and refinement guided by local routing cost.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.5

```python
def higc_initial_mapping(access, distance_matrix, backend, coarsen_target=4):
    from collections import defaultdict
    # Build interaction frequency
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = min(qubits), max(qubits)
            freq[(q1, q2)] += 1.0
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    # Coarsening: greedily merge highest-frequency pairs
    groups = {q: frozenset([q]) for q in logical_qubits}  # group_id -> members
    merged = {q: q for q in logical_qubits}  # qubit -> group representative
    sorted_pairs = sorted(freq.items(), key=lambda x: x[1], reverse=True)
    for (q1, q2), w in sorted_pairs:
        g1, g2 = merged[q1], merged[q2]
        if g1 != g2 and len(groups) > coarsen_target:
            new_group = groups[g1] | groups[g2]
            for q in new_group:
                merged[q] = g1
            groups[g1] = new_group
            del groups[g2]
    # Assign group representatives to hardware nodes
    phys_nodes = sorted(backend.keys(),
                        key=lambda p: len(backend[p]), reverse=True)  # degree-sorted
    group_reps = sorted(groups.keys())
    used = set()
    group_assignment = {}
    for i, rep in enumerate(group_reps):
        pq = phys_nodes[i]
        group_assignment[rep] = pq
        used.add(pq)
    # Uncoarsen: assign each group member near its group center
    mapping_dict = {}
    for rep, members in groups.items():
        center_pq = group_assignment[rep]
        member_list = sorted(members, key=lambda q: freq.get(
            (min(q,rep), max(q,rep)), 0), reverse=True)
        # BFS from center
        bfs_order = [center_pq]
        visited = {center_pq}
        queue = list(backend.get(center_pq, []))
        while queue:
            nb = queue.pop(0)
            if nb not in visited:
                visited.add(nb)
                bfs_order.append(nb)
                queue.extend(backend.get(nb, []))
        slot_idx = 0
        for lq in member_list:
            while slot_idx < len(bfs_order) and bfs_order[slot_idx] in used:
                slot_idx += 1
            if slot_idx < len(bfs_order):
                pq = bfs_order[slot_idx]
            else:
                pq = min((p for p in phys_nodes if p not in used),
                         key=lambda p: distance_matrix[center_pq][p])
            mapping_dict[lq] = pq
            used.add(pq)
            slot_idx += 1
    return mapping_dict
```

IDEA_NAME: Temporal Interaction Tensor Decomposition (TITD)
DESCRIPTION: Build a 3-way tensor T[q1, q2, layer] encoding whether logical qubits q1 and q2 interact in DAG layer `layer`. Apply Tucker/CP decomposition to extract latent qubit feature vectors that capture both structural (who interacts with whom) and temporal (when) interaction patterns. Map qubits with similar latent representations to nearby hardware nodes.
ALGORITHMIC_APPROACH:
1. Assign each gate a layer index using its `dag_dependencies_count` value as proxy for depth
2. Build tensor T of shape (n_logical, n_logical, n_layers): T[i,j,t] = 1 if qubits i,j interact in layer t
3. Compute CP decomposition to rank R (e.g., R=3): T ≈ Σ_r a_r ⊗ b_r ⊗ c_r
4. Each logical qubit i gets feature vector: concat(A[i,:], B[i,:]) where A, B are factor matrices
5. Embed hardware qubits in feature space using their Laplacian eigenvectors
6. Match logical qubits to hardware qubits via nearest-neighbor in feature space with Hungarian deduplication
COLLISION_PREVENTION: After nearest-neighbor matching, use Hungarian algorithm on the distance matrix between logical feature vectors and hardware feature vectors to guarantee a perfect bijection.
WHY_NOVEL: No existing placement approach uses tensor decomposition. The temporal mode of the tensor explicitly captures *when* interactions occur, enabling the decomposition to discover latent "interaction rhythms" that are invisible to standard graph-based methods.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 6
EFFORT_SCORE: 5
FEASIBILITY_SCORE: 8
AVERAGE_SCORE: 7.0

```python
# Note: requires tensorly library (pip install tensorly)
def titd_initial_mapping(access, dag_dependencies_count, distance_matrix, backend, rank=3):
    import numpy as np
    try:
        import tensorly as tl
        from tensorly.decomposition import parafac
        tensor_available = True
    except ImportError:
        tensor_available = False
    from scipy.optimize import linear_sum_assignment
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    n_log = len(logical_qubits)
    depths = sorted(set(dag_dependencies_count.values()))
    depth_idx = {d: i for i, d in enumerate(depths)}
    n_layers = len(depths)
    if tensor_available and n_log >= 2:
        T = np.zeros((n_log, n_log, n_layers))
        for gate, qubits in access.items():
            if len(qubits) == 2:
                q1, q2 = qubits
                if q1 in lq_idx and q2 in lq_idx:
                    t = depth_idx.get(dag_dependencies_count.get(gate, 0), 0)
                    T[lq_idx[q1]][lq_idx[q2]][t] = 1
                    T[lq_idx[q2]][lq_idx[q1]][t] = 1
        factors = parafac(T, rank=min(rank, n_log))
        qubit_features = np.concatenate([factors[0], factors[1]], axis=1)
    else:
        # Fallback: use adjacency rows as features
        A = np.zeros((n_log, n_log))
        for gate, qubits in access.items():
            if len(qubits) == 2:
                q1, q2 = qubits
                if q1 in lq_idx and q2 in lq_idx:
                    A[lq_idx[q1]][lq_idx[q2]] += 1
        qubit_features = A
    # Hardware features via Laplacian embedding
    phys_nodes = list(backend.keys())
    n_phys = len(phys_nodes)
    pi = {p: i for i, p in enumerate(phys_nodes)}
    A_H = np.zeros((n_phys, n_phys))
    for p, nbs in backend.items():
        for nb in nbs:
            A_H[pi[p]][pi[nb]] = 1
    L_H = np.diag(A_H.sum(1)) - A_H
    _, V_H = np.linalg.eigh(L_H)
    hw_features = V_H[:, 1:qubit_features.shape[1]+1]
    # Cost matrix: L2 distance in feature space
    C = np.array([[np.linalg.norm(qubit_features[i] - hw_features[j])
                   for j in range(n_phys)] for i in range(n_log)])
    row_ind, col_ind = linear_sum_assignment(C)
    return {logical_qubits[r]: phys_nodes[c] for r, c in zip(row_ind, col_ind)}
```

IDEA_NAME: Interaction Entropy Minimization Placement (IEMP)
DESCRIPTION: Define an "interaction entropy" for a placement as H(π) = -Σ_{(q1,q2)} p(q1,q2) × log(d(π(q1), π(q2)) / d_max), where p(q1,q2) is the normalized interaction probability and d(·,·) is hardware distance. A placement that puts all frequently-interacting pairs close together minimizes this entropy. Greedy entropy reduction constructs the mapping one qubit at a time.
ALGORITHMIC_APPROACH:
1. Compute normalized interaction probabilities p(q1,q2) = freq(q1,q2) / Σ freq
2. Initialize: place the highest-degree logical qubit at the hardware node with maximum degree
3. Greedily add one logical qubit at a time: for each unplaced qubit q, for each unoccupied hardware node p, compute the marginal entropy reduction ΔH = -Σ_{already_placed q'} p(q,q') × log(d(p, π(q')))
4. Assign q to the physical node p that maximizes ΔH (minimizes entropy increment)
COLLISION_PREVENTION: Strict greedy construction maintains `placed = set()` of used physical nodes. Each new assignment picks from `unoccupied = all_physical - placed`, guaranteeing no collisions. Only one physical node assigned per logical qubit per iteration.
WHY_NOVEL: Formulating quantum placement as an entropy minimization over the joint distribution of interaction probabilities and hardware distances is novel. It draws on information-theoretic principles (mutual information between circuit structure and hardware geometry) unexploited in prior art.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.25

```python
def iemp_initial_mapping(access, distance_matrix, backend):
    import math
    from collections import defaultdict
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1.0
    total = sum(freq.values()) or 1.0
    prob = {k: v / total for k, v in freq.items()}
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    phys_nodes = list(backend.keys())
    # Start: highest-degree logical qubit at highest-degree hardware node
    lq_degree = defaultdict(int)
    for (q1, q2) in freq:
        lq_degree[q1] += 1; lq_degree[q2] += 1
    start_lq = max(logical_qubits, key=lambda q: lq_degree[q])
    start_pq = max(phys_nodes, key=lambda p: len(backend.get(p, [])))
    mapping_dict = {start_lq: start_pq}
    placed = {start_pq}
    unplaced = [q for q in logical_qubits if q != start_lq]
    d_max = max(distance_matrix[i][j]
                for i in distance_matrix for j in distance_matrix[i]) or 1
    for lq in unplaced:
        best_pq, best_delta = None, float('inf')
        for pq in phys_nodes:
            if pq in placed:
                continue
            delta = 0.0
            for placed_lq, placed_pq in mapping_dict.items():
                key = (min(lq, placed_lq), max(lq, placed_lq))
                p_val = prob.get(key, 0)
                d = distance_matrix.get(pq, {}).get(placed_pq, d_max)
                if p_val > 0 and d > 0:
                    delta += -p_val * math.log(d / d_max + 1e-9)
            if delta < best_delta:
                best_delta, best_pq = delta, pq
        mapping_dict[lq] = best_pq
        placed.add(best_pq)
    return mapping_dict
```

IDEA_NAME: Community Detection + Bipartite Voronoi Matching (CDBVM)
DESCRIPTION: Detect communities in the logical interaction graph using Louvain/Leiden community detection. Simultaneously, partition the hardware topology into Voronoi-like regions by choosing `k` seeds (highest-betweenness hardware nodes) and assigning each hardware node to the region of its nearest seed. Then use bipartite matching (Hungarian) between logical communities and hardware regions, placing each community's qubits within the matched hardware region.
ALGORITHMIC_APPROACH:
1. Build weighted interaction graph, run Louvain community detection → k logical communities C_1, ..., C_k
2. Find k hardware "seeds" = top-k nodes by betweenness centrality in `self.backend`
3. Assign each hardware node to nearest seed via BFS on `distance_matrix` → hardware regions R_1, ..., R_k
4. Build bipartite cost matrix: B[i,j] = sum of interaction frequencies between C_i members and members outside C_i that would be served by region R_j
5. Solve B with Hungarian → match each C_i to R_{sigma(i)}
6. Within each matched pair (C_i, R_{sigma(i)}): sort C_i members by intra-community degree, sort R_{sigma(i)} nodes by intra-region hardware degree, assign in order
COLLISION_PREVENTION: Each hardware node belongs to exactly one region (Voronoi partition). Within each (C_i, R_i) pair, sorted-order bijection. Global `used_physical` set prevents cross-region collisions.
WHY_NOVEL: Prior community-based placement methods partition only the logical graph. CDBVM performs *dual* partitioning of both logical and physical graphs, then uses Hungarian matching at the community level — a two-level hierarchical bijection that no prior work has applied.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.5

```python
# Requires: networkx (pip install networkx) for Louvain community detection
def cdbvm_initial_mapping(access, distance_matrix, backend):
    import networkx as nx
    from collections import defaultdict
    from scipy.optimize import linear_sum_assignment
    import numpy as np
    # Build weighted interaction graph
    G_L = nx.Graph()
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1
    for (q1, q2), w in freq.items():
        G_L.add_edge(q1, q2, weight=w)
    # Community detection
    communities = list(nx.community.louvain_communities(G_L, seed=42))
    k = len(communities)
    # Hardware betweenness centrality seeds
    G_H = nx.Graph(backend)
    bc = nx.betweenness_centrality(G_H)
    seeds = sorted(bc, key=bc.get, reverse=True)[:k]
    # Voronoi partition of hardware
    phys_nodes = list(backend.keys())
    hw_regions = {s: [] for s in seeds}
    for p in phys_nodes:
        nearest_seed = min(seeds,
            key=lambda s: distance_matrix.get(p, {}).get(s, float('inf')))
        hw_regions[nearest_seed].append(p)
    # Bipartite cost matrix between communities and regions
    seed_list = list(seeds)
    C = np.zeros((k, k))
    for i, comm in enumerate(communities):
        for j, seed in enumerate(seed_list):
            # Cost: external interaction frequency that region j can't serve locally
            C[i][j] = sum(freq.get((min(q1,q2), max(q1,q2)), 0)
                          for q1 in comm for q2 in G_L.neighbors(q1) if q2 not in comm)
    row_ind, col_ind = linear_sum_assignment(C)
    # Assign within matched pairs
    mapping_dict, used = {}, set()
    for i, j in zip(row_ind, col_ind):
        comm_members = sorted(communities[i],
                              key=lambda q: G_L.degree(q, weight='weight'), reverse=True)
        region_nodes = sorted(hw_regions[seed_list[j]],
                              key=lambda p: len(backend.get(p, [])), reverse=True)
        for lq, pq in zip(comm_members, region_nodes):
            if pq not in used:
                mapping_dict[lq] = pq
                used.add(pq)
    # Assign any remaining unplaced qubits
    for lq in {q for qs in access.values() for q in qs} - set(mapping_dict):
        pq = min((p for p in phys_nodes if p not in used),
                 key=lambda p: sum(distance_matrix.get(p, {}).get(mapping_dict.get(lq2, p), 0)
                                   for lq2 in mapping_dict))
        mapping_dict[lq] = pq
        used.add(pq)
    return mapping_dict
```

IDEA_NAME: Interaction Frequency Markov Chain Monte Carlo (IFMCMC)
DESCRIPTION: Define a Boltzmann distribution over valid placements (bijections) with energy E(π) = Σ_{(q1,q2)} freq(q1,q2) × distance_matrix[π(q1)][π(q2)]. Sample from this distribution using Metropolis-Hastings MCMC, where each proposal is a random transposition of two logical qubit assignments. Run for N steps with annealing temperature schedule; return the lowest-energy placement visited.
ALGORITHMIC_APPROACH:
1. Start from a seed placement (e.g., SFQA or trivial)
2. Define E(π) = Σ_{(q1,q2)} freq(q1,q2) × distance_matrix[π(q1)][π(q2)]
3. MCMC proposal: randomly select two distinct logical qubits lq1, lq2, swap their physical assignments
4. Compute ΔE efficiently: only recompute terms involving lq1 or lq2
5. Accept: if ΔE ≤ 0 always; else with probability exp(-ΔE / T)
6. Anneal T: T = T_0 × α^step
7. Track and return best placement (lowest E seen across all accepted + rejected states)
COLLISION_PREVENTION: Only transpositions (swaps) are used as proposals — the bijection is invariant under transposition since no qubit can appear twice in the same mapping. The set structure of mapping values is preserved at every step.
WHY_NOVEL: MCMC placement with a physically motivated energy function (weighted distance sum) and efficient incremental energy updates is novel for quantum initial placement. Prior MCMC/SA approaches for quantum circuit use flat interaction models; IFMCMC uses distance-weighted interaction frequencies as a statistically grounded energy landscape.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.0

```python
def ifmcmc_initial_mapping(seed_mapping, access, distance_matrix,
                           n_steps=2000, T0=5.0, alpha=0.997):
    import math, random
    from collections import defaultdict
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1.0
    mapping = dict(seed_mapping)
    logical_qubits = list(mapping.keys())

    def energy(m):
        return sum(f * distance_matrix.get(m[q1], {}).get(m[q2], 0)
                   for (q1, q2), f in freq.items()
                   if q1 in m and q2 in m)

    def delta_energy(m, lq1, lq2):
        # Efficient incremental ΔE for swapping lq1 <-> lq2
        delta = 0.0
        for (q_a, q_b), f in freq.items():
            if lq1 in (q_a, q_b) or lq2 in (q_a, q_b):
                other = q_b if q_a in (lq1, lq2) else q_a
                if other in (lq1, lq2):
                    continue  # Both involved, no change in distance
                p_other = m.get(other)
                if p_other is None:
                    continue
                old_d = distance_matrix.get(m[q_a], {}).get(m[q_b], 0)
                # Simulate swap
                m[lq1], m[lq2] = m[lq2], m[lq1]
                new_d = distance_matrix.get(m[q_a], {}).get(m[q_b], 0)
                m[lq1], m[lq2] = m[lq2], m[lq1]  # revert
                delta += f * (new_d - old_d)
        return delta

    best_mapping = dict(mapping)
    best_energy = energy(mapping)
    T = T0
    for step in range(n_steps):
        lq1, lq2 = random.sample(logical_qubits, 2)
        dE = delta_energy(mapping, lq1, lq2)
        if dE <= 0 or random.random() < math.exp(-dE / max(T, 1e-9)):
            mapping[lq1], mapping[lq2] = mapping[lq2], mapping[lq1]
            if energy(mapping) < best_energy:
                best_energy = energy(mapping)
                best_mapping = dict(mapping)
        T *= alpha
    return best_mapping
```

IDEA_NAME: Interaction Window Temporal Path Alignment (IWTPA)
DESCRIPTION: Partition the circuit DAG into K temporal windows (consecutive layer groups). In each window, identify the "dominant interaction path" — the chain of 2-qubit gates with the highest dependency-weighted interaction frequency. Find a matching hardware path of appropriate length. Align window-dominant paths to hardware paths, then use a greedy BFS wave to fill remaining qubits near their most active window partners.
ALGORITHMIC_APPROACH:
1. Partition gates into K temporal windows by binning `dag_dependencies_count` values into K equal-size buckets
2. Per window: build interaction graph, find heaviest-weight Hamiltonian path approximation (greedy nearest-neighbor starting from max-degree node)
3. Find a hardware path of matching length via BFS from each hardware node, score by total edge degree
4. Use greedy matching: align window-1 dominant path to the best hardware path, window-2 to a connected extension, etc.
5. Remaining qubits: BFS from already-placed qubits, assign to nearest unoccupied hardware neighbors weighted by interaction frequency with already-placed qubits
COLLISION_PREVENTION: Path alignment assigns distinct hardware nodes (paths are node-simple). BFS fill uses `used_physical` set. If no hardware path of matching length exists, the path is truncated and remaining logical qubits fall through to global BFS fill.
WHY_NOVEL: Temporal windowing of the circuit into interaction phases, combined with path-to-path hardware alignment, is unexplored. The key insight is that routing overhead compounds across time windows — aligning each window's dominant interaction chain to a hardware path independently prevents SWAP cascade accumulation.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 8
AVERAGE_SCORE: 7.25

```python
def iwtpa_initial_mapping(access, dag_dependencies_count, distance_matrix, backend, K=3):
    from collections import defaultdict, deque
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1.0
    # Partition gates into K windows by dep count
    dep_vals = sorted(set(dag_dependencies_count.values()))
    window_size = max(len(dep_vals) // K, 1)
    def get_window(gate):
        d = dag_dependencies_count.get(gate, 0)
        return dep_vals.index(d) // window_size if d in dep_vals else 0
    window_freq = [defaultdict(float) for _ in range(K)]
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            w = get_window(gate)
            if w < K:
                window_freq[w][(min(q1,q2), max(q1,q2))] += 1.0
    # Per window: greedy path through interaction graph
    def greedy_path(wf):
        node_deg = defaultdict(float)
        for (q1, q2), w in wf.items():
            node_deg[q1] += w; node_deg[q2] += w
        if not node_deg:
            return []
        start = max(node_deg, key=node_deg.get)
        path, visited = [start], {start}
        while True:
            last = path[-1]
            neighbors = [(q2 if q1 == last else q1, w)
                         for (q1, q2), w in wf.items() if last in (q1, q2)]
            unvisited = [(q, w) for q, w in neighbors if q not in visited]
            if not unvisited:
                break
            nxt = max(unvisited, key=lambda x: x[1])[0]
            path.append(nxt); visited.add(nxt)
        return path
    # Hardware path finder via BFS
    def hw_path_of_length(start_pq, length, used):
        path = [start_pq]
        visited = {start_pq}
        while len(path) < length:
            last = path[-1]
            candidates = [nb for nb in backend.get(last, [])
                          if nb not in visited and nb not in used]
            if not candidates:
                break
            path.append(candidates[0]); visited.add(candidates[0])
        return path
    mapping_dict, used = {}, set()
    phys_nodes = sorted(backend.keys(), key=lambda p: len(backend.get(p, [])), reverse=True)
    anchor_pq = phys_nodes[0]
    for w in range(K):
        log_path = greedy_path(window_freq[w])
        hw_path = hw_path_of_length(anchor_pq, len(log_path), used)
        for lq, pq in zip(log_path, hw_path):
            if lq not in mapping_dict and pq not in used:
                mapping_dict[lq] = pq; used.add(pq)
        if hw_path:
            anchor_pq = hw_path[-1]
    # BFS fill remaining
    for lq in sorted({q for qs in access.values() for q in qs} - set(mapping_dict),
                     key=lambda q: sum(freq.get((min(q, p), max(q, p)), 0)
                                       for p in mapping_dict)):
        partners = [mapping_dict[p] for p in mapping_dict
                    if freq.get((min(lq,p), max(lq,p)), 0) > 0]
        pq = min((p for p in phys_nodes if p not in used),
                 key=lambda p: min((distance_matrix.get(p, {}).get(a, 999)
                                    for a in partners), default=0))
        mapping_dict[lq] = pq; used.add(pq)
    return mapping_dict
```

IDEA_NAME: Fused Spectral-Seed + Routing-Local-Search (FSSRLS)
DESCRIPTION: A two-phase hybrid. Phase 1: Use SFQA (Spectral Fiedler Alignment) as a warm start — it provides a globally structure-aware placement in O(n² log n). Phase 2: Apply a fast local search that reuses the existing Qlosure heuristic machinery (distance_matrix, extended_layer logic) but in *placement space* rather than routing space — iteratively testing transpositions of qubit pairs and accepting if the expected front-layer routing cost decreases.
ALGORITHMIC_APPROACH:
1. Phase 1: Run SFQA to get initial mapping π_0
2. Phase 2: For max_iters iterations:
   a. Compute front-layer score: S(π) = Σ_{g ∈ front_layer} (dep_count[g]+1) × dist(π(q1(g)), π(q2(g)))
   b. For each candidate transposition (lq1, lq2): compute ΔS using only terms involving lq1 or lq2 (O(|front_layer|) per candidate)
   c. Accept transposition if ΔS < 0 (pure greedy hill-climbing)
3. Stop when no improving transposition exists or max_iters reached
COLLISION_PREVENTION: All moves are transpositions on `mapping_dict` — bijection invariant. Initial SFQA already produces a bijection. Local search only swaps existing entries, never creates or deletes them.
WHY_NOVEL: Combines the global structure of spectral alignment with a routing-cost-aware local search that directly minimizes the Qlosure heuristic's front-layer scoring function — the same function used during routing. This creates a placement that is specifically optimized for the subsequent routing algorithm, not just for generic circuit structure.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 9
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.75

```python
def fssrls_initial_mapping(access, access2q, dag_dependencies_count,
                           distance_matrix, backend, front_layer,
                           max_iters=200):
    # Phase 1: SFQA warm start (inline simplified version)
    import numpy as np
    from collections import defaultdict
    freq = defaultdict(float)
    for gate, qubits in access.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            freq[(min(q1,q2), max(q1,q2))] += 1.0
    logical_qubits = sorted({q for qs in access.values() for q in qs})
    phys_nodes = sorted(backend.keys())
    n_log, n_phys = len(logical_qubits), len(phys_nodes)
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    # Build Laplacians and Fiedler vectors
    A_L = np.zeros((n_log, n_log))
    for (q1, q2), w in freq.items():
        if q1 in lq_idx and q2 in lq_idx:
            A_L[lq_idx[q1]][lq_idx[q2]] = A_L[lq_idx[q2]][lq_idx[q1]] = w
    L_L = np.diag(A_L.sum(1)) - A_L
    pi = {p: i for i, p in enumerate(phys_nodes)}
    A_H = np.zeros((n_phys, n_phys))
    for p, nbs in backend.items():
        for nb in nbs:
            A_H[pi[p]][pi[nb]] = 1
    L_H = np.diag(A_H.sum(1)) - A_H
    _, V_L = np.linalg.eigh(L_L)
    fiedler_L = V_L[:, min(1, n_log-1)]
    _, V_H = np.linalg.eigh(L_H)
    fiedler_H = V_H[:, min(1, n_phys-1)]
    sorted_lq = [logical_qubits[i] for i in np.argsort(fiedler_L)]
    sorted_pq = [phys_nodes[i] for i in np.argsort(fiedler_H)]
    mapping = {lq: sorted_pq[i] for i, lq in enumerate(sorted_lq)}
    # Phase 2: Routing-cost local search using front_layer
    def front_score(m):
        return sum((dag_dependencies_count.get(g, 0) + 1) *
                   distance_matrix.get(m[q1], {}).get(m[q2], 0)
                   for g in front_layer
                   for q1, q2 in [access2q.get(g, (None, None))]
                   if q1 in m and q2 in m)
    for _ in range(max_iters):
        improved = False
        lq_list = list(mapping.keys())
        for i in range(len(lq_list)):
            for j in range(i+1, len(lq_list)):
                lq1, lq2 = lq_list[i], lq_list[j]
                old_score = front_score(mapping)
                mapping[lq1], mapping[lq2] = mapping[lq2], mapping[lq1]
                if front_score(mapping) < old_score:
                    improved = True
                else:
                    mapping[lq1], mapping[lq2] = mapping[lq2], mapping[lq1]
        if not improved:
            break
    return mapping
```
