**SFQA `init_mapping` — Design Overview**

**Step 1 — Logical interaction graph**
Scans all 2-qubit gates in `self.access`, accumulating edge weights (interaction frequency) between logical qubit pairs into a weighted Laplacian matrix `L_logical` of size `n_logical × n_logical`.

**Step 2 — Hardware topology graph**
Iterates `self.backend` adjacency list (deduplicating undirected edges) to build the unweighted Laplacian `L_physical` of size `n_physical × n_physical`.

**Step 3 — Fiedler vectors**
Calls `np.linalg.eigh` (symmetric eigendecomposition, O(n³), cheap for ≤ 200 qubits) on each Laplacian. The second eigenvector (index 1 in ascending-eigenvalue order) is the Fiedler vector — a 1-D spectral embedding of each graph's geometry. Falls back to index-based order on numerical failure.

**Step 4 — Spectral alignment**
Both node lists are sorted by Fiedler value. Logical qubit at spectral rank `k` is assigned to the physical qubit at rank `round(k × (n_physical−1) / (n_logical−1))` — a proportional projection that aligns both spectral extremes regardless of size difference, guaranteeing no two logical qubits map to the same physical qubit.

**Step 5 — Bijection enforcement**
Starts from the identity permutation and applies each spectral assignment via an in-place swap of `mapping_dict`/`reverse_mapping_dict`, displacing the current occupant. This is the same pattern already used in the codebase and guarantees a strict 1-to-1 mapping over all `num_qubits` indices.
