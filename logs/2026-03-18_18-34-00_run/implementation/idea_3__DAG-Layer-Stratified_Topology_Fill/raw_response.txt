```python
def init_mapping(self):
    """
    DAG-Layer-Stratified Topology Fill (DLSTF).

    Aligns circuit temporal activation order with hardware BFS depth:
    early-critical qubits land near the hardware core, late-activating
    qubits sit on the periphery where SWAP overhead matters less.

    Steps:
      1. Compute earliest_layer[q] = DAG layer of first 2-qubit gate for q
         (lightweight simulation on sorted gate schedule).
      2. Sort logical qubits by earliest_layer asc; ties by 2q-gate count desc.
      3. BFS on hardware from the highest-degree physical qubit -> hw_order.
      4. Zip sorted logical qubits with hw_order[:n_logical].
      5. Encode assignment as a strict bijection over all num_qubits indices.
    """
    from collections import defaultdict, deque

    # --- Collect logical qubits and 2q-gate counts ---
    logical_qubit_set = set()
    two_qubit_count = defaultdict(int)

    for gate, qubits in self.access.items():
        for q in qubits:
            logical_qubit_set.add(q)
        if len(qubits) == 2:
            two_qubit_count[qubits[0]] += 1
            two_qubit_count[qubits[1]] += 1

    logical_qubits = sorted(logical_qubit_set)
    physical_qubits = sorted(self.backend.keys())

    # Fallback to identity mapping when circuit has no gates
    if not logical_qubits or not physical_qubits:
        self.mapping_dict = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # --- Step 1: Compute earliest_layer[q] via per-qubit frontier simulation ---
    # Process gates in sorted-key order (same topological order as DAG.schedule).
    # qubit_frontier[q] tracks the current DAG depth frontier for qubit q.
    schedule = sorted(self.access.keys())
    qubit_frontier = defaultdict(int)
    earliest_layer = {}

    for gate in schedule:
        qubits = self.access[gate]
        if not qubits:
            continue
        gate_layer = max(qubit_frontier[q] for q in qubits) + 1
        for q in qubits:
            qubit_frontier[q] = gate_layer
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            if q1 not in earliest_layer:
                earliest_layer[q1] = gate_layer
            if q2 not in earliest_layer:
                earliest_layer[q2] = gate_layer

    # Qubits that never appear in a 2-qubit gate are pushed to the periphery
    max_layer = max(qubit_frontier.values()) if qubit_frontier else 0
    for q in logical_qubits:
        if q not in earliest_layer:
            earliest_layer[q] = max_layer + 1

    # --- Step 2: Sort logical qubits ---
    # Primary: earliest_layer ascending (most time-critical qubits first)
    # Tiebreak: 2q-gate count descending (busiest qubit placed closer to core)
    sorted_logical = sorted(
        logical_qubits,
        key=lambda q: (earliest_layer[q], -two_qubit_count[q])
    )

    # --- Step 3: BFS on hardware graph from highest-degree seed ---
    seed_phys = max(physical_qubits, key=lambda p: len(self.backend[p]))
    hw_order = []
    visited = set([seed_phys])
    bfs_queue = deque([seed_phys])

    while bfs_queue:
        p = bfs_queue.popleft()
        hw_order.append(p)
        for nb in sorted(self.backend[p]):  # sort for determinism
            if nb not in visited:
                visited.add(nb)
                bfs_queue.append(nb)

    # Append any disconnected physical qubits (disjoint hardware components)
    for p in physical_qubits:
        if p not in visited:
            hw_order.append(p)

    # --- Step 4: Zip sorted logical qubits with BFS-ordered hardware ---
    lq_to_phys = {}
    for i, lq in enumerate(sorted_logical):
        lq_to_phys[lq] = hw_order[i]

    # --- Step 5: Encode as strict bijection via in-place swap ---
    # Start from identity permutation; apply each target assignment by
    # displacing the current occupant of the target physical slot.
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys:
            continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq

    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

---

**Design decisions and why they work:**

**Step 1 — Per-qubit frontier DAG simulation**  
`init_mapping` runs before `generate_dag`, so a full DAG isn't available. Instead, the code processes gates in sorted key order (matching `DAG.schedule`) and maintains `qubit_frontier[q]` = current depth of qubit `q`. Each gate's layer is `max(frontier over its qubits) + 1`. This is O(G) and correctly captures the precedence structure induced by qubit reuse.

**Step 2 — Sort key**  
`(earliest_layer[q], -two_qubit_count[q])` places the most urgent qubits first. A qubit with `earliest_layer=1` needs hardware adjacency with its partner from the very first scheduling wave; misplacing it causes SWAPs before any gate executes. Qubits that only appear in single-qubit gates (or never) get `max_layer + 1` and land at BFS leaves, where hardware distance is irrelevant.

**Step 3 — Hardware BFS from highest-degree seed**  
The highest-degree node is the most connected hub. BFS from there visits qubits in order of increasing hardware distance from the core, mirroring the stratum structure described in the idea.

**Step 4 — Zip assignment**  
Positional zip is O(n_logical). Collision is structurally impossible: `hw_order` lists each physical qubit exactly once, so assignment is injective by construction.

**Step 5 — Bijection via swap**  
The identity permutation is updated by a sequence of in-place swaps, identical to the pattern already used in the existing codebase. Correctness follows because each swap maintains the invariant that `mapping_dict` and `reverse_mapping_dict` are mutual inverses over all `num_qubits` indices.
