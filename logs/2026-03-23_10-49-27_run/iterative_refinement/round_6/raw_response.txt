## Critical Analysis of CSIWM-LS

**Strengths:** Good centroid seeding, critical path detection, greedy BFS expansion, and local search refinement.

**Key weaknesses I'll target:**
1. **Binary criticality**: Qubits are either "critical" (4x) or not (1x) — ignores the criticality gradient
2. **Inconsistent weights in local search**: Uses raw `interaction_neighbors` but greedy uses `enhanced` — local search refines against the wrong objective
3. **No relocation moves**: Local search only swaps occupied positions, ignoring potentially better unoccupied physical slots
4. **Single-start greedy**: One seed combination may land in a poor local optimum

## Evolution Strategy: Option A (Targeted Refinements)

Four concrete improvements: (1) graduated criticality scaling, (2) consistent `enhanced` weights in local search, (3) relocation moves for unoccupied physical slots, (4) multi-start with best-of-k selection.

```python
def init_mapping(self):
    """
    Multi-Seed Graduated-Criticality Mapping with Relocation Local Search (MSGCM-RLS)

    Key improvements over CSIWM-LS:
      1. Graduated criticality: per-qubit score based on near-critical gate depth
         ratio, not binary critical/non-critical. Pairs receive a continuous bonus
         1 + (MAX_BONUS-1) * avg_criticality instead of a hard 4x step.
      2. Consistent weights: local search uses enhanced weights (same objective as
         greedy phase), fixing the inconsistency in the previous heuristic.
      3. Relocation moves: alongside pairwise swaps, local search tries moving each
         logical qubit to unoccupied physical positions, which is impossible for
         pure swap-only search.
      4. Multi-start: top-K logical seeds x top-K physical centroids are tried;
         the best result after local search is kept.
    """
    from collections import defaultdict, deque

    # ------------------------------------------------------------------ #
    # 1. Build interaction graph                                           #
    # ------------------------------------------------------------------ #
    logical_qubit_set = set()
    interaction_neighbors = defaultdict(dict)

    for gate, qubits in self.access.items():
        for q in qubits:
            logical_qubit_set.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            w = interaction_neighbors[q1].get(q2, 0) + 1
            interaction_neighbors[q1][q2] = w
            interaction_neighbors[q2][q1] = w

    logical_qubits = sorted(logical_qubit_set)
    physical_qubits = sorted(self.backend.keys())

    if not logical_qubits:
        self.mapping_dict = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # ------------------------------------------------------------------ #
    # 2. Graduated criticality via DP on 2Q gate DAG                      #
    #    Each qubit gets a score in [0,1] based on depth ratio of the      #
    #    deepest near-critical gate it participates in.                    #
    # ------------------------------------------------------------------ #
    two_qubit_gates = {g: q for g, q in self.access.items() if len(q) == 2}
    qubit_criticality = defaultdict(float)

    if two_qubit_gates:
        sorted_2q = sorted(two_qubit_gates.keys())
        last_gate_on_qubit = {}
        dag_succ = defaultdict(set)
        dag_pred = defaultdict(set)

        for gate in sorted_2q:
            q1, q2 = two_qubit_gates[gate]
            for q in (q1, q2):
                if q in last_gate_on_qubit:
                    pred = last_gate_on_qubit[q]
                    dag_succ[pred].add(gate)
                    dag_pred[gate].add(pred)
            last_gate_on_qubit[q1] = gate
            last_gate_on_qubit[q2] = gate

        in_deg  = {g: len(dag_pred[g]) for g in sorted_2q}
        dp_len  = {g: 1 for g in sorted_2q}
        dp_prev = {g: None for g in sorted_2q}
        topo_q  = deque(g for g in sorted_2q if in_deg[g] == 0)

        while topo_q:
            node = topo_q.popleft()
            for succ in dag_succ[node]:
                if dp_len[node] + 1 > dp_len[succ]:
                    dp_len[succ] = dp_len[node] + 1
                    dp_prev[succ] = node
                in_deg[succ] -= 1
                if in_deg[succ] == 0:
                    topo_q.append(succ)

        cp_len = max(dp_len.values()) if dp_len else 1
        threshold = max(1, cp_len * 0.85)  # near-critical window

        # Score each qubit by the max depth-ratio among its near-critical gates
        for g in sorted_2q:
            if dp_len[g] >= threshold:
                depth_ratio = dp_len[g] / cp_len
                for q in two_qubit_gates[g]:
                    qubit_criticality[q] = max(qubit_criticality[q], depth_ratio)

        # Guarantee exact critical-path qubits score exactly 1.0
        node = max(sorted_2q, key=lambda g: dp_len[g])
        while node is not None:
            for q in two_qubit_gates[node]:
                qubit_criticality[q] = 1.0
            node = dp_prev[node]

    # ------------------------------------------------------------------ #
    # 3. Enhanced interaction weights with graduated criticality bonus     #
    #    bonus = 1 + (MAX_BONUS-1) * mean(c1, c2)                        #
    # ------------------------------------------------------------------ #
    MAX_BONUS = 5.0
    enhanced = defaultdict(dict)
    for q1 in interaction_neighbors:
        for q2, w in interaction_neighbors[q1].items():
            c1 = qubit_criticality.get(q1, 0.0)
            c2 = qubit_criticality.get(q2, 0.0)
            bonus = 1.0 + (MAX_BONUS - 1.0) * (c1 + c2) * 0.5
            enhanced[q1][q2] = w * bonus

    # ------------------------------------------------------------------ #
    # 4. Hardware seed candidates: K most central physical nodes           #
    # ------------------------------------------------------------------ #
    hw_sum_dist = {
        p: sum(
            self.distance_matrix[p][o]
            for o in physical_qubits
            if self.distance_matrix[p][o] != float('inf')
        )
        for p in physical_qubits
    }
    K_PHYS = min(3, len(physical_qubits))
    top_phys_seeds = sorted(physical_qubits, key=lambda p: hw_sum_dist[p])[:K_PHYS]

    # Logical seed candidates: highest enhanced degree
    enhanced_deg = {lq: sum(enhanced[lq].values()) for lq in logical_qubits}
    K_LQ = min(3, len(logical_qubits))
    top_lq_seeds = sorted(logical_qubits, key=lambda lq: -enhanced_deg[lq])[:K_LQ]

    # ------------------------------------------------------------------ #
    # 5. Total weighted distance (objective function)                      #
    # ------------------------------------------------------------------ #
    def total_cost(lq_to_phys):
        total = 0.0
        seen = set()
        for q1, q2_dict in enhanced.items():
            if q1 not in lq_to_phys:
                continue
            for q2, w in q2_dict.items():
                if q2 not in lq_to_phys:
                    continue
                pair = (min(q1, q2), max(q1, q2))
                if pair in seen:
                    continue
                seen.add(pair)
                d = self.distance_matrix[lq_to_phys[q1]][lq_to_phys[q2]]
                total += w * (d if d != float('inf') else 1e9)
        return total

    # ------------------------------------------------------------------ #
    # 6. Greedy BFS expansion                                              #
    # ------------------------------------------------------------------ #
    def greedy_expand(anchor_lq, anchor_phys):
        lq_to_phys = {anchor_lq: anchor_phys}
        placed_phys = {anchor_phys}
        unplaced = [lq for lq in logical_qubits if lq != anchor_lq]

        while unplaced:
            next_lq = max(
                unplaced,
                key=lambda lq: sum(enhanced[lq].get(p_lq, 0) for p_lq in lq_to_phys)
            )

            candidates = list({
                nb
                for phys in placed_phys
                for nb in self.backend[phys]
                if nb not in placed_phys
            })
            if not candidates:
                candidates = [p for p in physical_qubits if p not in placed_phys]
            if not candidates:
                break

            best_phys = min(
                candidates,
                key=lambda phys_c: sum(
                    enhanced[next_lq].get(p_lq, 0) * (
                        self.distance_matrix[phys_c][p_phys]
                        if self.distance_matrix[phys_c][p_phys] != float('inf')
                        else 1e9
                    )
                    for p_lq, p_phys in lq_to_phys.items()
                    if enhanced[next_lq].get(p_lq, 0) > 0
                )
            )

            lq_to_phys[next_lq] = best_phys
            placed_phys.add(best_phys)
            unplaced.remove(next_lq)

        return lq_to_phys

    # ------------------------------------------------------------------ #
    # 7. Local search: pairwise swap + relocation to unoccupied slots     #
    #    Both phases use enhanced weights (consistent with greedy).        #
    # ------------------------------------------------------------------ #
    def local_search(lq_to_phys):
        lq_list = [lq for lq in logical_qubits if lq in lq_to_phys]
        occupied = set(lq_to_phys.values())
        unoccupied = [p for p in physical_qubits if p not in occupied]
        n = len(lq_list)

        for _pass in range(20):
            improved = False

            # --- Pairwise swap moves (enhanced weights) ---
            for i in range(n):
                for j in range(i + 1, n):
                    lq1, lq2 = lq_list[i], lq_list[j]
                    p1, p2 = lq_to_phys[lq1], lq_to_phys[lq2]
                    delta = 0.0

                    for lq3, w in enhanced[lq1].items():
                        if lq3 not in lq_to_phys or lq3 == lq2:
                            continue
                        p3 = lq_to_phys[lq3]
                        d_old = self.distance_matrix[p1][p3]
                        d_new = self.distance_matrix[p2][p3]
                        delta += w * (
                            (d_new if d_new != float('inf') else 1e9) -
                            (d_old if d_old != float('inf') else 1e9)
                        )

                    for lq3, w in enhanced[lq2].items():
                        if lq3 not in lq_to_phys or lq3 == lq1:
                            continue
                        p3 = lq_to_phys[lq3]
                        d_old = self.distance_matrix[p2][p3]
                        d_new = self.distance_matrix[p1][p3]
                        delta += w * (
                            (d_new if d_new != float('inf') else 1e9) -
                            (d_old if d_old != float('inf') else 1e9)
                        )

                    if delta < -1e-9:
                        lq_to_phys[lq1], lq_to_phys[lq2] = p2, p1
                        improved = True

            # --- Relocation moves: move lq to a better unoccupied slot ---
            if unoccupied:
                for lq in lq_list:
                    p_old = lq_to_phys[lq]
                    best_delta = -1e-9
                    best_p_new = None

                    for p_new in unoccupied:
                        delta = 0.0
                        for lq2, w in enhanced[lq].items():
                            if lq2 not in lq_to_phys:
                                continue
                            p2 = lq_to_phys[lq2]
                            d_old = self.distance_matrix[p_old][p2]
                            d_new = self.distance_matrix[p_new][p2]
                            delta += w * (
                                (d_new if d_new != float('inf') else 1e9) -
                                (d_old if d_old != float('inf') else 1e9)
                            )
                        if delta < best_delta:
                            best_delta = delta
                            best_p_new = p_new

                    if best_p_new is not None:
                        lq_to_phys[lq] = best_p_new
                        unoccupied.remove(best_p_new)
                        unoccupied.append(p_old)
                        improved = True

            if not improved:
                break

        return lq_to_phys

    # ------------------------------------------------------------------ #
    # 8. Multi-start: try top-K_LQ x top-K_PHYS seeds, keep best         #
    # ------------------------------------------------------------------ #
    best_mapping = None
    best_score = float('inf')

    for anchor_lq in top_lq_seeds:
        for anchor_phys in top_phys_seeds:
            lq_to_phys = greedy_expand(anchor_lq, anchor_phys)
            lq_to_phys = local_search(lq_to_phys)
            score = total_cost(lq_to_phys)
            if score < best_score:
                best_score = score
                best_mapping = dict(lq_to_phys)

    lq_to_phys = best_mapping

    # ------------------------------------------------------------------ #
    # 9. Build strict 1-to-1 bijection via in-place swap                  #
    # ------------------------------------------------------------------ #
    mapping_dict         = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys:
            continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq]                   = target_phys
        mapping_dict[displaced_lq]         = current_phys
        reverse_mapping_dict[target_phys]  = lq
        reverse_mapping_dict[current_phys] = displaced_lq

    self.mapping_dict         = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

**Summary of changes vs. CSIWM-LS:**

| Aspect | CSIWM-LS | This version |
|---|---|---|
| Criticality model | Binary (critical / not) → 4x step | Graduated score ∈ [0,1] → continuous bonus up to 5x |
| Local search weights | Raw `interaction_neighbors` | `enhanced` (same as greedy) |
| Local search moves | Swap only | Swap + relocation to unoccupied physical nodes |
| Starting points | 1 (centroid + top-degree) | Up to 9 (3 logical × 3 physical seeds), best kept |
