## Analysis of Current Best (MBLP)

**Strengths:** Layer-weighted interaction graph, centrality-based anchor, BFS expansion with overlap scoring.

**Key weaknesses:**
1. **No post-placement refinement** — greedy BFS locks in locally optimal decisions that create globally suboptimal configurations
2. **Rank-based weighting** (`1/(rank+1)`) doesn't reflect true parallelism structure; gates in the same parallel layer get different weights based on sort order
3. **No Quadratic Assignment Problem (QAP) objective** — the cost function `Σ weight(q1,q2) × dist(p1,p2)` is never explicitly minimized

## Evolution Strategy: Option A (Refine)

The most impactful addition is a **2-opt QAP local search refinement phase** after the greedy placement. This iteratively swaps pairs of logical qubits' physical assignments whenever it reduces the total weighted interaction distance. Combined with **proper circuit layer decomposition** for more accurate temporal weighting, this should yield meaningful improvement.

```python
def init_mapping(self):
    """
    Layer-Aware Circuit Embedding with QAP Local Search Refinement (LACE-QAP).

    Key improvements over MBLP:
      1. Gate-layer decomposition: gates in the same parallel layer receive
         identical temporal weight 1/(layer+1), avoiding artefacts from
         sort-order within a layer.
      2. Degree-aware greedy placement: physical qubits whose connectivity
         degree resembles the logical qubit's interaction degree are preferred.
      3. QAP 2-opt local search: after the initial greedy placement, iteratively
         swap pairs of logical qubits' physical assignments whenever the swap
         reduces the total weighted interaction distance
             cost = Σ_{(q1,q2)} mb_weight[q1][q2] × dist(phys(q1), phys(q2))
         Repeat until convergence or max_iter reached.
    """
    import heapq
    from collections import defaultdict

    # ------------------------------------------------------------------ #
    # Collect logical qubits                                              #
    # ------------------------------------------------------------------ #
    logical_qubit_set = set()
    for qubits in self.access.values():
        for q in qubits:
            logical_qubit_set.add(q)

    logical_qubits  = sorted(logical_qubit_set)
    physical_qubits = sorted(self.backend.keys())

    if not logical_qubits:
        self.mapping_dict         = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # ------------------------------------------------------------------ #
    # Step 1 – Gate-layer decomposition for accurate temporal weighting   #
    # Gates that can execute in parallel share the same layer index.      #
    # Weight = 1/(layer+1): earlier layers carry higher weight since      #
    # they constitute the most constrained scheduling bottleneck.         #
    # ------------------------------------------------------------------ #
    sorted_gates = sorted(self.access.keys())

    qubit_next_layer = defaultdict(int)
    gate_layer = {}
    for gate in sorted_gates:
        qubits = self.access[gate]
        layer = max(qubit_next_layer[q] for q in qubits)
        gate_layer[gate] = layer
        for q in qubits:
            qubit_next_layer[q] = layer + 1

    mb_weight = defaultdict(lambda: defaultdict(float))
    for gate in sorted_gates:
        qubits = self.access[gate]
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            w = 1.0 / (gate_layer[gate] + 1)
            mb_weight[q1][q2] += w
            mb_weight[q2][q1] += w

    # ------------------------------------------------------------------ #
    # Step 2 – Graph property computation                                 #
    # ------------------------------------------------------------------ #
    mb_total   = {q: sum(mb_weight[q].values()) for q in logical_qubits}
    phys_degree = {p: len(self.backend[p])      for p in physical_qubits}
    lq_degree   = {q: len(mb_weight[q])         for q in logical_qubits}

    def _mean_dist(p):
        vals = [
            self.distance_matrix[p][o]
            for o in physical_qubits
            if o != p and self.distance_matrix[p][o] != float('inf')
        ]
        return sum(vals) / len(vals) if vals else float('inf')

    phys_centrality = {p: _mean_dist(p) for p in physical_qubits}

    # ------------------------------------------------------------------ #
    # Step 3 – Anchor: highest-MB-weight logical → most central physical  #
    # ------------------------------------------------------------------ #
    anchor_physical = min(physical_qubits, key=lambda p: phys_centrality[p])
    anchor_logical  = max(logical_qubits,  key=lambda q: mb_total[q])

    lq_to_phys  = {anchor_logical: anchor_physical}
    placed_phys = {anchor_physical}

    # ------------------------------------------------------------------ #
    # Step 4 – Greedy BFS expansion with degree-aware scoring             #
    # score(p, lq) = MB-overlap + small degree-match bonus               #
    # ------------------------------------------------------------------ #
    heap    = []
    counter = 0
    for nb_lq, w in mb_weight[anchor_logical].items():
        heapq.heappush(heap, (-w, counter, nb_lq))
        counter += 1

    while heap:
        _, _, lq = heapq.heappop(heap)
        if lq in lq_to_phys:
            continue

        ld = lq_degree.get(lq, 0)
        best_phys  = None
        best_score = (-float('inf'), -1)

        for p in physical_qubits:
            if p in placed_phys:
                continue

            overlap = 0.0
            for nb_lq2, w in mb_weight[lq].items():
                if nb_lq2 in lq_to_phys:
                    d = self.distance_matrix[p][lq_to_phys[nb_lq2]]
                    overlap += w / (d + 1)

            # Degree-match bonus: prefer physical qubits whose degree
            # is close to the logical qubit's interaction degree.
            degree_bonus = -abs(ld - phys_degree[p]) * 0.05

            score = (overlap + degree_bonus, phys_degree[p])
            if score > best_score:
                best_score = score
                best_phys  = p

        if best_phys is None:
            break

        lq_to_phys[lq] = best_phys
        placed_phys.add(best_phys)

        for nb_lq2, w in mb_weight[lq].items():
            if nb_lq2 not in lq_to_phys:
                heapq.heappush(heap, (-w, counter, nb_lq2))
                counter += 1

    # ------------------------------------------------------------------ #
    # Step 5 – Isolated qubits fill remaining slots by hw degree desc     #
    # ------------------------------------------------------------------ #
    remaining_phys = sorted(
        [p for p in physical_qubits if p not in placed_phys],
        key=lambda p: phys_degree[p],
        reverse=True,
    )
    for lq, p in zip([q for q in logical_qubits if q not in lq_to_phys], remaining_phys):
        lq_to_phys[lq] = p

    # ------------------------------------------------------------------ #
    # Step 6 – Build valid 1-to-1 mapping via in-place displacement       #
    # ------------------------------------------------------------------ #
    mapping_dict         = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys:
            continue
        displaced_lq                        = reverse_mapping_dict[target_phys]
        mapping_dict[lq]                    = target_phys
        mapping_dict[displaced_lq]          = current_phys
        reverse_mapping_dict[target_phys]   = lq
        reverse_mapping_dict[current_phys]  = displaced_lq

    # ------------------------------------------------------------------ #
    # Step 7 – QAP 2-opt local search refinement                         #
    #                                                                     #
    # Objective: minimise Σ mb_weight[q1][q2] × dist(phys(q1), phys(q2)) #
    #                                                                     #
    # For each pair (lq1, lq2) of logical qubits, compute the delta cost #
    # of swapping their physical assignments. Apply immediately if delta  #
    # < 0. Repeat outer while-loop until stable.                         #
    #                                                                     #
    # Delta computation exploits the fact that only edges incident to     #
    # lq1 or lq2 change cost; the lq1-lq2 edge itself is invariant       #
    # (dist(p1,p2) = dist(p2,p1)).                                       #
    # ------------------------------------------------------------------ #
    lq_list = list(logical_qubits)
    n_lq    = len(lq_list)

    improved = True
    max_iter = 20

    while improved and max_iter > 0:
        improved = False
        max_iter -= 1

        for i in range(n_lq):
            lq1 = lq_list[i]
            p1  = mapping_dict[lq1]

            for j in range(i + 1, n_lq):
                lq2 = lq_list[j]
                p2  = mapping_dict[lq2]

                # Edges from lq1 to neighbours other than lq2
                delta = 0.0
                for nb, w in mb_weight[lq1].items():
                    if nb == lq2:
                        continue          # lq1↔lq2 edge: dist unchanged
                    nb_p = mapping_dict[nb]
                    delta += w * (self.distance_matrix[p2][nb_p]
                                - self.distance_matrix[p1][nb_p])

                # Edges from lq2 to neighbours other than lq1
                for nb, w in mb_weight[lq2].items():
                    if nb == lq1:
                        continue
                    nb_p = mapping_dict[nb]
                    delta += w * (self.distance_matrix[p1][nb_p]
                                - self.distance_matrix[p2][nb_p])

                if delta < -1e-9:
                    # Apply swap in-place
                    mapping_dict[lq1]         = p2
                    mapping_dict[lq2]         = p1
                    reverse_mapping_dict[p1]  = lq2
                    reverse_mapping_dict[p2]  = lq1
                    # lq1's new physical position is old p2
                    p1 = p2
                    improved = True

    self.mapping_dict         = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

**Summary of changes:**

| Component | MBLP | LACE-QAP |
|---|---|---|
| Temporal weight | `1/(gate_rank+1)` — sort-order dependent | `1/(layer+1)` — reflects true parallelism |
| Placement tie-break | hardware degree only | hardware degree + degree-match bonus |
| Post-placement refinement | **none** | **QAP 2-opt local search** (converges in ~3-5 iterations typically) |

The local search is the dominant improvement: it directly minimizes the weighted distance objective and can correct any locally-greedy mistake the BFS made, at O(n²) cost per iteration.
