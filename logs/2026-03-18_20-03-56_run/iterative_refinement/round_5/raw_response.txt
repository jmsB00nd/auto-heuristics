**Critical Analysis of CPMR-3OLS:**

**Strengths:**
- True DAG critical path (fwd + bwd depth)
- 3-way cyclic permutations in local search
- Smart anchor orientation

**Key Weaknesses:**
1. **Weight formula is "smeared"**: `1.0 + 0.5*fwd_norm + 0.5*bwd_norm` normalizes both fwd and bwd by `max_fwd` — so early and late gates get similar boosts. It doesn't strongly differentiate *when* a gate executes
2. **Deterministic local search**: 3-opt always converges to the same local optimum from the same start — no escape mechanism
3. **Only 6 restarts** (3 edges × 2 pairs) — very limited exploration
4. **3-opt on only top-20 qubits**: misses interaction patterns in lower-weight qubits

**Evolution Strategy: Option A (Targeted Refinement)**

Key innovations:
1. **Layer-based exponential temporal decay** instead of normalized critical path — gates in circuit layer 0 are weighted ~10× more than layer 10+, accurately reflecting routing urgency
2. **Simulated Annealing** replacing deterministic 3-opt — accepts worse solutions probabilistically to escape local optima, with adaptive temperature calibrated to problem scale  
3. **Two-phase multi-restart**: greedy on 30 configs → SA refinement on top-5 by greedy cost + final deterministic polish

```python
def init_mapping(self):
    """
    Layer-Decay Simulated Annealing (LDSA)

    Key improvements over CPMR-3OLS (293.00):

    1. Layer-based exponential temporal decay weights:
       w = exp(-λ * circuit_layer) + ε  instead of fwd/bwd depth normalization.
       Layer 0 gates (immediately executable) have weight ~1.1, layer 10 ~0.18.
       This DIRECTLY captures routing urgency: early gates cost swaps now,
       late gates cost swaps later after the topology has shifted.

    2. Simulated Annealing local search replaces deterministic 3-opt:
       SA accepts worse solutions with probability exp(-delta/T), allowing
       escape from local optima that pairwise/3-opt cyclic search cannot leave.
       Temperature is calibrated to problem scale (avg edge weight × avg degree).

    3. Two-phase multi-restart:
       Phase 1 – Greedy placement on 30 anchor configs (5 edges × 3 phys pairs
       × 2 orientations). Phase 2 – SA refinement on the top-5 greedy solutions
       with distinct random seeds, then final deterministic polish.

    4. Deterministic polish post-SA:
       After SA's stochastic walk, one pass of pairwise swap hill-climbing
       guarantees the returned solution is a local minimum.
    """
    import heapq
    import math
    import random
    from collections import defaultdict

    # ------------------------------------------------------------------ #
    # Collect logical / physical qubit sets                               #
    # ------------------------------------------------------------------ #
    logical_qubit_set = set()
    for qubits in self.access.values():
        for q in qubits:
            logical_qubit_set.add(q)

    logical_qubits  = sorted(logical_qubit_set)
    physical_qubits = sorted(self.backend.keys())

    if not logical_qubits:
        self.mapping_dict         = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # ------------------------------------------------------------------ #
    # Step 1 – Build gate DAG and compute circuit layer for each gate     #
    # Layer = earliest timestep at which a gate can execute               #
    # ------------------------------------------------------------------ #
    sorted_gates    = sorted(self.access.keys())
    n_gates         = len(sorted_gates)
    qubit_last_gate = {}
    gate_prev       = [[] for _ in range(n_gates)]

    for i, gate in enumerate(sorted_gates):
        for q in self.access[gate]:
            if q in qubit_last_gate:
                gate_prev[i].append(qubit_last_gate[q])
            qubit_last_gate[q] = i

    gate_layer = [0] * n_gates
    for i in range(n_gates):
        if gate_prev[i]:
            gate_layer[i] = 1 + max(gate_layer[p] for p in gate_prev[i])

    # ------------------------------------------------------------------ #
    # Step 2 – Build interaction weights with exponential temporal decay  #
    # w(gate) = exp(-λ * layer) + ε                                      #
    # Early gates dominate: layer-0 weight ≈ 1.1, layer-10 weight ≈ 0.18#
    # ------------------------------------------------------------------ #
    DECAY   = 0.25
    EPSILON = 0.1   # floor so even late gates contribute

    iw = defaultdict(lambda: defaultdict(float))
    for i, gate in enumerate(sorted_gates):
        qubits = self.access[gate]
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            weight  = math.exp(-DECAY * gate_layer[i]) + EPSILON
            iw[q1][q2] += weight
            iw[q2][q1] += weight

    # ------------------------------------------------------------------ #
    # Step 3 – Hardware structures                                        #
    # ------------------------------------------------------------------ #
    phys_degree  = {p: len(self.backend[p]) for p in physical_qubits}
    phys_adj_set = {p: set(self.backend[p]) for p in physical_qubits}

    def _mean_dist(p):
        vals = [self.distance_matrix[p][o] for o in physical_qubits
                if o != p and self.distance_matrix[p][o] != float('inf')]
        return sum(vals) / len(vals) if vals else float('inf')

    phys_centrality = {p: _mean_dist(p) for p in physical_qubits}

    # ------------------------------------------------------------------ #
    # Objective: total weighted distance (lower = better)                #
    # ------------------------------------------------------------------ #
    def _total_cost(mapping):
        cost = 0.0
        for q1 in logical_qubits:
            if q1 not in mapping:
                continue
            for q2, w in iw[q1].items():
                if q2 > q1 and q2 in mapping:
                    d = self.distance_matrix[mapping[q1]][mapping[q2]]
                    if d != float('inf'):
                        cost += w * d
        return cost

    # ------------------------------------------------------------------ #
    # Greedy BFS placement given initial anchor assignments               #
    # ------------------------------------------------------------------ #
    def _greedy_place(anchor_assignments):
        lq_to_phys  = dict(anchor_assignments)
        placed_phys = set(lq_to_phys.values())
        heap        = []
        counter     = [0]

        def _push_unplaced(lq):
            for nb, w in iw[lq].items():
                if nb not in lq_to_phys:
                    heapq.heappush(heap, (-w, counter[0], nb))
                    counter[0] += 1

        for placed_lq in list(lq_to_phys.keys()):
            _push_unplaced(placed_lq)

        if not heap:
            for lq in logical_qubits:
                if lq not in lq_to_phys:
                    heapq.heappush(heap, (0.0, counter[0], lq))
                    counter[0] += 1
                    break

        while heap:
            _, _, lq = heapq.heappop(heap)
            if lq in lq_to_phys:
                continue
            available_phys = [p for p in physical_qubits if p not in placed_phys]
            if not available_phys:
                break

            best_phys  = None
            best_score = None
            for p in available_phys:
                direct = 0.0
                for nb_lq, w in iw[lq].items():
                    if nb_lq in lq_to_phys:
                        d = self.distance_matrix[p][lq_to_phys[nb_lq]]
                        if d != float('inf'):
                            direct += w / (d + 1)

                lookahead  = 0.0
                avail_excl = [q for q in available_phys if q != p]
                if avail_excl:
                    for nb_lq, w in iw[lq].items():
                        if nb_lq not in lq_to_phys:
                            best_d = min(
                                (self.distance_matrix[p][q] for q in avail_excl
                                 if self.distance_matrix[p][q] != float('inf')),
                                default=float('inf')
                            )
                            if best_d != float('inf'):
                                lookahead += w * 0.4 / (best_d + 1)

                score = (direct + lookahead, phys_degree[p])
                if best_score is None or score > best_score:
                    best_score = score
                    best_phys  = p

            if best_phys is None:
                break

            lq_to_phys[lq] = best_phys
            placed_phys.add(best_phys)
            _push_unplaced(lq)

        remaining_phys = sorted(
            [p for p in physical_qubits if p not in placed_phys],
            key=lambda p: phys_degree[p], reverse=True
        )
        for lq, phys in zip(
            [lq for lq in logical_qubits if lq not in lq_to_phys],
            remaining_phys
        ):
            lq_to_phys[lq] = phys

        return lq_to_phys

    # ------------------------------------------------------------------ #
    # Simulated Annealing local search                                    #
    # Temperature calibrated to avg_weight × avg_degree so acceptance    #
    # rate starts ~65% and decays to near-zero by the final steps.       #
    # ------------------------------------------------------------------ #
    def _simulated_annealing(lq_to_phys, seed=0, steps=6000):
        placed_lqs = [lq for lq in logical_qubits if lq in lq_to_phys]
        n          = len(placed_lqs)
        if n < 2:
            return lq_to_phys

        # Calibrate temperature to problem scale
        n_edges = sum(1 for q1 in logical_qubits for q2 in iw[q1] if q2 > q1)
        if n_edges > 0:
            total_w = sum(sum(iw[q].values()) for q in logical_qubits) / 2.0
            avg_w   = total_w / n_edges
            avg_deg = 2.0 * n_edges / max(1, len(logical_qubits))
        else:
            avg_w   = 1.0
            avg_deg = 1.0

        T_start = avg_w * avg_deg * 5.0
        T_end   = avg_w * 0.005
        T_start = max(T_start, 0.1)
        T_end   = min(T_end, T_start * 0.001)

        current      = dict(lq_to_phys)
        current_cost = _total_cost(current)
        best         = dict(current)
        best_cost    = current_cost

        cooling = (T_end / T_start) ** (1.0 / steps)
        T       = T_start
        rng     = random.Random(seed)

        for _ in range(steps):
            # Random pairwise swap
            i = rng.randrange(n)
            j = rng.randrange(n - 1)
            if j >= i:
                j += 1
            lq1, lq2 = placed_lqs[i], placed_lqs[j]
            p1,  p2  = current[lq1], current[lq2]

            # Incremental delta: only neighbours contribute, cross-term cancels
            delta = 0.0
            for nb, w in iw[lq1].items():
                if nb in current and nb != lq2:
                    nb_p  = current[nb]
                    d_bef = self.distance_matrix[p1][nb_p]
                    d_aft = self.distance_matrix[p2][nb_p]
                    if d_bef != float('inf') and d_aft != float('inf'):
                        delta += w * (d_aft - d_bef)
            for nb, w in iw[lq2].items():
                if nb in current and nb != lq1:
                    nb_p  = current[nb]
                    d_bef = self.distance_matrix[p2][nb_p]
                    d_aft = self.distance_matrix[p1][nb_p]
                    if d_bef != float('inf') and d_aft != float('inf'):
                        delta += w * (d_aft - d_bef)

            if delta < 0 or rng.random() < math.exp(-delta / T):
                current[lq1] = p2
                current[lq2] = p1
                current_cost += delta
                if current_cost < best_cost:
                    best_cost = current_cost
                    best      = dict(current)

            T *= cooling

        return best

    # ------------------------------------------------------------------ #
    # Deterministic polish: pairwise swap hill-climbing to local minimum  #
    # Cleans up any uphill moves made by SA near the end of cooling.     #
    # ------------------------------------------------------------------ #
    def _polish(lq_to_phys):
        placed_lqs = [lq for lq in logical_qubits if lq in lq_to_phys]
        improved   = True
        while improved:
            improved = False
            for i in range(len(placed_lqs)):
                for j in range(i + 1, len(placed_lqs)):
                    lq1, lq2 = placed_lqs[i], placed_lqs[j]
                    p1,  p2  = lq_to_phys[lq1], lq_to_phys[lq2]

                    delta = 0.0
                    for nb, w in iw[lq1].items():
                        if nb in lq_to_phys and nb != lq2:
                            nb_p  = lq_to_phys[nb]
                            d_bef = self.distance_matrix[p1][nb_p]
                            d_aft = self.distance_matrix[p2][nb_p]
                            if d_bef != float('inf') and d_aft != float('inf'):
                                delta += w * (d_aft - d_bef)
                    for nb, w in iw[lq2].items():
                        if nb in lq_to_phys and nb != lq1:
                            nb_p  = lq_to_phys[nb]
                            d_bef = self.distance_matrix[p2][nb_p]
                            d_aft = self.distance_matrix[p1][nb_p]
                            if d_bef != float('inf') and d_aft != float('inf'):
                                delta += w * (d_aft - d_bef)

                    if delta < -1e-9:
                        lq_to_phys[lq1] = p2
                        lq_to_phys[lq2] = p1
                        improved         = True
        return lq_to_phys

    # ------------------------------------------------------------------ #
    # Step 4 – Anchor candidate construction (edge × phys-pair × orient) #
    # ------------------------------------------------------------------ #
    edge_weights = []
    for q1 in logical_qubits:
        for q2, w in iw[q1].items():
            if q2 > q1:
                nbw   = sum(iw[q1].values()) + sum(iw[q2].values()) - 2 * w
                score = w + 0.15 * nbw
                edge_weights.append((score, q1, q2))
    edge_weights.sort(reverse=True)

    adjacent_pairs = []
    for p1 in physical_qubits:
        for p2 in phys_adj_set[p1]:
            if p2 > p1:
                score = (phys_centrality[p1] + phys_centrality[p2],
                         -(phys_degree[p1] + phys_degree[p2]))
                adjacent_pairs.append((score, p1, p2))
    adjacent_pairs.sort()

    TOP_K_EDGES    = min(5, len(edge_weights)) if edge_weights else 0
    TOP_K_PAIRS    = min(3, len(adjacent_pairs))
    top_phys_pairs = [(p1, p2) for _, p1, p2 in adjacent_pairs[:TOP_K_PAIRS]]

    # ------------------------------------------------------------------ #
    # Phase 1 – Greedy placement on all anchor configurations             #
    # ------------------------------------------------------------------ #
    candidates = []

    if edge_weights:
        for _, alq1, alq2 in edge_weights[:TOP_K_EDGES]:
            lq1_w = sum(iw[alq1].values())
            lq2_w = sum(iw[alq2].values())

            for bp1, bp2 in top_phys_pairs:
                if lq1_w >= lq2_w:
                    pref = (bp1, bp2) if phys_degree[bp1] >= phys_degree[bp2] \
                           else (bp2, bp1)
                else:
                    pref = (bp2, bp1) if phys_degree[bp1] >= phys_degree[bp2] \
                           else (bp1, bp2)

                for pp1, pp2 in [pref, (pref[1], pref[0])]:
                    anchor = {alq1: pp1, alq2: pp2}
                    placed = _greedy_place(anchor)
                    cost   = _total_cost(placed)
                    candidates.append((cost, placed))
    else:
        anchor_phys = min(physical_qubits, key=lambda p: phys_centrality[p])
        placed      = _greedy_place({logical_qubits[0]: anchor_phys})
        candidates.append((_total_cost(placed), placed))

    # ------------------------------------------------------------------ #
    # Phase 2 – SA refinement on top-5 greedy solutions, then polish     #
    # Different seeds explore distinct SA trajectories.                   #
    # ------------------------------------------------------------------ #
    candidates.sort(key=lambda x: x[0])
    TOP_SA = min(5, len(candidates))

    best_cost    = float('inf')
    best_mapping = None

    for idx, (_, placed) in enumerate(candidates[:TOP_SA]):
        refined = _simulated_annealing(placed, seed=idx * 17, steps=6000)
        refined = _polish(refined)
        cost    = _total_cost(refined)
        if cost < best_cost:
            best_cost    = cost
            best_mapping = dict(refined)

    lq_to_phys = best_mapping if best_mapping is not None else candidates[0][1]

    # ------------------------------------------------------------------ #
    # Step 5 – Build strict 1-to-1 permutation via in-place swap         #
    # ------------------------------------------------------------------ #
    mapping_dict         = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys:
            continue
        displaced_lq                       = reverse_mapping_dict[target_phys]
        mapping_dict[lq]                   = target_phys
        mapping_dict[displaced_lq]         = current_phys
        reverse_mapping_dict[target_phys]  = lq
        reverse_mapping_dict[current_phys] = displaced_lq

    self.mapping_dict         = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

---

**Summary of changes vs CPMR-3OLS:**

| Aspect | CPMR-3OLS (293.00) | LDSA (this proposal) |
|--------|-------------------|----------------------|
| **Weight formula** | `1 + 0.5*fwd_norm + 0.5*bwd_norm` — both terms normalized by same `max_fwd` | `exp(-0.25 * layer) + 0.1` — exponential decay directly from circuit execution order |
| **Local search** | Deterministic 3-opt (always same local optimum) | Simulated Annealing with adaptive temperature → escapes local optima |
| **Polish step** | None | Post-SA pairwise hill-climb ensures true local minimum |
| **Restarts** | 6 configs (3 edges × 2 pairs) | 30 greedy → top-5 for SA |
| **SA temperature** | N/A | Calibrated to `avg_w × avg_deg × 5`, decays to `avg_w × 0.005` |

The **exponential layer decay** is the key conceptual shift: instead of measuring how deep a gate is in the longest chain (which rewards late critical-path gates equally with early ones), it directly penalizes gates by how soon they execute. Layer-0 gates get ~11× the weight of layer-10 gates, making the placement strongly prioritize co-locating qubits that interact immediately — these are the swaps that cannot be amortized and must be paid upfront.
