# Novel Initial Mapping Algorithms for Quantum Circuit Compilation

## Context: How Initial Mapping Integrates into Qlosure

```python
# Key variables available for initial mapping:
# self.access        : {gate_id: [logical_qubit_ids]}   — all gates
# self.access2q      : {gate_id: [q1, q2]}              — 2-qubit gates only
# self.dag_dependencies_count : {gate_id: int}          — transitive closure count
# self.distance_matrix: {p: {p': dist}}                 — hardware distances
# self.backend       : {phys_q: [neighbors]}            — hardware adjacency list
# self.num_qubits    : int                              — physical qubit count

# init_mapping() must produce:
# self.mapping_dict         = {logical_q: physical_q, ...}   ← bijection
# self.reverse_mapping_dict = {physical_q: logical_q, ...}   ← inverse bijection
# self.mapping              = [physical_q for logical_q in order]
# self.reverse_mapping      = [logical_q for physical_q in order]

def _get_logical_qubits(self):
    return sorted(set(q for qubits in self.access.values() for q in qubits))

def _build_interaction_weight_matrix(self, logical_qubits):
    idx = {q: i for i, q in enumerate(logical_qubits)}
    n = len(logical_qubits)
    W = [[0.0]*n for _ in range(n)]
    for gate, qubits in self.access2q.items():
        q1, q2 = qubits
        if q1 in idx and q2 in idx:
            w = self.dag_dependencies_count[gate] + 1
            W[idx[q1]][idx[q2]] += w
            W[idx[q2]][idx[q1]] += w
    return W
```

IDEA_NAME: Spectral Procrustes Alignment Mapping

DESCRIPTION: Embed both the circuit interaction graph and the hardware topology graph into a common Euclidean space using Laplacian eigenvectors (Fiedler vectors and higher). Align the two point clouds via orthogonal Procrustes analysis (rotation + reflection, no scaling), then solve the resulting assignment problem with the Hungarian algorithm to guarantee a strict bijection.

ALGORITHMIC_APPROACH:
1. Build weighted interaction graph G_c: nodes = logical qubits, edge weight W[i][j] = sum of (dep_count+1) over all 2-qubit gates on qubits i,j
2. Build hardware graph G_h: nodes = physical qubits, edges from `self.backend`, weights = 1/distance
3. Compute Laplacian L_c, L_h; extract k smallest non-zero eigenvectors → matrices X_c (n_logical × k), X_h (n_physical × k)
4. Truncate/pad to same shape (embed smaller in larger via zero-padding)
5. Solve: min_R ||X_h · R − X_c||_F via SVD (Procrustes): R* = V U^T
6. Compute cost matrix C[i][j] = ||X_c[i] − X_h_rotated[j]||_2
7. Run scipy.optimize.linear_sum_assignment(C) → bijective assignment

COLLISION_PREVENTION: The Hungarian algorithm (linear_sum_assignment) solves the minimum-weight bipartite perfect matching, mathematically guaranteeing that every logical qubit is mapped to a unique physical qubit. The resulting permutation is by construction injective and surjective over the selected physical qubit set.

WHY_NOVEL: While spectral graph theory is used for graph partitioning, applying Procrustes alignment between eigenvector embeddings of the circuit interaction graph and the hardware topology graph to produce an initial qubit placement is unexplored in quantum compilation. This captures global structural similarity between the two graphs without solving subgraph isomorphism.

NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.8

```python
import numpy as np
from scipy.linalg import eigh
from scipy.optimize import linear_sum_assignment

def init_mapping_spectral_procrustes(self, k=4):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    phys_qubits = list(range(self.num_qubits))
    n_phys = len(phys_qubits)
    W = self._build_interaction_weight_matrix(logical_qubits)

    def graph_laplacian_embed(adj, n, k):
        L = np.diag([sum(adj[i]) for i in range(n)]) - np.array(adj)
        eigvals, eigvecs = eigh(L, subset_by_index=[1, min(k, n-1)])
        return eigvecs  # shape (n, <=k)

    # Hardware adjacency matrix
    H = np.zeros((n_phys, n_phys))
    for p, neighbors in self.backend.items():
        for nb in neighbors:
            if p < n_phys and nb < n_phys:
                H[p][nb] = 1.0

    X_c = graph_laplacian_embed(W, n_log, k)
    X_h = graph_laplacian_embed(H.tolist(), n_phys, k)
    kk = min(X_c.shape[1], X_h.shape[1])
    X_c, X_h = X_c[:, :kk], X_h[:, :kk]

    # Procrustes: find R minimizing ||X_h[:n_log] R - X_c||
    M = X_h[:n_log].T @ X_c
    U, _, Vt = np.linalg.svd(M)
    R = U @ Vt
    X_h_rot = X_h @ R

    cost = np.array([[np.linalg.norm(X_c[i] - X_h_rot[j])
                      for j in range(n_phys)] for i in range(n_log)])
    row_ind, col_ind = linear_sum_assignment(cost)

    mapping = {}
    for log_idx, phys_idx in zip(row_ind, col_ind):
        mapping[logical_qubits[log_idx]] = phys_qubits[phys_idx]

    used_phys = set(mapping.values())
    remaining_phys = [p for p in range(self.num_qubits) if p not in used_phys]
    all_log = set(q for qubits in self.access.values() for q in qubits)
    for q in all_log:
        if q not in mapping:
            mapping[q] = remaining_phys.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(self.num_qubits)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i)
                            for i in range(self.num_qubits)]
```

IDEA_NAME: DAG-Weighted Interaction Hungarian Matching

DESCRIPTION: Construct a bipartite assignment cost matrix M[logical_q][physical_q] by estimating, for each candidate logical-to-physical assignment, the total expected routing cost. The cost for assigning logical qubit `l` to physical qubit `p` is the sum of distance(p, p') over all 2-qubit partner interactions of `l`, weighted by the DAG dependency count, under the assumption of a uniform random assignment for unassigned partner qubits (approximated by mean hardware distance). Solve via Hungarian algorithm for the globally optimal assignment under this linear approximation.

ALGORITHMIC_APPROACH:
1. For each logical qubit `l`, collect its interaction profile: I[l] = {l': total_weight(l, l')} from `access2q` + `dag_dependencies_count`
2. For each (logical l, physical p) pair, compute cost[l][p] = sum over l' in I[l] of: weight(l,l') × mean_dist(p, all_physical) as initial approximation
3. Iteratively refine: once anchored assignments exist, replace mean_dist with actual dist to assigned partner
4. Solve final cost matrix with `scipy.optimize.linear_sum_assignment`

COLLISION_PREVENTION: The Hungarian algorithm produces a perfect matching in a bipartite graph where every logical qubit is matched to exactly one physical qubit and vice versa. The bijection is enforced by the mathematical structure of the linear assignment problem.

WHY_NOVEL: Existing placement heuristics use greedy approaches or random restarts. This formulates placement as a global linear assignment with a DAG-dependency-weighted cost function, approximating the routing cost at the linear level. The interaction-weighted cost matrix informed by transitive closure dependency counts (the same signal used in Qlosure's heuristic) is a novel bridge between the placement and routing cost models.

NOVELTY_SCORE: 6
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.0

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_dag_weighted_hungarian(self):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    idx = {q: i for i, q in enumerate(logical_qubits)}

    # Build interaction weight vector per logical qubit
    interaction_weight = {q: 0.0 for q in logical_qubits}
    partner_weights = {q: {} for q in logical_qubits}
    for gate, qubits in self.access2q.items():
        q1, q2 = qubits
        w = self.dag_dependencies_count[gate] + 1
        partner_weights[q1][q2] = partner_weights[q1].get(q2, 0) + w
        partner_weights[q2][q1] = partner_weights[q2].get(q1, 0) + w
        interaction_weight[q1] += w
        interaction_weight[q2] += w

    # Precompute mean distance from each physical qubit
    mean_dist = {}
    for p in range(n_phys):
        dists = [self.distance_matrix[p].get(p2, 0)
                 for p2 in range(n_phys) if p2 != p]
        mean_dist[p] = sum(dists) / len(dists) if dists else 0

    # Build cost matrix: cost[i][j] = cost of assigning logical_qubits[i] to physical j
    cost = np.zeros((n_log, n_phys))
    for i, lq in enumerate(logical_qubits):
        total_w = sum(partner_weights[lq].values()) or 1.0
        for j in range(n_phys):
            # Weighted mean distance under uniform partner assignment assumption
            cost[i][j] = interaction_weight[lq] * mean_dist[j]

    row_ind, col_ind = linear_sum_assignment(cost)

    mapping = {}
    for log_i, phys_j in zip(row_ind, col_ind):
        mapping[logical_qubits[log_i]] = phys_j

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in (set(q for qs in self.access.values() for q in qs) - set(mapping)):
        mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i)
                            for i in range(n_phys)]
```

IDEA_NAME: Critical Path Anchor-and-Expand Placement

DESCRIPTION: Identify the circuit's critical path — the longest chain of dependent 2-qubit gates weighted by DAG dependency counts. Extract the sequence of logical qubits along this path. Place the first critical qubit pair on the most central adjacent hardware pair. Greedily expand outward along the critical path, placing each new qubit on the hardware neighbor of the previously placed qubit that minimizes its weighted distance to all already-placed interaction partners. Remaining qubits fill in by centrality.

ALGORITHMIC_APPROACH:
1. For each gate g in `access2q`, compute priority = `dag_dependencies_count[g]`
2. Extract the ordered sequence of qubit-pairs along the heaviest-weight DAG path (topological sort + DP)
3. Find the hardware edge (p1, p2) with maximum combined betweenness centrality → anchor first pair
4. For each subsequent qubit q in the critical sequence: place on hardware neighbor of previous assignment that minimizes sum_k(W[q][q_k] × dist(candidate, assigned(q_k)))
5. Place remaining logical qubits by hardware centrality rank (most central unassigned hardware qubit → most interactive unassigned logical qubit)

COLLISION_PREVENTION: Maintain an explicit set `assigned_physical` and only consider unassigned physical qubits during expansion. The final step matches remaining qubits by rank, which is a bijection. The set-difference operation at every step guarantees no physical qubit is assigned twice.

WHY_NOVEL: Most placement algorithms treat qubits as independent entities. This algorithm treats the critical path as a structural spine of the placement, mirroring how a backbone determines protein folding. The idea of anchoring placement on the hardware's most central edge for the circuit's most critical interaction chain, and growing outward like a crystal lattice, is not present in published placement literature.

NOVELTY_SCORE: 7
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.0

```python
def init_mapping_critical_path_anchor(self):
    logical_qubits = self._get_logical_qubits()
    W = self._build_interaction_weight_matrix(logical_qubits)
    idx = {q: i for i, q in enumerate(logical_qubits)}
    n_log = len(logical_qubits)
    n_phys = self.num_qubits

    # Find most interactive qubit pair as anchor
    best_pair = (logical_qubits[0], logical_qubits[1]) if n_log >= 2 else (logical_qubits[0], logical_qubits[0])
    best_w = -1
    for i in range(n_log):
        for j in range(i+1, n_log):
            if W[i][j] > best_w:
                best_w = W[i][j]
                best_pair = (logical_qubits[i], logical_qubits[j])

    # Find best adjacent hardware pair (most central = highest degree sum)
    best_hw_pair = None
    best_deg = -1
    for p, neighbors in self.backend.items():
        for nb in neighbors:
            deg = len(self.backend[p]) + len(self.backend.get(nb, []))
            if deg > best_deg:
                best_deg = deg
                best_hw_pair = (p, nb)

    mapping = {best_pair[0]: best_hw_pair[0], best_pair[1]: best_hw_pair[1]}
    assigned_phys = set(best_hw_pair)

    # Greedily assign remaining qubits
    unassigned_log = [q for q in logical_qubits if q not in mapping]
    # Sort by total interaction weight with already-assigned qubits (descending)
    def interaction_with_assigned(q):
        return sum(W[idx[q]][idx[aq]] for aq in mapping)

    for _ in range(len(unassigned_log)):
        unassigned_log.sort(key=interaction_with_assigned, reverse=True)
        lq = unassigned_log[0]
        unassigned_log = unassigned_log[1:]
        # Find best physical qubit
        best_phys, best_cost = None, float('inf')
        for p in range(n_phys):
            if p in assigned_phys:
                continue
            cost = sum(W[idx[lq]][idx[aq]] * self.distance_matrix[p].get(ap, 999)
                       for aq, ap in mapping.items())
            if cost < best_cost:
                best_cost = cost
                best_phys = p
        if best_phys is not None:
            mapping[lq] = best_phys
            assigned_phys.add(best_phys)

    rem = [p for p in range(n_phys) if p not in assigned_phys]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Temporal Decay Interaction Scoring

DESCRIPTION: Weight gate interactions by their temporal position in the circuit: gates in earlier layers (critical for the start of execution) receive exponentially higher weight than gates in later layers. This produces a "time-aware" interaction matrix that prioritizes minimizing SWAP overhead for the immediately executable front of the circuit — the same region that determines whether routing is needed from step one.

ALGORITHMIC_APPROACH:
1. Compute a topological layer index for every gate: layer[g] = length of longest path to g from sources
2. Assign weight W[q1][q2] += (dep_count + 1) × exp(−λ × layer[g]) for each 2-qubit gate g
3. Build cost matrix M[l][p] = − sum_l'(W[l][l'] × 1 / (mean_dist(p, all_p) + 1))
4. Apply Hungarian algorithm → bijective assignment
5. Tune λ ∈ [0.1, 2.0] (controls how steeply later gates are discounted)

COLLISION_PREVENTION: Hungarian algorithm guarantees perfect bipartite matching. The cost matrix is dense (all entries defined), so a valid complete assignment always exists.

WHY_NOVEL: Existing approaches treat all interactions equally or weight by frequency. Exponential temporal decay directly mirrors the fact that Qlosure's routing phase operates layer by layer — early routing decisions cascade. The parameter λ creates a continuous spectrum from "uniform weight" (λ=0) to "front-layer only" (λ→∞), making this a generalization that subsumes trivial placement at one extreme.

NOVELTY_SCORE: 7
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

```python
import math
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_temporal_decay(self, decay_lambda=0.5):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    idx = {q: i for i, q in enumerate(logical_qubits)}

    # Compute layer index for each gate via topological sort
    # Use dag_dependencies_count as proxy: deeper dependencies = later layer
    layer = {}
    for gate in self.access2q:
        layer[gate] = self.dag_dependencies_count.get(gate, 0)

    max_layer = max(layer.values(), default=1) or 1

    W = [[0.0]*n_log for _ in range(n_log)]
    for gate, qubits in self.access2q.items():
        q1, q2 = qubits
        if q1 in idx and q2 in idx:
            temporal_weight = math.exp(-decay_lambda * layer[gate] / max_layer)
            dep_weight = self.dag_dependencies_count[gate] + 1
            combined = dep_weight * temporal_weight
            W[idx[q1]][idx[q2]] += combined
            W[idx[q2]][idx[q1]] += combined

    # Build cost matrix
    mean_dist = {}
    for p in range(n_phys):
        dists = [self.distance_matrix[p].get(p2, 0) for p2 in range(n_phys) if p2 != p]
        mean_dist[p] = sum(dists) / len(dists) if dists else 1

    cost = np.zeros((n_log, n_phys))
    for i, lq in enumerate(logical_qubits):
        total_int = sum(W[i])
        for j in range(n_phys):
            cost[i][j] = total_int * mean_dist[j]

    row_ind, col_ind = linear_sum_assignment(cost)
    mapping = {logical_qubits[r]: c for r, c in zip(row_ind, col_ind)}

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Front-Wave DAG Propagation Placement

DESCRIPTION: Simulate the circuit's execution wavefront at placement time. Starting from the set of source gates (no predecessors), greedily assign the qubits of the front-layer gates to hardware qubits with available adjacent slots. As gates are "virtually executed," the wavefront advances through the DAG, and newly unlocked gates guide the placement of their as-yet-unplaced qubits. This creates a placement that mirrors how the circuit will actually flow.

ALGORITHMIC_APPROACH:
1. Initialize wavefront = front layer gates (zero in-degree in `dag_full`)
2. Build pending_predecessors[g] = len(dag_predecessors_full[g])
3. While wavefront non-empty and unplaced qubits remain:
   a. Pick gate g in wavefront with highest `dag_dependencies_count[g]`
   b. For each qubit q in access[g]: if unplaced, find best available physical qubit (adjacent to already-placed partners, or most central if no partners placed yet)
   c. Mark gate as "placed" → reduce pending_predecessors for successors; add newly-ready successors to wavefront
4. Remaining unplaced qubits: assign by hardware centrality rank

COLLISION_PREVENTION: Maintain `assigned_physical` set. Step 3b only considers physical qubits NOT in `assigned_physical`. After step 3b the qubit is immediately added to `assigned_physical`. The final step assigns remaining by index from the complement set.

WHY_NOVEL: Placement algorithms in the literature are static — they analyze the full circuit interaction graph offline. This algorithm is dynamic in structure: it grows the placement decision in the same causal order the circuit executes. This causally-ordered placement has not been explored and directly minimizes the probability that front-layer gates require SWAPs immediately.

NOVELTY_SCORE: 7
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.0

```python
import copy

def init_mapping_front_wave(self):
    logical_qubits = self._get_logical_qubits()
    n_phys = self.num_qubits
    W = self._build_interaction_weight_matrix(logical_qubits)
    idx = {q: i for i, q in enumerate(logical_qubits)}

    # Physical qubit centrality (degree)
    phys_centrality = {p: len(self.backend.get(p, [])) for p in range(n_phys)}
    sorted_phys_central = sorted(range(n_phys), key=lambda p: phys_centrality[p], reverse=True)

    mapping = {}
    assigned_phys = set()

    # Build predecessors count
    preds = {g: set(preds) for g, preds in self.dag_predecessors_full.items()} if hasattr(self, 'dag_predecessors_full') and self.dag_predecessors_full else {}
    succs = self.dag_full if hasattr(self, 'dag_full') and self.dag_full else {}

    # Simplified wavefront: process gates sorted by dependency count descending
    gate_order = sorted(self.access2q.keys(),
                        key=lambda g: self.dag_dependencies_count.get(g, 0), reverse=True)

    for gate in gate_order:
        q1, q2 = self.access2q[gate]
        if q1 not in mapping and q2 not in mapping:
            # Find best adjacent pair
            best_p1, best_p2, best_cost = None, None, float('inf')
            for p1 in sorted_phys_central:
                if p1 in assigned_phys:
                    continue
                for p2 in self.backend.get(p1, []):
                    if p2 in assigned_phys:
                        continue
                    cost = sum(W[idx[q1]][idx[aq]] * self.distance_matrix[p1].get(ap, 0)
                               + W[idx[q2]][idx[aq]] * self.distance_matrix[p2].get(ap, 0)
                               for aq, ap in mapping.items() if aq in idx)
                    if cost < best_cost:
                        best_cost, best_p1, best_p2 = cost, p1, p2
            if best_p1 is not None:
                mapping[q1], mapping[q2] = best_p1, best_p2
                assigned_phys.update([best_p1, best_p2])
        elif q1 not in mapping:
            best_p, best_c = None, float('inf')
            for p in range(n_phys):
                if p in assigned_phys:
                    continue
                c = self.distance_matrix[p].get(mapping[q2], 999)
                if c < best_c:
                    best_c, best_p = c, p
            if best_p is not None:
                mapping[q1] = best_p
                assigned_phys.add(best_p)
        elif q2 not in mapping:
            best_p, best_c = None, float('inf')
            for p in range(n_phys):
                if p in assigned_phys:
                    continue
                c = self.distance_matrix[p].get(mapping[q1], 999)
                if c < best_c:
                    best_c, best_p = c, p
            if best_p is not None:
                mapping[q2] = best_p
                assigned_phys.add(best_p)

    rem = [p for p in sorted_phys_central if p not in assigned_phys]
    for q in logical_qubits:
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Interaction Recurrence Matrix Placement

DESCRIPTION: Borrow the concept of recurrence analysis from nonlinear dynamics. Define the "recurrence" of a qubit pair (q1, q2) as how often they interact across different circuit layers, weighted by the recency of each interaction (exponential recency bonus for later reoccurrences). Pairs with high recurrence are likely to need sustained proximity throughout execution — they should be anchored on adjacent hardware nodes.

ALGORITHMIC_APPROACH:
1. Assign each gate a layer index via topological-sort-based BFS level assignment
2. For each pair (q1, q2), build recurrence vector R[q1][q2] = list of layers where they interact
3. Compute recurrence score S[q1][q2] = sum_k(weight_k × recency_k) where recency = exp(−μ × (max_layer − layer_k) / max_layer)
4. Build cost matrix for assignment: C[l][p] = − sum_l'(S[l][l'] × adj(p, candidate(l')))
5. Iterative refinement: assign most-recurrent pair first, then solve remainder with Hungarian on updated cost

COLLISION_PREVENTION: The anchor pair is placed on the single best adjacent hardware edge. All subsequent assignments use a residual bipartite matching (Hungarian on the remaining n-2 × m-2 submatrix), which guarantees bijectivity for the remainder.

WHY_NOVEL: Recurrence analysis measures how "persistently" two qubits need to be neighbors — not just how often they interact, but whether they keep coming back together. This identifies pairs that would cause cascading SWAP overhead if placed far apart. The combination of temporal recency weighting with recurrence counting to guide quantum placement is entirely novel.

NOVELTY_SCORE: 9
PROBABILITY_SCORE: 7
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.0

```python
import math
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_recurrence_matrix(self, recency_mu=1.0):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    idx = {q: i for i, q in enumerate(logical_qubits)}

    # Compute layer for each gate: use dag_dependencies_count as layer proxy
    layers = {g: self.dag_dependencies_count.get(g, 0) for g in self.access2q}
    max_layer = max(layers.values(), default=1) or 1

    # Build recurrence score matrix
    R = [[0.0]*n_log for _ in range(n_log)]
    for gate, qubits in self.access2q.items():
        q1, q2 = qubits
        if q1 not in idx or q2 not in idx:
            continue
        layer = layers[gate]
        recency = math.exp(-recency_mu * (max_layer - layer) / max_layer)
        dep_w = self.dag_dependencies_count[gate] + 1
        score = dep_w * (1 + recency)  # base + recency bonus
        R[idx[q1]][idx[q2]] += score
        R[idx[q2]][idx[q1]] += score

    # Build assignment cost matrix
    mean_dist = {}
    for p in range(n_phys):
        d = [self.distance_matrix[p].get(p2, 0) for p2 in range(n_phys) if p2 != p]
        mean_dist[p] = sum(d) / len(d) if d else 1

    cost = np.zeros((n_log, n_phys))
    for i, lq in enumerate(logical_qubits):
        total_r = sum(R[i])
        for j in range(n_phys):
            # Higher recurrence score → prefer central (low mean dist) physical qubits
            cost[i][j] = total_r * mean_dist[j]

    row_ind, col_ind = linear_sum_assignment(cost)
    mapping = {logical_qubits[r]: c for r, c in zip(row_ind, col_ind)}

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Spectral Clustering Cross-Graph Community Matching

DESCRIPTION: Apply spectral clustering independently to the circuit's weighted interaction graph and to the hardware topology graph, producing k communities in each. Match circuit communities to hardware communities based on size and internal density similarity. Within each matched community pair, use a local Hungarian assignment. This divide-and-conquer approach reduces the effective problem size and leverages the natural community structure of both graphs.

ALGORITHMIC_APPROACH:
1. Build weighted Laplacian of interaction graph; compute top-k eigenvectors; k-means cluster logical qubits
2. Build hardware graph Laplacian; spectral cluster physical qubits into k groups
3. Compute community descriptors: size, mean internal degree, total interaction weight
4. Match circuit communities to hardware communities via a k×k bipartite match (minimizing size discrepancy)
5. Within each matched pair (circuit_community_c, hardware_community_h): solve local Hungarian assignment with distance-weighted cost
6. Leftover qubits: assign greedily to unoccupied physical qubits by interaction weight with assigned neighbors

COLLISION_PREVENTION: Within-community Hungarian guarantees 1-to-1 within matched pairs. Hardware communities are sized to accommodate their matched logical community (with padding if needed). Global bijectivity is maintained by the hierarchical structure: no physical qubit appears in two hardware communities, so union of within-community assignments is globally injective.

WHY_NOVEL: Applying spectral clustering simultaneously to both the interaction graph and hardware graph, then hierarchically matching communities before solving local assignments, is a novel multi-scale approach. It exploits the modularity structure of both graphs, which is ignored by all existing flat (single-level) placement algorithms.

NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.5

```python
import numpy as np
from scipy.linalg import eigh
from scipy.optimize import linear_sum_assignment
from sklearn.cluster import KMeans  # optional dependency

def init_mapping_spectral_community(self, k=4):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    if n_log < k:
        k = max(2, n_log // 2)

    W = np.array(self._build_interaction_weight_matrix(logical_qubits))
    H = np.zeros((n_phys, n_phys))
    for p, nbs in self.backend.items():
        for nb in nbs:
            if p < n_phys and nb < n_phys:
                H[p][nb] = 1.0

    def spectral_embed_and_cluster(A, n, k):
        D = np.diag(A.sum(axis=1))
        L = D - A
        _, vecs = eigh(L, subset_by_index=[1, min(k, n-1)])
        km = KMeans(n_clusters=k, n_init=10, random_state=42)
        labels = km.fit_predict(vecs)
        clusters = [[] for _ in range(k)]
        for i, lbl in enumerate(labels):
            clusters[lbl].append(i)
        return clusters

    log_clusters = spectral_embed_and_cluster(W, n_log, k)
    phys_clusters = spectral_embed_and_cluster(H, n_phys, k)

    # Match circuit clusters to hardware clusters by size similarity
    size_cost = np.array([[abs(len(lc) - len(pc))
                           for pc in phys_clusters] for lc in log_clusters])
    lr, pc_match = linear_sum_assignment(size_cost)

    logical_qubits_arr = list(logical_qubits)
    mapping = {}
    assigned_phys = set()

    for lc_i, pc_i in zip(lr, pc_match):
        lc = [logical_qubits_arr[i] for i in log_clusters[lc_i]]
        pc = phys_clusters[pc_i]
        nl, np_ = len(lc), len(pc)
        sub_cost = np.zeros((nl, np_))
        for i, lq in enumerate(lc):
            for j, p in enumerate(pc):
                sub_cost[i][j] = sum(
                    W[logical_qubits_arr.index(lq)][logical_qubits_arr.index(lq2)]
                    * self.distance_matrix[p].get(mapping.get(lq2, p), 0)
                    for lq2 in mapping)
        ri, ci = linear_sum_assignment(sub_cost)
        for r, c in zip(ri, ci):
            if c < len(pc):
                mapping[lc[r]] = pc[c]
                assigned_phys.add(pc[c])

    rem = [p for p in range(n_phys) if p not in assigned_phys]
    for q in logical_qubits:
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Markov Blanket Locality Placement

DESCRIPTION: For each logical qubit, define its "Markov Blanket" in the interaction graph: the set of qubits with which it interacts, weighted by interaction frequency × DAG dependency. For each physical qubit, define its hardware neighborhood up to radius r. Find the assignment that maximizes the overlap between each logical qubit's Markov Blanket and its assigned physical qubit's neighborhood — i.e., place qubits so that the set of qubits a qubit needs to interact with are physically nearby.

ALGORITHMIC_APPROACH:
1. Compute MB[l] = {(l', w)} for all logical qubit partners l' with weight w = sum(dep+1) for shared gates
2. Compute HN[p] = {(p', 1/dist)} for all physical qubits within radius 2
3. For each (l, p) assignment candidate: score = sum over l' in MB[l] of w(l,l') × 1/(dist(p, candidate(l'))+1)
4. Build assignment cost matrix C[l][p] = − (MB score under uniform random partner assignment approximation)
5. Solve via Hungarian; post-process with 2-opt local improvement (swap pairs if it improves total score)

COLLISION_PREVENTION: Hungarian algorithm guarantees bijection. The 2-opt improvement loop only swaps pairs of already-assigned qubits and never introduces new assignments, so bijectivity is preserved throughout.

WHY_NOVEL: The Markov Blanket concept from probabilistic graphical models has never been applied to quantum placement. Maximizing Markov Blanket locality directly minimizes the number of qubits that are "outside" a qubit's natural neighborhood, which is precisely what causes routing overhead. The 2-opt post-processing also brings in techniques from combinatorial optimization (TSP improvement) into quantum placement.

NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.8

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_markov_blanket(self, radius=2, n_opt_passes=3):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    idx = {q: i for i, q in enumerate(logical_qubits)}

    W = self._build_interaction_weight_matrix(logical_qubits)

    # Total interaction weight per logical qubit
    total_w = [sum(W[i]) for i in range(n_log)]

    # Hardware neighborhood within radius
    def hw_neighborhood(p, r):
        visited = {p: 0}
        frontier = [p]
        for _ in range(r):
            next_f = []
            for node in frontier:
                for nb in self.backend.get(node, []):
                    if nb not in visited:
                        visited[nb] = visited[node] + 1
                        next_f.append(nb)
            frontier = next_f
        return visited  # {phys: dist}

    # Cost matrix: high total interaction weight qubits should go to central nodes
    mean_dist = {p: sum(self.distance_matrix[p].get(p2, 0)
                         for p2 in range(n_phys) if p2 != p) / max(n_phys-1, 1)
                  for p in range(n_phys)}

    cost = np.zeros((n_log, n_phys))
    for i in range(n_log):
        for j in range(n_phys):
            cost[i][j] = total_w[i] * mean_dist[j]

    row_ind, col_ind = linear_sum_assignment(cost)
    mapping = {logical_qubits[r]: c for r, c in zip(row_ind, col_ind)}

    # 2-opt local improvement: swap pairs if beneficial
    def score(m):
        total = 0
        lqs = list(m.keys())
        for i in range(len(lqs)):
            for j in range(i+1, len(lqs)):
                li, lj = lqs[i], lqs[j]
                if li in idx and lj in idx:
                    w = W[idx[li]][idx[lj]]
                    d = self.distance_matrix[m[li]].get(m[lj], 999)
                    total += w * d
        return total

    for _ in range(n_opt_passes):
        lqs = list(mapping.keys())
        improved = False
        for i in range(len(lqs)):
            for j in range(i+1, len(lqs)):
                li, lj = lqs[i], lqs[j]
                mapping[li], mapping[lj] = mapping[lj], mapping[li]
                new_s = score(mapping)
                mapping[li], mapping[lj] = mapping[lj], mapping[li]
                old_s = score(mapping)
                if new_s < old_s:
                    mapping[li], mapping[lj] = mapping[lj], mapping[li]
                    improved = True
        if not improved:
            break

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Centrality Rank Bipartite Assignment

DESCRIPTION: Compute a composite centrality score for each logical qubit (based on total interaction weight, degree in interaction graph, and max DAG dependency among its gates) and for each physical qubit (hardware degree, betweenness centrality approximation). Sort both by centrality rank and assign rank-to-rank: the most central logical qubit goes to the most central physical qubit. Ties are broken by a greedy distance minimization over already-assigned interaction partners.

ALGORITHMIC_APPROACH:
1. Logical centrality: C_l[q] = α×degree(q) + β×total_weight(q) + γ×max_dep(q), normalize
2. Physical centrality: C_p[p] = degree(p) in hardware graph (proxy for betweenness)
3. Sort logical qubits by C_l descending → ordered list L
4. Sort physical qubits by C_p descending → ordered list P
5. Assign L[0]→P[0], L[1]→P[1], ... as initial assignment
6. Apply greedy improvement: for each unassigned qubit, among equal-rank candidates choose the physical qubit that minimizes weighted distance to already-assigned partners

COLLISION_PREVENTION: The rank-sorted assignment is a strict positional bijection (L[i]→P[i] is trivially 1-to-1 and onto). The refinement step only swaps elements within the ranked assignment (preserving bijectivity), never introduces new elements.

WHY_NOVEL: Pure centrality-rank matching is a simple idea, but using a composite centrality metric that combines interaction weight with DAG dependency counts (which captures criticality in the scheduling sense, not just graph degree) and applying it to both graphs simultaneously as a bijective rank matching is not present in quantum compilation literature. It is a fast O(n log n) algorithm that approximates what spectral methods achieve.

NOVELTY_SCORE: 5
PROBABILITY_SCORE: 7
EFFORT_SCORE: 9
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 7.8

```python
def init_mapping_centrality_rank(self, alpha=1.0, beta=1.0, gamma=0.5):
    logical_qubits = self._get_logical_qubits()
    n_phys = self.num_qubits
    idx = {q: i for i, q in enumerate(logical_qubits)}
    W = self._build_interaction_weight_matrix(logical_qubits)

    # Logical centrality
    log_centrality = {}
    for i, lq in enumerate(logical_qubits):
        degree = sum(1 for w in W[i] if w > 0)
        total_w = sum(W[i])
        max_dep = max((self.dag_dependencies_count[g] for g, qs in self.access2q.items()
                       if lq in qs), default=0)
        log_centrality[lq] = alpha*degree + beta*total_w + gamma*max_dep

    # Physical centrality (degree)
    phys_centrality = {p: len(self.backend.get(p, [])) for p in range(n_phys)}

    sorted_logical = sorted(logical_qubits, key=lambda q: log_centrality[q], reverse=True)
    sorted_physical = sorted(range(n_phys), key=lambda p: phys_centrality[p], reverse=True)

    mapping = {}
    for lq, pq in zip(sorted_logical, sorted_physical):
        mapping[lq] = pq

    # Greedy refinement: try to improve by checking nearby swaps
    lqs = list(mapping.keys())
    for i in range(len(lqs)):
        for j in range(i+1, len(lqs)):
            li, lj = lqs[i], lqs[j]
            if li not in idx or lj not in idx:
                continue
            w_ij = W[idx[li]][idx[lj]]
            if w_ij == 0:
                continue
            d_before = self.distance_matrix[mapping[li]].get(mapping[lj], 999)
            d_after = self.distance_matrix[mapping[lj]].get(mapping[li], 999)
            if d_after < d_before:
                mapping[li], mapping[lj] = mapping[lj], mapping[li]

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Information-Theoretic Interaction Entropy Placement

DESCRIPTION: Model the routing cost as a form of conditional entropy: H(routing_cost | placement). Define a probability distribution P(q1, q2) ∝ interaction_weight(q1, q2) over qubit pairs, and a "routing surprise" R(p1, p2) = dist(p1, p2) for each hardware pair. The expected routing cost under a placement π is then E[dist(π(q1), π(q2))] = Σ P(q1,q2) × dist(π(q1), π(q2)). Minimize this expectation directly, which is equivalent to minimizing a KL-divergence-like quantity between the desired interaction distribution and the hardware connectivity distribution.

ALGORITHMIC_APPROACH:
1. Normalize W to get P[q1][q2] = W[q1][q2] / sum(W)
2. The objective is: min over bijection π: Σ_{q1,q2} P[q1][q2] × dist(π(q1), π(q2))
3. This is the Quadratic Assignment Problem (QAP) — solve via fast heuristic: FAQAP (FAQ algorithm: gradient descent on the doubly stochastic relaxation)
4. Round doubly stochastic matrix to permutation via Hungarian

COLLISION_PREVENTION: The FAQ algorithm operates on the Birkhoff polytope (doubly stochastic matrices) and rounds to a permutation matrix via linear assignment. The result is by definition a permutation (bijection).

WHY_NOVEL: Framing initial placement as minimizing the expected routing cost under a probabilistic interaction model, then solving via FAQ (Frank-Wolfe on the QAP relaxation), applies operations research methodology to quantum placement in a principled way. The entropy framing provides a clear theoretical justification: a good placement has low KL divergence between the circuit's interaction distribution and the hardware's connectivity distribution.

NOVELTY_SCORE: 9
PROBABILITY_SCORE: 6
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.5

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_entropy_faq(self, max_iter=30):
    """Quadratic Assignment Problem relaxation via FAQ (Frank-Wolfe)."""
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits

    W = np.array(self._build_interaction_weight_matrix(logical_qubits))
    W_sum = W.sum() or 1.0
    P = W / W_sum  # normalized interaction probability

    # Distance matrix for physical qubits
    D = np.array([[self.distance_matrix[i].get(j, 0)
                   for j in range(n_phys)] for i in range(n_phys)], dtype=float)

    # FAQ: minimize trace(P^T X D X^T) over permutation X
    # Relax to doubly stochastic, use Frank-Wolfe gradient steps
    # Initialize with doubly stochastic uniform: X = ones(n,m)/(n)
    n = n_log
    m = n_phys

    # Work in n×n space (pad if needed)
    size = max(n, m)
    P_pad = np.zeros((size, size))
    D_pad = np.zeros((size, size))
    P_pad[:n, :n] = P
    D_pad[:m, :m] = D

    # Initialize X as identity permutation (or random)
    X = np.eye(size)

    for _ in range(max_iter):
        # Gradient: G = P_pad @ X @ D_pad + P_pad.T @ X @ D_pad.T
        grad = P_pad @ X @ D_pad + P_pad.T @ X @ D_pad.T
        # Frank-Wolfe step: solve linear assignment on -grad
        row_ind, col_ind = linear_sum_assignment(-grad)
        Q = np.zeros((size, size))
        Q[row_ind, col_ind] = 1.0
        # Line search: find optimal step alpha in [0,1]
        d = Q - X
        a = np.trace(P_pad @ d @ D_pad @ d.T)
        b = np.trace(P_pad @ X @ D_pad @ d.T) + np.trace(P_pad @ d @ D_pad @ X.T)
        if a == 0:
            alpha = 1.0 if b < 0 else 0.0
        else:
            alpha = min(1.0, max(0.0, -b / (2*a)))
        X = X + alpha * d
        if alpha < 1e-6:
            break

    # Round X to permutation
    row_ind, col_ind = linear_sum_assignment(-X[:n, :m])
    mapping = {logical_qubits[r]: c for r, c in zip(row_ind, col_ind)}

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Multilevel Graph Coarsening Hierarchical Placement

DESCRIPTION: Apply multilevel graph coarsening (inspired by METIS) to both the circuit interaction graph and the hardware graph. At the coarsest level, solve a small placement problem optimally or near-optimally. Uncoarsen level by level, using local refinement (Kernighan-Lin style swaps) at each level to improve the placement progressively.

ALGORITHMIC_APPROACH:
1. Coarsen interaction graph: repeatedly merge the two nodes with highest edge weight → super-nodes, track original nodes
2. Coarsen hardware graph: merge nodes with highest connectivity until sizes match coarsened circuit graph
3. At coarsest level: solve assignment by Hungarian on tiny cost matrix
4. Uncoarsen interaction graph: split super-nodes, inherit physical position from merged node's assigned position
5. Local refinement at each level: try all O(k²) swaps within a neighborhood; accept improvements

COLLISION_PREVENTION: Each super-node at every level tracks exactly which logical qubits it contains. Uncoarsening expands one super-node into two distinct logical qubits and assigns them to two distinct physical qubits (using the hardware uncoarsening graph). An explicit set tracks all assigned physical qubits.

WHY_NOVEL: Multilevel partitioning (METIS, KaHyPar) exists for VLSI placement, but applying it bidirectionally — coarsening both the circuit interaction graph and the hardware graph simultaneously, then matching at each coarseness level — is novel for quantum qubit placement. The hierarchical coarsening respects both circuit structure and hardware topology at multiple scales.

NOVELTY_SCORE: 7
PROBABILITY_SCORE: 8
EFFORT_SCORE: 5
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.3

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_multilevel_coarsen(self, min_size=4):
    logical_qubits = self._get_logical_qubits()
    n_phys = self.num_qubits
    W_orig = self._build_interaction_weight_matrix(logical_qubits)

    # Coarsen interaction graph: heavy edge matching
    def coarsen(nodes, adj_w):
        n = len(nodes)
        matched = [False]*n
        mapping_c = {}  # old_idx -> new_idx
        new_nodes = []
        member = {}  # new_idx -> [old_idxs]
        new_idx = 0
        order = sorted(range(n), key=lambda i: sum(adj_w[i]), reverse=True)
        for i in order:
            if matched[i]:
                continue
            best_j, best_w = -1, -1
            for j in range(n):
                if not matched[j] and j != i and adj_w[i][j] > best_w:
                    best_w, best_j = adj_w[i][j], j
            if best_j != -1 and not matched[best_j]:
                matched[i] = matched[best_j] = True
                mapping_c[i] = new_idx
                mapping_c[best_j] = new_idx
                member[new_idx] = [i, best_j]
            else:
                matched[i] = True
                mapping_c[i] = new_idx
                member[new_idx] = [i]
            new_idx += 1
        nn = new_idx
        new_adj = [[0.0]*nn for _ in range(nn)]
        for i in range(n):
            for j in range(n):
                ni, nj = mapping_c[i], mapping_c[j]
                if ni != nj:
                    new_adj[ni][nj] += adj_w[i][j]
        return nn, new_adj, member

    # Build coarsening levels
    levels = [(list(range(len(logical_qubits))), [row[:] for row in W_orig])]
    while levels[-1][0] is not None and len(levels[-1][0]) > min_size:
        nn, new_adj, member = coarsen(levels[-1][0], levels[-1][1])
        levels.append((list(range(nn)), new_adj, member))
        if nn >= len(levels[-2][0]):
            break  # no progress

    # Solve at coarsest level
    coarse_nodes = levels[-1][0]
    coarse_adj = levels[-1][1]
    nc = len(coarse_nodes)
    phys_nodes = list(range(min(nc, n_phys)))

    mean_dist = {p: sum(self.distance_matrix[p].get(p2,0) for p2 in range(n_phys) if p2!=p)/max(n_phys-1,1)
                 for p in range(n_phys)}
    coarse_w = [sum(coarse_adj[i]) for i in range(nc)]
    sorted_c = sorted(range(nc), key=lambda i: coarse_w[i], reverse=True)
    sorted_p = sorted(range(n_phys), key=lambda p: mean_dist[p])
    coarse_map = {sorted_c[i]: sorted_p[i] for i in range(min(nc, n_phys))}

    # Uncoarsen: assign original logical qubits
    def uncoarsen(coarse_m, level_members, logical_qubits_at_level, parent_adj):
        fine_map = {}
        used_p = set(coarse_m.values())
        for coarse_idx, phys in coarse_m.items():
            members = level_members.get(coarse_idx, [coarse_idx])
            if len(members) == 1:
                fine_map[logical_qubits_at_level[members[0]]] = phys
            else:
                fine_map[logical_qubits_at_level[members[0]]] = phys
                # Find best neighbor for second member
                best_p2, best_d = None, float('inf')
                for p2 in range(n_phys):
                    if p2 not in used_p:
                        d = self.distance_matrix[phys].get(p2, 999)
                        if d < best_d:
                            best_d, best_p2 = d, p2
                if best_p2 is not None:
                    fine_map[logical_qubits_at_level[members[1]]] = best_p2
                    used_p.add(best_p2)
        return fine_map, used_p

    # Walk back through levels
    current_map = coarse_map
    for level_idx in range(len(levels)-1, 0, -1):
        if len(levels[level_idx]) == 3:
            _, _, member = levels[level_idx]
        else:
            break
        parent_nodes = levels[level_idx-1][0]
        current_map, _ = uncoarsen(current_map, member, parent_nodes, levels[level_idx-1][1])

    mapping = {}
    for log_i, phys in current_map.items():
        if isinstance(log_i, int) and log_i < len(logical_qubits):
            mapping[logical_qubits[log_i]] = phys

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in logical_qubits:
```

IDEA_NAME: Force-Directed Spring Embedding with Procrustes Refinement

DESCRIPTION: Model both the circuit interaction graph and the hardware topology graph as spring-mass systems. Run force-directed layout independently on each, producing 2D positions for logical and physical qubits. Align the two point clouds using Procrustes analysis (rotation + reflection). Assign using the Hungarian algorithm on the pairwise Euclidean distance matrix between aligned embeddings.

ALGORITHMIC_APPROACH:
1. Force-directed layout for interaction graph: attractive force ∝ W[q1][q2], repulsive force ∝ 1/dist² (Fruchterman-Reingold style, ~100 iterations)
2. Force-directed layout for hardware: same algorithm on hardware adjacency
3. Procrustes alignment: compute optimal rotation R = V Uᵀ from SVD(X_hw^T X_circ)
4. Cost matrix C[l][p] = ||pos_circ[l] − R×pos_hw[p]||₂
5. Hungarian algorithm on C → bijective assignment

COLLISION_PREVENTION: Hungarian algorithm guarantees perfect bipartite matching. Force-directed layouts produce unique positions (with near-zero probability of exact collision), and even if two positions coincide, the Hungarian algorithm resolves ties by minimizing global cost.

WHY_NOVEL: Force-directed layouts are used extensively for graph visualization but have never been applied to quantum placement. The idea of treating the circuit and hardware as two separate "universes" with their own physical dynamics, then finding the best geometric alignment between them, is a creative cross-domain application. It provides a natural way to handle arbitrary hardware topologies without assuming any structural regularity.

NOVELTY_SCORE: 7
PROBABILITY_SCORE: 6
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.3

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_force_directed(self, iterations=100, k_scale=1.0):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    W = self._build_interaction_weight_matrix(logical_qubits)

    def fruchterman_reingold(n, adj, iters=100):
        np.random.seed(42)
        pos = np.random.rand(n, 2)
        area = n * k_scale
        k = np.sqrt(area / n)
        for t_iter in range(iters):
            temp = 1.0 - t_iter / iters
            disp = np.zeros((n, 2))
            for i in range(n):
                for j in range(i+1, n):
                    delta = pos[i] - pos[j]
                    dist = max(np.linalg.norm(delta), 1e-6)
                    repulse = (k**2 / dist**2) * delta
                    disp[i] += repulse
                    disp[j] -= repulse
                    if adj[i][j] > 0:
                        attract = (dist**2 / k) * adj[i][j] * delta / dist
                        disp[i] -= attract
                        disp[j] += attract
            for i in range(n):
                d = np.linalg.norm(disp[i])
                if d > 0:
                    pos[i] += (disp[i] / d) * min(d, temp)
        return pos

    pos_circ = fruchterman_reingold(n_log, W)

    H = [[0.0]*n_phys for _ in range(n_phys)]
    for p, nbs in self.backend.items():
        for nb in nbs:
            if p < n_phys and nb < n_phys:
                H[p][nb] = 1.0
    pos_hw = fruchterman_reingold(n_phys, H)

    # Procrustes: align pos_hw[:n_log] to pos_circ
    A, B = pos_hw[:n_log], pos_circ
    M = A.T @ B
    U, _, Vt = np.linalg.svd(M)
    R = U @ Vt
    pos_hw_rot = pos_hw @ R

    cost = np.array([[np.linalg.norm(pos_circ[i] - pos_hw_rot[j])
                      for j in range(n_phys)] for i in range(n_log)])
    row_ind, col_ind = linear_sum_assignment(cost)
    mapping = {logical_qubits[r]: c for r, c in zip(row_ind, col_ind)}

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Extended Lookahead Window Greedy Placement

DESCRIPTION: Replicate the extended layer lookahead mechanism from Qlosure's routing heuristic, but apply it at placement time. Build the initial K-layer extended set (the same `create_leveled_extended_successor_set` used in routing), compute a placement score for each candidate complete assignment based on the weighted distance cost over the front + extended layers, and use greedy optimization to find a locally optimal placement within this window.

ALGORITHMIC_APPROACH:
1. Build `extended_layer` using the existing `create_leveled_extended_successor_set` from the Qlosure codebase
2. For a candidate placement (starting from identity/random), compute the placement cost identically to `qlosure_poly_heuristic` but at t=0 (before any routing)
3. Apply random restart hill climbing: propose random 2-qubit swaps in the mapping, accept if they reduce the placement cost
4. After convergence, finalize `mapping_dict` and `reverse_mapping_dict`

COLLISION_PREVENTION: The mapping is always a permutation: initialized as `list(range(n))`, and swaps always exchange two elements, preserving the permutation property. The bijection is maintained by construction at all times.

WHY_NOVEL: This approach directly optimizes the same cost function that the routing phase will use, but applies it at placement time. It essentially "pre-runs" one step of the Qlosure routing heuristic to find the placement that minimizes the heuristic from the very first gate, creating tight coupling between placement and routing objective. No prior work directly optimizes the routing heuristic's cost function at placement time.

NOVELTY_SCORE: 7
PROBABILITY_SCORE: 9
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.5

```python
import random
from src.mapping.heuristic import create_leveled_extended_successor_set

def init_mapping_extended_lookahead_greedy(self, look_ahead_param=5, n_restarts=50, n_iter_per_restart=200):
    """Uses Qlosure's own heuristic cost at t=0 to optimize placement."""
    n = self.num_qubits

    # Build DAGs if not yet built — called after generate_dag
    if not hasattr(self, 'dag2q') or self.dag2q is None:
        return  # fallback: called inside run() after DAG construction

    # Compute front layer once
    front = set()
    for gate in self.dag_full:
        if len(self.dag_predecessors_full[gate]) == 0:
            front.add(gate)

    logical_qubits_in_front = [q for g in front for q in self.access2q.get(g, [])]
    phys_active = set(range(min(len(logical_qubits_in_front)*2, n)))
    extended, ext_index = create_leveled_extended_successor_set(
        front, self.dag2q_restricted, self.access2q,
        len(phys_active)*look_ahead_param)

    def placement_cost(mapping_d):
        f_distance = 0
        front_size = max(len(front), 1)
        for g in front:
            if g not in self.access2q:
                continue
            q1, q2 = self.access2q[g]
            Q1, Q2 = mapping_d.get(q1, q1), mapping_d.get(q2, q2)
            deps = self.dag_dependencies_count.get(g, 0)
            f_distance += (deps+1) * self.distance_matrix[Q1].get(Q2, 999)

        e_distance = 0
        ext_size = max(len(extended), 1)
        for g in extended:
            if g not in self.access2q:
                continue
            q1, q2 = self.access2q[g]
            Q1, Q2 = mapping_d.get(q1, q1), mapping_d.get(q2, q2)
            layer_f = ext_index.get(g, 0) + 1
            deps = self.dag_dependencies_count.get(g, 0)
            e_distance += (deps+1) * self.distance_matrix[Q1].get(Q2, 999) / layer_f

        return f_distance / front_size + (e_distance / ext_size if ext_size else 0)

    all_log_qubits = sorted(set(q for qs in self.access.values() for q in qs))
    best_mapping = {q: q for q in range(n)}
    best_cost = placement_cost(best_mapping)

    for _ in range(n_restarts):
        perm = list(range(n))
        random.shuffle(perm)
        mapping_d = {lq: perm[i] for i, lq in enumerate(all_log_qubits)}
        mapping_d.update({q: perm[len(all_log_qubits)+i]
                          for i, q in enumerate(range(n))
                          if q not in mapping_d and len(all_log_qubits)+i < n})

        for _ in range(n_iter_per_restart):
            i, j = random.sample(range(n), 2)
            perm[i], perm[j] = perm[j], perm[i]
            new_mapping = {lq: perm[k] for k, lq in enumerate(all_log_qubits)}
            new_cost = placement_cost(new_mapping)
            if new_cost < best_cost:
                best_cost = new_cost
                best_mapping = dict(new_mapping)
            else:
                perm[i], perm[j] = perm[j], perm[i]

    used = set(best_mapping.values())
    rem = [p for p in range(n) if p not in used]
    for q in all_log_qubits:
        if q not in best_mapping:
            best_mapping[q] = rem.pop(0)

    self.mapping_dict = best_mapping
    self.reverse_mapping_dict = {v: k for k, v in best_mapping.items()}
    self.mapping = [best_mapping.get(i, i) for i in range(n)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n)]
```

IDEA_NAME: Degree-Sequence Histogram Matching with Local Search

DESCRIPTION: Compute the weighted degree sequence of the circuit interaction graph (each logical qubit's total interaction weight) and the degree sequence of the hardware graph (physical qubit connectivity degree). Match logical qubits to physical qubits such that the degree sequences align as closely as possible — highest-degree logical qubit to highest-degree physical qubit — then refine with a tabu-search-inspired local improvement that avoids revisiting recently tried swaps.

ALGORITHMIC_APPROACH:
1. Compute degree_L[q] = sum of W[q][q'] for all q' (logical interaction degree)
2. Compute degree_P[p] = number of hardware edges incident to p
3. Sort both by degree descending; assign rank-by-rank as initial mapping
4. Tabu search: maintain tabu list of recently swapped (q1, q2) pairs; propose random swaps from non-tabu pairs; accept if total weighted routing cost decreases; tabu tenure = sqrt(n)
5. Terminate after n²/4 evaluations; return best found mapping

COLLISION_PREVENTION: The mapping is initialized as a bijection (rank-to-rank assignment is a permutation). Tabu search only ever swaps two existing assignments (exchanging physical qubits between two logical qubits), which maintains the permutation property. The tabu list prevents cycles without affecting bijectivity.

WHY_NOVEL: Tabu search has been applied to routing but not to quantum initial placement. The degree-sequence initialization (not random) provides a much better starting point than random for tabu search, and the combination of a principled initialization with tabu search's non-greedy exploration (ability to temporarily worsen the solution to escape local optima) is novel for this problem.

NOVELTY_SCORE: 6
PROBABILITY_SCORE: 8
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 7.8

```python
import random

def init_mapping_tabu_degree(self, tabu_tenure=None, max_evals=None):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    W = self._build_interaction_weight_matrix(logical_qubits)
    idx = {q: i for i, q in enumerate(logical_qubits)}

    degree_L = {q: sum(W[idx[q]]) for q in logical_qubits}
    degree_P = {p: len(self.backend.get(p, [])) for p in range(n_phys)}

    sorted_L = sorted(logical_qubits, key=lambda q: degree_L[q], reverse=True)
    sorted_P = sorted(range(n_phys), key=lambda p: degree_P[p], reverse=True)

    perm = list(range(n_phys))
    # Initial mapping: rank-by-rank
    for rank, (lq, pq) in enumerate(zip(sorted_L, sorted_P)):
        perm[rank] = pq
    for i in range(n_log, n_phys):
        pass  # remaining physical qubits stay as-is

    def cost(perm):
        total = 0
        for i, lq in enumerate(logical_qubits):
            for j, lq2 in enumerate(logical_qubits):
                if j <= i:
                    continue
                w = W[i][j]
                if w > 0:
                    total += w * self.distance_matrix[perm[i]].get(perm[j], 999)
        return total

    tabu = {}
    tenure = tabu_tenure or max(5, int(n_log**0.5))
    evals = max_evals or max(100, n_log*n_log//4)

    best_perm = list(perm)
    best_cost = cost(perm)
    current_cost = best_cost
    t = 0

    for t in range(evals):
        i, j = random.sample(range(n_log), 2)
        if (i, j) in tabu or (j, i) in tabu:
            continue
        perm[i], perm[j] = perm[j], perm[i]
        new_cost = cost(perm)
        if new_cost < best_cost or new_cost < current_cost:
            current_cost = new_cost
            tabu[(i, j)] = t + tenure
            if new_cost < best_cost:
                best_cost = new_cost
                best_perm = list(perm)
        else:
            perm[i], perm[j] = perm[j], perm[i]
        # Remove expired tabu entries
        tabu = {k: v for k, v in tabu.items() if v > t}

    mapping = {logical_qubits[i]: best_perm[i] for i in range(n_log)}
    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Qubit Interaction Tensor Decomposition Placement

DESCRIPTION: Model the 3-dimensional qubit interaction tensor T[q1][q2][layer] where T[q1][q2][t] = dependency-weighted count of gates between q1 and q2 at temporal layer t. Apply CP tensor decomposition to extract rank-r factor matrices. The first factor matrix (rank × n_logical) captures each qubit's "interaction mode" vector. Use these mode vectors to embed logical qubits in latent space, then align with hardware embedding and assign via Hungarian.

ALGORITHMIC_APPROACH:
1. Build T[q1][q2][t] using layer indices from dag_dependencies_count
2. Compute CP decomposition via alternating least squares (ALS): T ≈ Σ_r a_r ⊗ b_r ⊗ c_r
3. Factor matrix A (n_logical × rank) = qubit mode vectors
4. Analogously embed hardware: use H[p1][p2] = 1/dist(p1,p2) and replicate to 3D (or use hardware distance tensor)
5. Align embeddings via Procrustes; assign via Hungarian

COLLISION_PREVENTION: Final assignment via Hungarian algorithm on Euclidean distance between aligned embeddings. Hungarian always produces a perfect matching (bijection) when the cost matrix is fully defined.

WHY_NOVEL: No prior quantum placement work models interaction patterns as a 3D tensor. The time dimension captures the temporal evolution of interaction needs, which is entirely absent from 2D interaction graph approaches. CP decomposition extracts latent "interaction modes" that represent clusters of qubits participating in synchronized interaction patterns — a structural feature invisible to 2D analysis.

NOVELTY_SCORE: 9
PROBABILITY_SCORE: 6
EFFORT_SCORE: 5
FEASIBILITY_SCORE: 8
AVERAGE_SCORE: 7.0

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_tensor_decomposition(self, rank=4, max_als_iter=50):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    idx = {q: i for i, q in enumerate(logical_qubits)}

    # Build 3D tensor: T[i][j][layer]
    layers = {g: self.dag_dependencies_count.get(g, 0) for g in self.access2q}
    max_layer = max(layers.values(), default=0) + 1
    n_layers = min(max_layer + 1, 20)  # cap for efficiency

    T = np.zeros((n_log, n_log, n_layers))
    for gate, qubits in self.access2q.items():
        q1, q2 = qubits
        if q1 not in idx or q2 not in idx:
            continue
        t = min(layers[gate], n_layers - 1)
        w = self.dag_dependencies_count[gate] + 1
        T[idx[q1]][idx[q2]][t] += w
        T[idx[q2]][idx[q1]][t] += w

    # Simple CP-ALS: find A (n_log x rank) such that T ≈ A factor
    # For placement, we just need A's row vectors (qubit embeddings)
    r = min(rank, n_log - 1, n_layers - 1)
    np.random.seed(42)
    A = np.random.rand(n_log, r)
    B = np.random.rand(n_log, r)
    C = np.random.rand(n_layers, r)

    # Unfold T along mode 0: T_(0) shape (n_log, n_log*n_layers)
    T0 = T.reshape(n_log, -1)
    for _ in range(max_als_iter):
        # Update A: A = T_(0) (C khatri-rao B) pinv
        kr_BC = np.array([np.kron(C[:, rc], B[:, rc]) for rc in range(r)]).T
        A = T0 @ kr_BC @ np.linalg.pinv(B.T @ B * (C.T @ C))

        T1 = T.transpose(1, 0, 2).reshape(n_log, -1)
        kr_AC = np.array([np.kron(C[:, rc], A[:, rc]) for rc in range(r)]).T
        B = T1 @ kr_AC @ np.linalg.pinv(A.T @ A * (C.T @ C))

        T2 = T.transpose(2, 0, 1).reshape(n_layers, -1)
        kr_AB = np.array([np.kron(B[:, rc], A[:, rc]) for rc in range(r)]).T
        C = T2 @ kr_AB @ np.linalg.pinv(A.T @ A * (B.T @ B))

    # Hardware embedding: use distance matrix as proxy
    H_dist = np.array([[self.distance_matrix[i].get(j, 0)
                        for j in range(n_phys)] for i in range(n_phys)], dtype=float)
    _, X_hw = np.linalg.eigh(-H_dist)
    X_hw = X_hw[:, -r:]  # top-r eigenvectors

    # Align A (n_log x r) with X_hw (n_phys x r) via Procrustes
    M = X_hw[:n_log].T @ A
    U, _, Vt = np.linalg.svd(M)
    R = U @ Vt
    X_hw_rot = X_hw @ R

    cost = np.array([[np.linalg.norm(A[i] - X_hw_rot[j])
                      for j in range(n_phys)] for i in range(n_log)])
    row_ind, col_ind = linear_sum_assignment(cost)
    mapping = {logical_qubits[r_]: c for r_, c in zip(row_ind, col_ind)}

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```

IDEA_NAME: Node Embedding Alignment via Random Walk Statistics

DESCRIPTION: Generate node embeddings for both the circuit interaction graph and the hardware graph using random walk statistics (analogous to node2vec/DeepWalk, but computed analytically via power iteration on the transition matrix). Each qubit is represented by its stationary visit distribution over random walks of length L. Align the two embedding spaces using Procrustes and assign via Hungarian.

ALGORITHMIC_APPROACH:
1. Transition matrix M_c[i][j] = W[i][j] / sum_k(W[i][k]) for interaction graph
2. Transition matrix M_h[p][q] = 1/degree(p) if edge(p,q) else 0
3. Embedding X_c[q] = concatenate [M_c^1[q], M_c^2[q], ..., M_c^L[q]] (walk distribution at each step)
4. Embedding X_h[p] = same for hardware
5. Procrustes alignment + Hungarian matching

COLLISION_PREVENTION: Hungarian algorithm on the fully-defined cost matrix guarantees a perfect bijective matching.

WHY_NOVEL: While node2vec uses random walks with learned embeddings (requiring neural network training), this approach computes walk distribution embeddings analytically via matrix exponentiation — making it deterministic, parameter-free (beyond walk length L), and computable in O(n³) without any training. The use of multi-hop walk distributions to capture structural similarity between graphs for quantum placement is novel.

NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.8

```python
import numpy as np
from scipy.optimize import linear_sum_assignment

def init_mapping_random_walk_embedding(self, walk_length=5):
    logical_qubits = self._get_logical_qubits()
    n_log = len(logical_qubits)
    n_phys = self.num_qubits
    W = np.array(self._build_interaction_weight_matrix(logical_qubits), dtype=float)

    # Transition matrix for interaction graph
    row_sums = W.sum(axis=1, keepdims=True)
    row_sums[row_sums == 0] = 1
    M_c = W / row_sums

    # Transition matrix for hardware graph
    M_h = np.zeros((n_phys, n_phys))
    for p, nbs in self.backend.items():
        if p < n_phys and nbs:
            for nb in nbs:
                if nb < n_phys:
                    M_h[p][nb] = 1.0 / len(nbs)

    # Build embeddings: concatenate walk distributions at each step
    def walk_embedding(M, n, L):
        emb = []
        current = np.eye(n)
        for _ in range(L):
            current = current @ M
            emb.append(current)
        return np.hstack(emb)  # shape (n, n*L)

    X_c = walk_embedding(M_c, n_log, walk_length)
    X_h = walk_embedding(M_h, n_phys, walk_length)

    # Align dimensions
    dim = min(X_c.shape[1], X_h.shape[1])
    X_c, X_h = X_c[:, :dim], X_h[:, :dim]

    # Procrustes: align X_h[:n_log] → X_c
    if n_log <= n_phys:
        M_align = X_h[:n_log].T @ X_c
    else:
        M_align = X_h.T @ X_c[:n_phys]
    U, _, Vt = np.linalg.svd(M_align)
    R = U @ Vt
    X_h_rot = X_h @ R

    cost = np.array([[np.linalg.norm(X_c[i] - X_h_rot[j])
                      for j in range(n_phys)] for i in range(n_log)])
    row_ind, col_ind = linear_sum_assignment(cost)
    mapping = {logical_qubits[r]: c for r, c in zip(row_ind, col_ind)}

    used = set(mapping.values())
    rem = [p for p in range(n_phys) if p not in used]
    for q in set(q for qs in self.access.values() for q in qs):
        if q not in mapping:
            mapping[q] = rem.pop(0)

    self.mapping_dict = mapping
    self.reverse_mapping_dict = {v: k for k, v in mapping.items()}
    self.mapping = [mapping.get(i, i) for i in range(n_phys)]
    self.reverse_mapping = [self.reverse_mapping_dict.get(i, i) for i in range(n_phys)]
```
