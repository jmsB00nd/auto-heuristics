## `init_mapping` — Extended Lookahead Window Greedy Placement (ELWGP)

```python
def init_mapping(self):
    from collections import defaultdict

    # ── Step 1: Collect logical qubits ──────────────────────────────────
    logical_qubit_set = set()
    for gate, qubits in self.access.items():
        for q in qubits:
            logical_qubit_set.add(q)

    logical_qubits = sorted(logical_qubit_set)
    physical_qubits = sorted(self.backend.keys())

    # Trivial fallback: no gates
    if not logical_qubits:
        self.mapping_dict = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # ── Step 2: Build DAG for Extended Lookahead Window ─────────────────
    # Mirrors exactly what run() does, giving us the same structure the
    # routing heuristic later uses.
    successors2q, dag_predecessors2q, _, _, access2q = generate_dag(
        self.access, self.write_dict, self.num_qubits,
        enforce_read_after_read=True, transitive_reduction=True
    )

    # Dependency counts (critical-path weight) for each 2q gate
    deps_count = compute_transitive_closure_bitset(successors2q, dag_predecessors2q)

    # ── Step 3: Build initial front layer and extended lookahead set ─────
    front_layer_2q = set(
        g for g in successors2q
        if len(dag_predecessors2q.get(g, set())) == 0
    )

    # Extended set size: mirrors routing default (|active phys qubits| * look_ahead_param=5)
    num_active = max(len(front_layer_2q) * 2, 1)
    extended_set_size = num_active * 5

    extended_layer, extended_layer_index = create_leveled_extended_successor_set(
        front_layer_2q, successors2q, access2q, extended_set_size
    )

    front_size = len(front_layer_2q)
    extended_size = len(extended_layer)

    # ── Step 4: Seed placement via interaction-weighted BFS ──────────────
    # Anchor the highest-interaction logical qubit to the most central
    # physical qubit, then greedily expand by interaction weight.
    interaction_neighbors = defaultdict(dict)
    weighted_degree = defaultdict(float)
    for gate, qubits in self.access.items():
        if len(qubits) == 2:
            q1, q2 = qubits[0], qubits[1]
            w = 1.0
            interaction_neighbors[q1][q2] = interaction_neighbors[q1].get(q2, 0) + w
            interaction_neighbors[q2][q1] = interaction_neighbors[q2].get(q1, 0) + w
            weighted_degree[q1] += w
            weighted_degree[q2] += w

    anchor_logical = max(logical_qubits, key=lambda q: weighted_degree[q])

    def mean_dist(p):
        finite = [self.distance_matrix[p][o] for o in physical_qubits
                  if o != p and self.distance_matrix[p][o] != float('inf')]
        return sum(finite) / len(finite) if finite else float('inf')

    anchor_physical = min(physical_qubits, key=mean_dist)

    lq_to_phys = {anchor_logical: anchor_physical}
    placed_phys = {anchor_physical}
    unplaced = [lq for lq in logical_qubits if lq != anchor_logical]

    while unplaced:
        next_lq = max(
            unplaced,
            key=lambda lq: sum(interaction_neighbors[lq].get(pl, 0) for pl in lq_to_phys)
        )
        candidates = [nb for phys in placed_phys for nb in self.backend[phys]
                      if nb not in placed_phys]
        if not candidates:
            candidates = [p for p in physical_qubits if p not in placed_phys]
        if not candidates:
            break

        def _seed_cost(phys_c, _lq=next_lq):
            return sum(
                interaction_neighbors[_lq].get(pl, 0) *
                (self.distance_matrix[phys_c][pp] if self.distance_matrix[phys_c][pp] != float('inf') else 1e9)
                for pl, pp in lq_to_phys.items()
            )

        best_phys = min(candidates, key=_seed_cost)
        lq_to_phys[next_lq] = best_phys
        placed_phys.add(best_phys)
        unplaced.remove(next_lq)

    remaining_phys = sorted([p for p in physical_qubits if p not in placed_phys],
                             key=lambda p: len(self.backend[p]), reverse=True)
    for lq, phys in zip(unplaced, remaining_phys):
        lq_to_phys[lq] = phys

    # Materialise into strict 1-to-1 bijection arrays
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))

    for lq, target_phys in lq_to_phys.items():
        cur = mapping_dict[lq]
        if cur == target_phys:
            continue
        displaced = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced] = cur
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[cur] = displaced

    # ── Step 5: ELWGP local search ───────────────────────────────────────
    # No 2-qubit gates ready to schedule → placement makes no difference yet
    if front_size == 0:
        self.mapping_dict = mapping_dict
        self.reverse_mapping_dict = reverse_mapping_dict
        if self.use_isl:
            self.isl_mapping = dict_to_isl_map(self.mapping_dict)
        return

    # Index logical qubit → list of (is_front: bool, gate_id) for O(1) delta
    lq_to_gates: dict = defaultdict(list)
    for g in front_layer_2q:
        q1, q2 = access2q[g]
        lq_to_gates[q1].append((True, g))
        lq_to_gates[q2].append((True, g))
    for g in extended_layer:
        q1, q2 = access2q[g]
        lq_to_gates[q1].append((False, g))
        lq_to_gates[q2].append((False, g))

    W = 1.0

    def _delta(la: int, lb: int) -> float:
        """Score change from swapping physical assignments of logical la ↔ lb."""
        phys_a = mapping_dict[la]
        phys_b = mapping_dict[lb]

        # Unique affected gates (a gate touching both la and lb is counted once)
        seen: set = set()
        affected = []
        for entry in lq_to_gates[la]:
            seen.add(entry[1])
            affected.append(entry)
        for entry in lq_to_gates[lb]:
            if entry[1] not in seen:
                affected.append(entry)

        delta = 0.0
        for is_front, g in affected:
            q1, q2 = access2q[g]
            P1 = mapping_dict[q1]
            P2 = mapping_dict[q2]
            d_old = self.distance_matrix[P1][P2]
            if d_old == float('inf'):
                d_old = 1e9

            # Physical assignment after swapping la↔lb
            P1_new = phys_b if q1 == la else (phys_a if q1 == lb else P1)
            P2_new = phys_b if q2 == la else (phys_a if q2 == lb else P2)
            d_new = self.distance_matrix[P1_new][P2_new]
            if d_new == float('inf'):
                d_new = 1e9

            w_gate = deps_count[g] + 1
            if is_front:
                delta += w_gate * (d_new - d_old) / front_size
            else:
                lf = extended_layer_index.get(g, 0) + 1
                delta += W * w_gate * (d_new - d_old) / (lf * extended_size)

        return delta

    # Steepest-descent pairwise local search over logical qubit assignments
    max_iterations = 30
    for _ in range(max_iterations):
        best_delta = -1e-10
        best_la = best_lb = -1

        for i in range(len(logical_qubits)):
            for j in range(i + 1, len(logical_qubits)):
                la = logical_qubits[i]
                lb = logical_qubits[j]
                d = _delta(la, lb)
                if d < best_delta:
                    best_delta = d
                    best_la, best_lb = la, lb

        if best_la == -1:
            break  # Converged: no improving swap exists

        # Apply the best logical-qubit swap to mapping arrays
        phys_a = mapping_dict[best_la]
        phys_b = mapping_dict[best_lb]
        mapping_dict[best_la] = phys_b
        mapping_dict[best_lb] = phys_a
        reverse_mapping_dict[phys_a] = best_lb
        reverse_mapping_dict[phys_b] = best_la

    # ── Commit ───────────────────────────────────────────────────────────
    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict

    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

## Algorithm walkthrough

**Phase 1 — DAG + lookahead window construction** (`generate_dag` + `create_leveled_extended_successor_set`, same calls as routing)

The 2-qubit DAG is built with `enforce_read_after_read=True, transitive_reduction=True` — identical to what `run()` uses. `compute_transitive_closure_bitset` gives each gate a critical-path depth count `deps_count[g]`, which is the exact weight already used by the routing heuristic. `create_leveled_extended_successor_set` produces the K-layer lookahead set with each gate's `layer_index` — again identical to routing.

**Phase 2 — Interaction-weighted BFS seed** (the existing placement strategy)

Places the busiest logical qubit on the most central physical qubit, then iteratively places the logical qubit with the highest interaction weight to already-placed qubits onto the best adjacent physical location. This gives a high-quality warm start.

**Phase 3 — ELWGP steepest-descent local search**

The objective is the Qlosure routing cost function evaluated *statically* over the placement:

```
Score(mapping) = Σ_{g ∈ F} (deps[g]+1)·dist(Q1,Q2) / |F|
              + W · Σ_{g ∈ E} (deps[g]+1)·dist(Q1,Q2) / (layer_idx[g]+1) / |E|
```

This is exactly `qlosure_poly_heuristic` without the decay term (irrelevant at placement time). Each iteration scans all O(n²) pairs of logical qubits and picks the single swap with the largest score decrease (steepest descent). The `_delta` function evaluates only the O(degree) gates touching the two candidate qubits, making each probe O(|F|+|E|) in the worst case but typically O(1) for sparse circuits. The loop stops when no improving swap exists or after 30 iterations.

**Validity guarantee**: The bijection is maintained by construction throughout — both the seed phase (in-place swaps on the identity permutation) and the local search phase (swap both `mapping_dict` and `reverse_mapping_dict` symmetrically).

**Complexity**: O(G log G) DAG build + O(G·Q) closure + O(iter · n² · (|F|+|E|)) local search — all polynomial.
