The user needs to approve the file write. Once approved, the implementation will replace the existing `init_mapping` with the Centrality Rank Bipartite Assignment algorithm. Here's a summary of what the implementation does:

**Algorithm breakdown:**

**Step 1 — Interaction graph:** Build from `self.access`, tracking edge weights (co-occurrence count) and recording 2-qubit gate order for dependency estimation.

**Step 2 — Logical qubit composite centrality (3 components, each normalised to [0,1]):**
- `weighted_degree[q]` — total interaction weight on edges incident to q
- `interaction_degree[q]` — number of distinct 2-qubit partners (unweighted degree)
- `max_dag_dep[q]` — max over 2q-gates touching q of `(N₂q − gate_position)`, approximating downstream dependency depth without needing the full DAG

**Step 3 — Physical qubit composite centrality (2 components, normalised):**
- `hw_degree[p]` — number of hardware neighbours
- `closeness(p)` = `|reachable| / Σdist` — standard closeness centrality via the precomputed `distance_matrix`

**Step 4–5 — Rank-to-rank bipartite assignment with tie-breaking:**
- Sort both logical and physical lists by score descending
- Assign positionally (rank 0 → rank 0, rank 1 → rank 1, …)
- Within score-tied logical groups: greedy O(k²) matching against the corresponding physical slots, minimising total weighted distance to already-placed interaction partners

**Step 6–7 — Validity guarantee:** Isolated (non-interacting) logical qubits fill remaining physical slots; the identity permutation + in-place swap construction guarantees a strict 1-to-1 bijection over all `num_qubits` indices.
