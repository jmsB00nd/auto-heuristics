IDEA_NAME: Spectral Laplacian Dual Embedding Alignment
DESCRIPTION: Computes the normalized graph Laplacian for both the circuit interaction graph (logical qubits = nodes, 2Q gate counts = edge weights) and the hardware topology graph. Projects both graphs into the same low-dimensional Euclidean space via their smallest k eigenvectors (Fiedler vectors). Assigns logical qubits to physical qubits by solving a minimum-weight bipartite matching between their spectral coordinates using the Hungarian algorithm. The spectral embedding captures global structural similarity: qubits that are "spectrally close" in the interaction graph get mapped to physical qubits that are spectrally close in the hardware graph.
ALGORITHMIC_APPROACH:
  1. Build weighted interaction graph G_c: nodes = logical qubits, edge weight(q1,q2) = count of 2Q gates on (q1,q2).
  2. Build hardware graph G_h: nodes = physical qubits, edge weight = 1/distance.
  3. Compute normalized Laplacian L_c and L_h; extract eigenvectors v2..vk+1 (skip v1=constant).
  4. Embed logical qubits as rows of [v2..vk] from L_c; embed physical qubits from L_h.
  5. Compute pairwise Euclidean distance matrix between the two k-dim embeddings.
  6. Run scipy.optimize.linear_sum_assignment to find minimum-cost bijection.
  7. Apply universal bijection guarantee for unmapped qubits.
COLLISION_PREVENTION: Hungarian algorithm guarantees a perfect matching (bijection) on the square cost matrix. Unmapped logical qubits (no interactions) are greedily assigned to remaining physical qubits via the bijection swap trick.
WHY_NOVEL: No existing quantum compiler uses spectral graph theory to co-embed the circuit interaction graph AND hardware topology in the same eigenspace for placement. Current approaches (SABRE, VF2++, CCHPCR) are topology-matching or heuristic BFS — none exploit global spectral structure.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

```python
from scipy.sparse.linalg import eigsh
from scipy.optimize import linear_sum_assignment
from collections import defaultdict

def init_mapping_spectral(self):
    # Build interaction graph
    interact = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            interact[(min(q1,q2), max(q1,q2))] += 1.0
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    k = min(4, n_l - 1, n_p - 1)  # embedding dimension
    
    def laplacian_embed(nodes, edges_weighted, k):
        n = len(nodes)
        idx = {v: i for i, v in enumerate(nodes)}
        W = np.zeros((n, n))
        for (u, v), w in edges_weighted.items():
            i, j = idx.get(u, -1), idx.get(v, -1)
            if i >= 0 and j >= 0:
                W[i, j] = W[j, i] = w
        D = np.diag(W.sum(axis=1))
        L = D - W
        # Normalized Laplacian
        d = np.diag(D)
        d_inv_sqrt = np.where(d > 0, 1.0 / np.sqrt(d), 0.0)
        D_inv_sqrt = np.diag(d_inv_sqrt)
        L_norm = D_inv_sqrt @ L @ D_inv_sqrt
        if k <= 0 or n <= 1: return np.zeros((n, 1))
        vals, vecs = np.linalg.eigh(L_norm)
        return vecs[:, 1:k+1]  # skip trivial v1
    
    lc_embed = laplacian_embed(logical_qubits, 
                               {(logical_qubits[lq_idx[min(q1,q2)]], logical_qubits[lq_idx[max(q1,q2)]]): w 
                                for (q1,q2), w in interact.items()}, k)
    
    hw_edges = {(u, v): 1.0 for u in self.backend for v in self.backend[u] if u < v}
    lh_embed = laplacian_embed(phys_qubits, hw_edges, k)
    
    # Cost matrix: Euclidean distance between spectral coordinates
    cost = np.linalg.norm(lc_embed[:, np.newaxis, :] - lh_embed[np.newaxis, :, :], axis=2)
    row_ind, col_ind = linear_sum_assignment(cost)
    
    lq_to_phys = {}
    for r, c in zip(row_ind, col_ind):
        lq_to_phys[logical_qubits[r]] = phys_qubits[c]
    # ... apply universal bijection guarantee
```

IDEA_NAME: DAG Temporal Coexistence Window Clustering
DESCRIPTION: Extracts "coexistence windows" from the circuit DAG — time intervals (topological layers) where certain logical qubit pairs are simultaneously active in the front layer. Builds a "temporal coexistence graph" where edge weight between two logical qubits = number of distinct time windows they appear together. Uses community detection (Louvain-style greedy modularity) on this graph to cluster logical qubits into groups that are temporally co-active. Maps each cluster to a connected subgraph of the hardware via BFS seed expansion, ensuring intra-cluster qubits are physically close.
ALGORITHMIC_APPROACH:
  1. Topologically sort the 2Q DAG and extract leveled layers (gates with same topological depth).
  2. For each layer L, record the set of logical qubits that appear as operands of layer-L gates.
  3. For each pair (q1, q2) appearing in the same layer, increment coexistence_weight[q1][q2].
  4. Run greedy modularity community detection on the weighted coexistence graph.
  5. For each community, find its total interaction weight with each physical qubit subgraph region.
  6. Assign communities to hardware regions via greedy matching (highest weight community to densest region first).
  7. Within each community-region assignment, map individual qubits via interaction-weighted BFS.
  8. Apply bijection guarantee.
COLLISION_PREVENTION: Community assignment partitions logical qubits; within each partition, a greedy one-to-one assignment to distinct physical qubits is maintained by tracking used physical qubits in a set.
WHY_NOVEL: Unlike CCHPCR (which focuses on the single critical path), this captures ALL simultaneous execution patterns across ALL time windows, not just the bottleneck. The coexistence graph is a new intermediate representation not used in any known compiler placement pass.

IDEA_NAME: Weighted Centrality Fingerprint Bipartite Matching
DESCRIPTION: Extracts a multi-dimensional "centrality fingerprint" for each logical qubit from the circuit interaction graph, and for each physical qubit from the hardware graph. Fingerprint dimensions: (1) weighted degree, (2) betweenness centrality, (3) closeness centrality, (4) clustering coefficient, (5) k-core number. Builds a cost matrix where cost(lq, pq) = weighted Euclidean distance between their normalized fingerprints. Solves optimal bijection via the Hungarian algorithm (O(n³)). Unlike spectral methods, this uses local structural features rather than global eigenstructure.
ALGORITHMIC_APPROACH:
  1. Build weighted interaction graph from self.access (2Q gates).
  2. Compute 5 centrality metrics for each logical qubit (on interaction graph).
  3. Compute same 5 metrics for each physical qubit (on hardware graph using distance_matrix).
  4. Normalize each feature dimension to [0,1] across all nodes.
  5. Assign weights to each feature dimension (e.g., weighted_degree=2, betweenness=1.5, ...).
  6. Compute n_logical × n_physical cost matrix.
  7. Pad cost matrix to square (n_physical × n_physical) with dummy high-cost rows.
  8. Run scipy.optimize.linear_sum_assignment; assign results to lq_to_phys.
  9. Apply bijection guarantee.
COLLISION_PREVENTION: Hungarian algorithm on a square padded matrix guarantees a perfect matching. Each logical qubit gets exactly one physical qubit, and the bijection guarantee handles any unmapped residuals.
WHY_NOVEL: Existing methods use only one structural property (e.g., degree or path length). No prior work uses a multi-feature fingerprint vector + optimal bipartite matching combining both graph structural metrics simultaneously for quantum placement.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

```python
def init_mapping_fingerprint_matching(self):
    import numpy as np
    from scipy.optimize import linear_sum_assignment
    from collections import defaultdict
    
    # Build interaction graph adjacency and weights
    interact = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            interact[(q1, q2)] = interact.get((q1,q2), 0) + 1
            interact[(q2, q1)] = interact.get((q2,q1), 0) + 1
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    
    def compute_fingerprint_logical(lq):
        # weighted degree
        w_deg = sum(interact.get((lq, nb), 0) for nb in all_lq)
        # closeness: avg inverse distance in interaction graph (BFS on unweighted)
        # betweenness: approximated by counting paths through lq
        # clustering coefficient
        neighbors = [nb for nb in all_lq if interact.get((lq, nb), 0) > 0]
        tri = sum(1 for i, u in enumerate(neighbors) for v in neighbors[i+1:] 
                  if interact.get((u, v), 0) > 0)
        k = len(neighbors)
        cc = (2 * tri / (k * (k-1))) if k > 1 else 0.0
        return [w_deg, len(neighbors), cc, 0, 0]
    
    def compute_fingerprint_physical(pq):
        neighbors = self.backend[pq]
        k = len(neighbors)
        # degree, avg distance, clustering in hardware
        avg_dist = sum(self.distance_matrix[pq][nb] for nb in phys_qubits 
                      if self.distance_matrix[pq][nb] != float('inf')) / max(n_p-1, 1)
        cc = sum(1 for i, u in enumerate(neighbors) for v in neighbors[i+1:]
                 if v in self.backend[u]) / max(k*(k-1)/2, 1)
        return [k, avg_dist, cc, 0, 0]
    
    F_l = np.array([compute_fingerprint_logical(lq) for lq in logical_qubits], dtype=float)
    F_p = np.array([compute_fingerprint_physical(pq) for pq in phys_qubits], dtype=float)
    
    # Normalize
    for col in range(F_l.shape[1]):
        mx = max(F_l[:,col].max(), F_p[:,col].max(), 1e-9)
        F_l[:,col] /= mx
        F_p[:,col] /= mx
    
    # Cost matrix: Euclidean distance between fingerprints
    cost = np.linalg.norm(F_l[:, np.newaxis, :] - F_p[np.newaxis, :, :], axis=2)
    # Pad to square
    if n_l < n_p:
        pad = np.full((n_p - n_l, n_p), cost.max() * 2)
        cost_sq = np.vstack([cost, pad])
    else:
        cost_sq = cost
    
    row_ind, col_ind = linear_sum_assignment(cost_sq)
    lq_to_phys = {}
    for r, c in zip(row_ind, col_ind):
        if r < n_l:
            lq_to_phys[logical_qubits[r]] = phys_qubits[c]
    # ... bijection guarantee
```

IDEA_NAME: Multilevel Coarsening-Uncoarsening Placement (MCUP)
DESCRIPTION: Inspired by METIS-style multilevel graph partitioning. Repeatedly coarsens the circuit interaction graph by merging pairs of highly-interacting logical qubits into "super-qubits", producing a hierarchy of smaller graphs. Solves the placement problem optimally (or near-optimally) on the coarsest level where the problem is trivial, then uncoarsens back level-by-level, refining the placement at each level using a local improvement pass that tries swapping adjacent pairs.
ALGORITHMIC_APPROACH:
  1. Build weighted interaction graph G_0 from 2Q gates.
  2. Coarsen: repeatedly find the maximum-weight matching in G_current; merge matched pairs into super-nodes. Record coarsening history. Stop when < 8 super-qubits or no further merging possible.
  3. Solve initial placement on coarsest graph: at < 8 nodes, try all or greedy orderings against hardware, pick lowest total interaction-distance cost.
  4. Uncoarsen: at each level, split super-nodes back to constituent qubits. Place the two children on hardware neighbors of the super-node's assigned physical qubit.
  5. Local refinement at each level: try swapping adjacent logical-physical assignments to reduce total weighted distance; accept improvements.
  6. Apply bijection guarantee for remaining unmapped qubits.
COLLISION_PREVENTION: At each uncoarsening step, the two children of a super-node are assigned to distinct physical qubits (parent's current physical qubit + one free neighbor). The used-physical set is tracked throughout.
WHY_NOVEL: Multilevel graph coarsening is dominant in VLSI placement (METIS, hMETIS) but has never been applied to quantum circuit initial mapping. The hierarchical structure naturally captures multi-scale qubit interaction patterns.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 8
EFFORT_SCORE: 6
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.0

```python
def init_mapping_mcup(self):
    from collections import defaultdict
    
    # Build interaction graph
    interact_wt = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            key = (min(q1,q2), max(q1,q2))
            interact_wt[key] += 1.0
    
    # Represent graph as {node: {neighbor: weight}}
    def build_adj(nodes, edges):
        adj = {n: {} for n in nodes}
        for (u, v), w in edges.items():
            adj[u][v] = adj[u].get(v, 0) + w
            adj[v][u] = adj[v].get(u, 0) + w
        return adj
    
    # Coarsen: find maximal heavy-edge matching
    def coarsen(adj, node_map):
        """node_map: current_node -> set of original logical qubits"""
        nodes = list(adj.keys())
        matched = set()
        merges = []  # list of (u, v) to merge
        for u in sorted(nodes, key=lambda x: -max(adj[x].values(), default=0)):
            if u in matched: continue
            best_v = max(adj[u], key=lambda v: adj[u][v], default=None)
            if best_v and best_v not in matched:
                merges.append((u, best_v))
                matched.add(u); matched.add(best_v)
        
        # Build coarsened graph
        super_node_map = {}  # new_node -> set of original lqs
        new_adj = {}
        for u, v in merges:
            sn = min(u, v)  # use min as super-node ID
            super_node_map[sn] = node_map.get(u, {u}) | node_map.get(v, {v})
            new_adj[sn] = {}
        for u in nodes:
            if u not in matched:
                super_node_map[u] = node_map.get(u, {u})
                new_adj[u] = {}
        # ... rebuild edges for super-nodes (contract edges)
        return new_adj, super_node_map, merges
    
    # ... (coarsen loop, solve at coarsest, uncoarsen with local refinement)
```

IDEA_NAME: Quantum Walk Centrality Rank Matching
DESCRIPTION: Simulates a discrete-time quantum walk (or equivalently, computes the quantum hitting time) on both the circuit interaction graph and the hardware topology graph. Uses the quantum walk's long-time probability distribution (stationary distribution of the quantum walk) as a "centrality" measure for each node. Matches logical qubits to physical qubits by pairing nodes with the most similar quantum walk centrality ranks. The quantum walk captures higher-order connectivity patterns that classical random walks miss.
ALGORITHMIC_APPROACH:
  1. Build circuit interaction graph adjacency matrix A_c and hardware adjacency matrix A_h.
  2. Compute the quantum walk transition matrix: U = exp(i * A * t) for t=π/2 (discrete approximation: use A^2 normalized).
  3. Extract stationary-like distribution: compute |U_ij|^2 averaged over a few time steps → quantum centrality vector C_c[i] for logical qubits, C_h[i] for physical qubits.
  4. Sort both lists by quantum centrality (descending). Rank-match: logical qubit with rank k → physical qubit with rank k.
  5. Break rank ties using secondary criterion: weighted degree.
  6. Apply bijection guarantee.
COLLISION_PREVENTION: Rank matching on two sorted lists of the same length naturally produces a bijection. Ties are broken deterministically. Remaining (unmatched) qubits are assigned greedily.
WHY_NOVEL: Quantum walk theory has been used in quantum algorithm analysis but never applied to the placement problem. The quantum walk stationary distribution captures destructive/constructive interference patterns in the connectivity structure, giving a genuinely quantum-informed centrality beyond classical betweenness or closeness.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 6
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 7.8

```python
def init_mapping_quantum_walk(self):
    import numpy as np
    from collections import defaultdict
    
    interact = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            interact[(q1, q2)] += 1.0
            interact[(q2, q1)] += 1.0
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    
    def quantum_centrality(nodes, adj_func, n):
        A = np.zeros((n, n))
        for i, u in enumerate(nodes):
            for j, v in enumerate(nodes):
                A[i, j] = adj_func(u, v)
        # Normalize to get quantum walk coin: D^{-1/2} A D^{-1/2}
        d = A.sum(axis=1)
        d_inv_sqrt = np.where(d > 0, 1.0/np.sqrt(d), 0.0)
        D_inv = np.diag(d_inv_sqrt)
        H = D_inv @ A @ D_inv  # Hamiltonian
        # Simulate quantum walk: |psi(t)> = exp(-iHt)|psi(0)>
        # Approximate via Taylor: (I - iHt - H²t²/2) for t=1
        t = 1.0
        U_approx = np.eye(n) - 1j*t*H - (t**2/2)*H@H
        # Quantum centrality = time-averaged |amplitude|^2
        centrality = np.abs(U_approx).mean(axis=0)
        return centrality
    
    c_logical = quantum_centrality(logical_qubits,
        lambda u, v: interact.get((u,v), 0.0), n_l)
    
    hw_adj = {(phys_qubits[i], phys_qubits[j]): 1.0 
              for i, u in enumerate(phys_qubits) 
              for j, v in enumerate(phys_qubits) if v in self.backend[u]}
    c_phys = quantum_centrality(phys_qubits,
        lambda u, v: hw_adj.get((u,v), 0.0), n_p)
    
    # Rank sort and match
    lq_ranked = [logical_qubits[i] for i in np.argsort(-c_logical)]
    pq_ranked = [phys_qubits[i] for i in np.argsort(-c_phys)]
    
    lq_to_phys = {}
    for i, lq in enumerate(lq_ranked):
        if i < n_p:
            lq_to_phys[lq] = pq_ranked[i]
    # ... bijection guarantee
```

IDEA_NAME: Front-Layer Simulation Lookahead Placement (FSLP)
DESCRIPTION: Evaluates initial mapping candidates by actually simulating a short prefix of the routing algorithm. For each candidate mapping (generated by a fast seed heuristic), runs the Qlosure routing heuristic for a fixed number of SWAP steps T (e.g., T=20) and records the accumulated SWAP count. The mapping that produces the fewest SWAPs in the simulation prefix is selected as the final initial mapping. Uses a pool of diverse candidates: trivial, random seeds, BFS-expansion variants, and spectral.
ALGORITHMIC_APPROACH:
  1. Generate K=10-20 diverse candidate mappings using cheap methods: trivial, random (×5), BFS from different hardware seeds, degree-sorted.
  2. For each candidate, simulate the routing main loop for T=min(20, total_gates/10) SWAP steps using the Qlosure heuristic in a sandboxed copy (copy.deepcopy of relevant state).
  3. Record: (simulated_SWAP_count, simulated_depth) for each candidate.
  4. Lexicographically sort candidates by (swap_count, depth); take the best.
  5. Commit the winning mapping to self.mapping_dict / self.reverse_mapping_dict.
COLLISION_PREVENTION: All candidate mappings are generated by well-defined bijective methods (random shuffle, BFS expansion). The simulation does not alter the bijection property.
WHY_NOVEL: This is a direct "placement-by-routing-simulation" approach — using the routing heuristic itself as the fitness function for placement. Unlike SABRE (which does a full routing pass per iteration), FSLP uses only a short prefix simulation, making it cheap. The key novelty is the simulation-based fitness oracle.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 9
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

```python
def init_mapping_fslp(self, T=20, K=15):
    import copy, random
    from collections import defaultdict, deque
    
    def make_trivial():
        return list(range(self.num_qubits)), list(range(self.num_qubits))
    
    def make_random():
        phys = list(range(self.num_qubits))
        random.shuffle(phys)
        rev = [-1] * self.num_qubits
        for l, p in enumerate(phys): rev[p] = l
        return phys, rev
    
    def bfs_from_seed(seed_phys):
        # BFS-based expansion from hardware seed
        interact = defaultdict(float)
        all_lq = set()
        for qubits in self.access.values():
            for q in qubits: all_lq.add(q)
            if len(qubits) == 2:
                q1, q2 = qubits
                interact[(q1, q2)] += 1.0
                interact[(q2, q1)] += 1.0
        
        lq_by_degree = sorted(all_lq, 
            key=lambda q: -sum(interact.get((q,nb),0) for nb in all_lq))
        
        lq_to_phys = {}
        placed_phys = set()
        hw_queue = deque([seed_phys])
        placed_phys.add(seed_phys)
        lq_to_phys[lq_by_degree[0]] = seed_phys
        
        for i, lq in enumerate(lq_by_degree[1:], 1):
            candidates = [nb for p in list(lq_to_phys.values()) 
                         for nb in self.backend[p] if nb not in placed_phys]
            if not candidates:
                candidates = [p for p in self.backend if p not in placed_phys]
            if not candidates: break
            best = min(candidates, key=lambda p: sum(
                interact.get((lq, alq), 0) * self.distance_matrix[p][lq_to_phys[alq]]
                for alq in lq_to_phys if self.distance_matrix[p][lq_to_phys[alq]] != float('inf')
            ))
            lq_to_phys[lq] = best
            placed_phys.add(best)
        
        mapping = list(range(self.num_qubits))
        reverse = list(range(self.num_qubits))
        for lq, pq in lq_to_phys.items():
            cur = mapping[lq]
            if cur == pq: continue
            disp = reverse[pq]
            mapping[lq] = pq; mapping[disp] = cur
            reverse[pq] = lq; reverse[cur] = disp
        return mapping, reverse
    
    def simulate_prefix(mapping, reverse_mapping, T_steps):
        """Run T_steps of the Qlosure routing loop and count SWAPs."""
        # Temporarily set mappings and run partial execute_algorithm
        saved_map = self.mapping_dict
        saved_rev = self.reverse_mapping_dict
        self.mapping_dict = mapping[:]
        self.reverse_mapping_dict = reverse_mapping[:]
        # ... build temp DAG state, run T steps, count SWAPs
        # (requires pre-computed DAG from self.dag2q, etc.)
        swaps = 0
        self.mapping_dict = saved_map
        self.reverse_mapping_dict = saved_rev
        return swaps
    
    candidates = [make_trivial(), make_random()]
    for seed in list(self.backend.keys())[:5]:
        candidates.append(bfs_from_seed(seed))
    for _ in range(K - len(candidates)):
        candidates.append(make_random())
    
    # Evaluate and pick best
    best_swaps = float('inf')
    best_mapping, best_reverse = candidates[0]
    for mapping, reverse in candidates:
        sim_swaps = simulate_prefix(mapping, reverse, T)
        if sim_swaps < best_swaps:
            best_swaps = sim_swaps
            best_mapping, best_reverse = mapping, reverse
    
    self.mapping_dict = best_mapping
    self.reverse_mapping_dict = best_reverse
    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

Simultaneously bisects the hardware graph into equally-sized regions. Recursively maps each logical partition to its corresponding hardware region. This exploits the deep structural correspondence between the circuit's communication pattern and the hardware's topological structure.
ALGORITHMIC_APPROACH:

IDEA_NAME: Persistent Interaction Neighborhood Embedding (PINE)
DESCRIPTION: For each logical qubit q, computes its "k-hop interaction profile": a vector where entry k = total weight of interactions within k hops in the circuit interaction graph (i.e., sum of interaction weights reachable in exactly k hops). This profile captures how "locally dense" vs. "globally connected" each qubit is. Computes the same profile for each physical qubit based on hop-distance neighborhoods in the hardware. Matches logical to physical qubits by minimizing the L1 distance between their interaction neighborhood profiles via the Hungarian algorithm.
ALGORITHMIC_APPROACH:
  1. Build weighted interaction graph G_c.
  2. For each logical qubit q, BFS outward k=1,2,...,K hops; compute profile[q][k] = sum of interaction weights at hop k.
  3. Normalize profiles so profile[q][0] = 1.0 (or normalize by total interaction weight).
  4. For each physical qubit p, compute connectivity profile[p][k] = number of hardware nodes at hop k.
  5. Normalize physical profiles similarly.
  6. Build cost matrix: cost[lq][pq] = sum_k |profile_lq[k] - profile_pq[k]|.
  7. Solve via Hungarian algorithm → lq_to_phys.
  8. Bijection guarantee.
COLLISION_PREVENTION: Hungarian algorithm guarantees bijection. K-hop profiles are computed on the interaction graph independently for each qubit.
WHY_NOVEL: The k-hop interaction neighborhood profile is a novel fingerprint not used in quantum placement. Unlike degree or betweenness, it captures the multi-scale interaction density decay pattern around each qubit. The idea of matching decay profiles between circuit and hardware is fundamentally new.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

```python
def init_mapping_pine(self, K=5):
    import numpy as np
    from scipy.optimize import linear_sum_assignment
    from collections import defaultdict, deque
    
    interact = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            interact[(q1, q2)] += 1.0
            interact[(q2, q1)] += 1.0
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    
    def lq_profile(lq, K):
        profile = []
        visited = {lq}
        frontier = {lq}
        for k in range(1, K+1):
            next_frontier = set()
            layer_weight = 0.0
            for u in frontier:
                for v in all_lq:
                    if v not in visited and interact.get((u, v), 0) > 0:
                        layer_weight += interact[(u, v)]
                        next_frontier.add(v)
            visited |= next_frontier
            profile.append(layer_weight)
            frontier = next_frontier
            if not frontier: break
        while len(profile) < K: profile.append(0.0)
        return profile
    
    def pq_profile(pq, K):
        profile = []
        visited = {pq}
        frontier = {pq}
        for k in range(1, K+1):
            next_frontier = set()
            for u in frontier:
                for v in self.backend[u]:
                    if v not in visited:
                        next_frontier.add(v)
            count = len(next_frontier)
            profile.append(float(count))
            visited |= next_frontier
            frontier = next_frontier
            if not frontier: break
        while len(profile) < K: profile.append(0.0)
        return profile
    
    F_l = np.array([lq_profile(lq, K) for lq in logical_qubits])
    F_p = np.array([pq_profile(pq, K) for pq in phys_qubits])
    
    # Normalize
    for arr in [F_l, F_p]:
        row_sums = arr.sum(axis=1, keepdims=True)
        row_sums[row_sums == 0] = 1.0
        arr /= row_sums
    
    # Cost matrix
    cost = np.abs(F_l[:, np.newaxis, :] - F_p[np.newaxis, :, :]).sum(axis=2)
    if n_l < n_p:
        pad = np.full((n_p - n_l, n_p), 1e9)
        cost_sq = np.vstack([cost, pad])
    else:
        cost_sq = cost
    
    row_ind, col_ind = linear_sum_assignment(cost_sq)
    lq_to_phys = {logical_qubits[r]: phys_qubits[c] 
                  for r, c in zip(row_ind, col_ind) if r < n_l}
```

IDEA_NAME: DAG Critical Subgraph Hardware Isomorphism Seeding
DESCRIPTION: Instead of searching for full subgraph isomorphism (exponential), extracts the small subgraph induced by the "hot qubits" — the top-M most interacting logical qubits (M ≤ 8). Enumerates all M-node connected subgraphs of the hardware graph (polynomial for small M on sparse hardware). Scores each hardware subgraph candidate by computing the minimum-weight bipartite matching between the hot-qubit interaction subgraph and the hardware subgraph. The best-scoring hardware subgraph defines the seed placement for hot qubits; remaining qubits use interaction-weighted BFS.
ALGORITHMIC_APPROACH:
  1. Build interaction graph; compute weighted degree per logical qubit.
  2. Select top-M=min(8, n_logical) hot qubits by weighted degree.
  3. Extract induced interaction subgraph G_hot among hot qubits.
  4. Enumerate all connected M-node subgraphs of hardware (via BFS expansion from each hardware node up to depth D=3, deduplicated by frozenset).
  5. For each hardware subgraph candidate S, compute bipartite matching cost: find bijection between hot qubits and nodes of S minimizing total |interaction_dist - hardware_dist|.
  6. Select best-cost hardware subgraph; assign hot qubits to its nodes per matching.
  7. BFS-expand remaining qubits using interaction-weighted greedy.
  8. Bijection guarantee.
COLLISION_PREVENTION: The seed placement maps M distinct hot qubits to M distinct hardware nodes (enforced by bipartite matching). BFS expansion maintains a used-physical set.
WHY_NOVEL: This is a targeted, tractable alternative to full subgraph isomorphism: it restricts the search to the top-M most critical qubits and uses weighted matching (not exact isomorphism) as the score. The size constraint (M ≤ 8) keeps enumeration polynomial on sparse hardware graphs.

Compaction: repeatedly commute gates past each other (if they share no qubits) to maximize the size of the initial front layer. The resulting enlarged front layer exposes the true initial parallelism of the circuit, and the initial mapping optimizes placement for this maximally parallel start.

IDEA_NAME: Interaction Recency Decay Weighted Placement (IRDWP)
DESCRIPTION: Not all interactions are equally important — early interactions in the circuit are immediately relevant while late interactions matter less for initial placement (routing can adapt). Assigns a time-decayed weight to each interaction: weight(gate_g) = exp(-λ * layer_index(g)) where layer_index is the gate's topological depth. Builds a decay-weighted interaction graph and uses interaction-weighted BFS expansion (similar to CCHPCR step 6) but with decay-weighted edge costs. This focuses the initial placement on minimizing SWAP overhead for the circuit's early critical gates.
ALGORITHMIC_APPROACH:
  1. Compute topological depth (layer index) for each gate via Kahn's algorithm.
  2. Build decay-weighted interaction graph: edge_weight(q1, q2) = sum over all gates g on (q1,q2) of exp(-λ * layer_g). Use λ=0.1 as default.
  3. Find the highest decay-weighted degree qubit as anchor; place on highest-centrality hardware node.
  4. Greedy expansion: place unplaced qubit with highest total decay-weighted interaction to placed qubits, on the hardware candidate minimizing weighted distance cost.
  5. Bijection guarantee.
COLLISION_PREVENTION: Greedy expansion maintains used-physical tracking set. Bijection swap trick finalizes.
WHY_NOVEL: The temporal discount (recency decay) is standard in online learning and scheduling but has never been applied to quantum placement. The insight is that initial mapping quality is most impactful for early-circuit gates (before routing has had time to adapt), so early interactions should dominate the placement objective.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 8
EFFORT_SCORE: 9
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.5

Reference implementation sketch:
```python
def init_mapping_irdwp(self, decay_lambda=0.1):
    import math
    from collections import defaultdict, deque
    
    # Compute topological depth per gate
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
    
    last_gate_on_qubit = {}
    dag_succ = defaultdict(set)
    dag_pred = defaultdict(set)
    two_q = {g: q for g, q in self.access.items() if len(q) == 2}
    
    for gate in sorted(two_q.keys()):
        q1, q2 = two_q[gate]
        for q in (q1, q2):
            if q in last_gate_on_qubit:
                pred = last_gate_on_qubit[q]
                dag_succ[pred].add(gate)
                dag_pred[gate].add(pred)
            last_gate_on_qubit[q] = gate
    
    in_deg = {g: len(dag_pred[g]) for g in two_q}
    depth = {g: 0 for g in two_q}
    q = deque(g for g in two_q if in_deg[g] == 0)
    while q:
        node = q.popleft()
        for s in dag_succ[node]:
            depth[s] = max(depth[s], depth[node] + 1)
            in_deg[s] -= 1
            if in_deg[s] == 0:
                q.append(s)
    
    # Build decay-weighted interaction graph
    interact_decay = defaultdict(float)
    for gate, qubits in two_q.items():
        q1, q2 = qubits
        w = math.exp(-decay_lambda * depth[gate])
        interact_decay[(q1, q2)] += w
        interact_decay[(q2, q1)] += w
    
    logical_qubits = sorted(all_lq)
    physical_qubits = sorted(self.backend.keys())
    
    # Anchor: highest decay-weighted degree logical qubit → most central physical
    lq_degree = {lq: sum(interact_decay.get((lq, nb), 0) for nb in all_lq)
                 for lq in logical_qubits}
    pq_centrality = {pq: -sum(
        self.distance_matrix[pq][other] 
        for other in physical_qubits 
        if self.distance_matrix[pq][other] != float('inf'))
        for pq in physical_qubits}
    
    anchor_lq = max(logical_qubits, key=lambda q: lq_degree[q])
    anchor_pq = max(physical_qubits, key=lambda p: pq_centrality[p])
    
    lq_to_phys = {anchor_lq: anchor_pq}
    placed_phys = {anchor_pq}
    unplaced = [lq for lq in logical_qubits if lq != anchor_lq]
    
    # Greedy decay-weighted BFS expansion
    while unplaced:
        next_lq = max(unplaced, key=lambda lq: sum(
            interact_decay.get((lq, p_lq), 0) for p_lq in lq_to_phys))
        
        candidates = list({nb for p in placed_phys for nb in self.backend[p] 
                          if nb not in placed_phys})
        if not candidates:
            candidates = [p for p in physical_qubits if p not in placed_phys]
        if not candidates: break
        
        best_pq = min(candidates, key=lambda p: sum(
            interact_decay.get((next_lq, p_lq), 0) * 
            (self.distance_matrix[p][p_pq] 
             if self.distance_matrix[p][p_pq] != float('inf') else 1e9)
            for p_lq, p_pq in lq_to_phys.items()))
        
        lq_to_phys[next_lq] = best_pq
        placed_phys.add(best_pq)
        unplaced.remove(next_lq)
    
    # Bijection guarantee (universal snippet)
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))
    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys: continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq
    
    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict
    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

IDEA_NAME: Hardware Topology Voronoi Qubit Partitioning
DESCRIPTION: Selects K "seed" physical qubits as Voronoi centers on the hardware graph (using farthest-point sampling on the distance matrix). Each hardware node is assigned to its nearest Voronoi center, creating K hardware regions (Voronoi cells). Simultaneously clusters logical qubits into K groups using K-medoids on the circuit interaction graph. Bipartitely matches logical clusters to hardware Voronoi cells by minimizing total intra-cluster interaction distance. Within each matched pair, places logical qubits in the Voronoi cell greedily.
ALGORITHMIC_APPROACH:
  1. Choose K = ceil(sqrt(n_logical)) Voronoi centers on hardware via farthest-point sampling (iteratively pick the hardware node farthest from all selected centers).
  2. Assign each hardware node to its nearest center → K hardware cells.
  3. Cluster logical qubits via K-medoids on interaction distance (BFS on interaction graph): iteratively swap medoids to minimize total interaction distance to medoid.
  4. Build K×K cost matrix: cost(logical_cluster_i, hw_cell_j) = sum over lq in cluster_i of (interaction_weight(lq, other_lq) * distance_matrix[proposed_pq][other_pq]).

  6. Within each matched (cluster, cell) pair, place logical qubits by interaction-weighted greedy.
  7. Bijection guarantee.
COLLISION_PREVENTION: Voronoi cells are disjoint; K-medoids clusters are disjoint. Within-cell greedy maintains used-physical tracking.

IDEA_NAME: Qubit Interaction DAG Backward-Forward Consensus
DESCRIPTION: Runs two independent greedy placement passes — one on the forward DAG (optimizing for early gates) and one on the backward/reversed DAG (optimizing for late gates). Computes a consensus mapping by finding the bijection that minimizes total displacement from both solutions. Specifically, for each logical qubit, the consensus physical assignment is chosen to minimize (dist_to_forward_placement + dist_to_backward_placement) via a min-cost bipartite matching.
ALGORITHMIC_APPROACH:
  1. Run any fast greedy placement (e.g., IRDWP with λ=0.1) on the forward DAG → mapping_fwd.
  2. Reverse the gate order in self.access (invert topological sort); run the same greedy placement → mapping_bwd.
  3. Build cost matrix: cost[lq][pq] = dist(pq, mapping_fwd[lq]) + dist(pq, mapping_bwd[lq]).
  4. Solve min-cost bipartite matching (Hungarian) on cost matrix → consensus mapping.
  5. Bijection guarantee.
COLLISION_PREVENTION: Hungarian algorithm guarantees bijection on the consensus cost matrix.
WHY_NOVEL: The forward-backward consensus for placement is analogous to bidirectional Dijkstra but for mapping optimization. No existing placement algorithm reconciles both temporal directions simultaneously into a consensus. The SABRE algorithm does forward-backward routing (not placement) — this applies the concept to initial placement.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

Reference implementation sketch:
```python
def init_mapping_bfc(self):
    import numpy as np
    from scipy.optimize import linear_sum_assignment
    from collections import defaultdict, deque
    import math
    
    def run_irdwp(decay_lambda, reverse_dag=False):
        """Simplified IRDWP pass; returns lq_to_phys dict."""
        all_lq = set()
        for qubits in self.access.values():
            for q in qubits: all_lq.add(q)
        
        two_q = {g: q for g, q in self.access.items() if len(q) == 2}
        last_gate_on_qubit = {}
        dag_succ = defaultdict(set); dag_pred = defaultdict(set)
        
        gates_ordered = sorted(two_q.keys(), reverse=reverse_dag)
        for gate in gates_ordered:
            q1, q2 = two_q[gate]
            for q in (q1, q2):
                if q in last_gate_on_qubit:
                    pred = last_gate_on_qubit[q]
                    dag_succ[pred].add(gate)
                    dag_pred[gate].add(pred)
                last_gate_on_qubit[q] = gate
        
        in_deg = {g: len(dag_pred[g]) for g in two_q}
        depth = {g: 0 for g in two_q}
        bfs_q = deque(g for g in two_q if in_deg[g] == 0)
        while bfs_q:
            node = bfs_q.popleft()
            for s in dag_succ[node]:
                depth[s] = max(depth[s], depth[node] + 1)
                in_deg[s] -= 1
                if in_deg[s] == 0: bfs_q.append(s)
        
        interact_decay = defaultdict(float)
        for gate, qubits in two_q.items():
            q1, q2 = qubits
            w = math.exp(-decay_lambda * depth[gate])
            interact_decay[(q1, q2)] += w
            interact_decay[(q2, q1)] += w
        
        logical_qubits = sorted(all_lq)
        physical_qubits = sorted(self.backend.keys())
        
        lq_degree = {lq: sum(interact_decay.get((lq, nb), 0) for nb in all_lq)
                     for lq in logical_qubits}
        pq_cent = {pq: -sum(self.distance_matrix[pq][o] 
                            for o in physical_qubits 
                            if self.distance_matrix[pq][o] != float('inf'))
                   for pq in physical_qubits}
        
        anchor_lq = max(logical_qubits, key=lambda q: lq_degree[q], default=logical_qubits[0])
        anchor_pq = max(physical_qubits, key=lambda p: pq_cent[p])
        
        lq_to_phys = {anchor_lq: anchor_pq}
        placed_phys = {anchor_pq}
        unplaced = [lq for lq in logical_qubits if lq != anchor_lq]
        
        while unplaced:
            next_lq = max(unplaced, key=lambda lq: sum(
                interact_decay.get((lq, p_lq), 0) for p_lq in lq_to_phys))
            candidates = list({nb for p in placed_phys for nb in self.backend[p]
                               if nb not in placed_phys})
            if not candidates:
                candidates = [p for p in physical_qubits if p not in placed_phys]
            if not candidates: break
            best = min(candidates, key=lambda p: sum(
                interact_decay.get((next_lq, p_lq), 0) *
                (self.distance_matrix[p][p_pq] if self.distance_matrix[p][p_pq] != float('inf') else 1e9)
                for p_lq, p_pq in lq_to_phys.items()))
            lq_to_phys[next_lq] = best
            placed_phys.add(best)
            unplaced.remove(next_lq)
        return lq_to_phys
    
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    
    map_fwd = run_irdwp(0.1, reverse_dag=False)
    map_bwd = run_irdwp(0.1, reverse_dag=True)
    
    # Consensus: cost[lq_idx][pq_idx] = dist to fwd + dist to bwd
    cost = np.zeros((n_l, n_p))
    for i, lq in enumerate(logical_qubits):
        p_fwd = map_fwd.get(lq, phys_qubits[0])
        p_bwd = map_bwd.get(lq, phys_qubits[0])
        for j, pq in enumerate(phys_qubits):
            d_fwd = self.distance_matrix[pq][p_fwd] if self.distance_matrix[pq][p_fwd] != float('inf') else 1e9
            d_bwd = self.distance_matrix[pq][p_bwd] if self.distance_matrix[pq][p_bwd] != float('inf') else 1e9
            cost[i, j] = d_fwd + d_bwd
    
    if n_l < n_p:
        pad = np.full((n_p - n_l, n_p), 1e9)
        cost_sq = np.vstack([cost, pad])
    else:
        cost_sq = cost
    
    row_ind, col_ind = linear_sum_assignment(cost_sq)
    lq_to_phys = {logical_qubits[r]: phys_qubits[c]
                  for r, c in zip(row_ind, col_ind) if r < n_l}
    
    # Bijection guarantee
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))
    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys: continue
```

IDEA_NAME: K-Core Stratified Hardware Anchoring
DESCRIPTION: Computes the k-core decomposition of both the circuit interaction graph and the hardware topology graph. K-core decomposition peels nodes with degree < k, revealing the most densely connected "cores". Logical qubits in the highest k-core (most critical, most interconnected) are mapped to physical qubits also in the hardware's highest k-core. Lower k-core logical qubits are mapped to correspondingly lower k-core hardware nodes. Within each stratum, greedy interaction-weighted placement.
ALGORITHMIC_APPROACH:
  1. Build (unweighted, or threshold-weighted) interaction graph from 2Q gates.
  2. Compute k-core decomposition on interaction graph: peel nodes iteratively, assign each node its core number.
  3. Compute k-core decomposition on hardware graph using adjacency.
  4. Sort logical qubits by core number (descending); sort physical qubits by core number (descending).
  5. For each core stratum (same core level), match logical qubits in that stratum to physical qubits in the same (or nearest available) stratum via greedy interaction-weighted assignment.
  6. Bijection guarantee.
COLLISION_PREVENTION: Stratum-wise greedy assignment with used-physical tracking. Bijection guarantee handles cross-stratum residuals.
WHY_NOVEL: K-core decomposition is used in network analysis but not in quantum compilation. It naturally identifies which logical qubits are in the "dense interaction core" of the circuit and maps them to the hardware's "communication core" — a new structural principle.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 9
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.0

Reference implementation sketch:
```python
def init_mapping_kcore(self):
    from collections import defaultdict
    
    # Build interaction graph (unweighted: edge if any 2Q gate exists)
    interact_adj = defaultdict(set)
    interact_wt = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            interact_adj[q1].add(q2)
            interact_adj[q2].add(q1)
            interact_wt[(q1,q2)] += 1.0
            interact_wt[(q2,q1)] += 1.0
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    
    def kcore_decomposition(nodes, adj):
        """Returns {node: core_number}."""
        deg = {n: len(adj.get(n, set())) for n in nodes}
        core = {}
        remaining = set(nodes)
        k = 0
        while remaining:
            # Find nodes with degree <= k
            changed = True
            while changed:
                changed = False
                to_remove = [n for n in remaining if deg.get(n, 0) <= k]
                for n in to_remove:
                    core[n] = k
                    remaining.discard(n)
                    for nb in adj.get(n, set()):
                        if nb in remaining:
                            deg[nb] = max(0, deg[nb] - 1)
                    changed = True
            k += 1
        return core
    
    lq_core = kcore_decomposition(logical_qubits, interact_adj)
    pq_adj = {p: set(self.backend[p]) for p in phys_qubits}
    pq_core = kcore_decomposition(phys_qubits, pq_adj)
    
    # Group by core stratum
    from collections import defaultdict as dd
    lq_by_core = dd(list)
    for lq, c in lq_core.items(): lq_by_core[c].append(lq)
    pq_by_core = dd(list)
    for pq, c in pq_core.items(): pq_by_core[c].append(pq)
    
    lq_to_phys = {}
    used_phys = set()
    
    # Match strata from highest core downward
    max_lq_core = max(lq_core.values(), default=0)
    for c in range(max_lq_core, -1, -1):
        lqs = lq_by_core.get(c, [])
        if not lqs: continue
        # Find available physical qubits in nearest core stratum
        available_pqs = []
        for cc in range(c, -1, -1):
            avail = [pq for pq in pq_by_core.get(cc, []) if pq not in used_phys]
            available_pqs.extend(avail)
            if len(available_pqs) >= len(lqs): break
        if not available_pqs:
            available_pqs = [p for p in phys_qubits if p not in used_phys]
        
        # Greedy: assign each lq to pq minimizing weighted distance to already-placed
        for lq in sorted(lqs, key=lambda q: -sum(interact_wt.get((q,nb),0) for nb in all_lq)):
            if not available_pqs: break
            best = min(available_pqs, key=lambda p: sum(
                interact_wt.get((lq, p_lq), 0) * 
                (self.distance_matrix[p][p_pq] if self.distance_matrix[p][p_pq] != float('inf') else 1e9)
                for p_lq, p_pq in lq_to_phys.items()) if lq_to_phys else 0)
            lq_to_phys[lq] = best
            used_phys.add(best)
            available_pqs.remove(best)
    
    # Bijection guarantee
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))
    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys: continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq
    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict
    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

IDEA_NAME: Resistance Distance Isometric Embedding Placement
DESCRIPTION: Models the circuit interaction graph as an electrical network (edge weight = interaction count = conductance) and computes the effective resistance between all pairs of logical qubits. Similarly computes effective resistance between all physical qubits on the hardware graph. Embeds both sets into Euclidean space via Classical Multi-Dimensional Scaling (CMDS) using their resistance-distance matrices as dissimilarity. Finds the optimal bijection between the two embedded point clouds via the Hungarian algorithm on pairwise Euclidean distances.
ALGORITHMIC_APPROACH:
  1. Build conductance matrix for interaction graph: C_ij = number of 2Q gates on (i,j).
  2. Compute Laplacian L_c; compute pseudo-inverse L_c^+ (Moore-Penrose) via numpy.
  3. Effective resistance: R_ij = L_c^+[i,i] + L_c^+[j,j] - 2*L_c^+[i,j].
  4. Repeat for hardware graph with unit conductances.
  5. Apply CMDS: center the resistance-distance matrix, compute eigendecomposition, embed into d=3 dimensions.
  6. Hungarian matching on pairwise Euclidean distances between circuit and hardware embeddings.
  7. Bijection guarantee.
COLLISION_PREVENTION: Hungarian algorithm guarantees bijection. Pseudo-inverse is well-defined for connected components.
WHY_NOVEL: Effective resistance is a well-studied graph metric with deep connections to quantum walk mixing times, but it has never been used for quantum circuit placement. The isometric embedding via CMDS of both the circuit and hardware resistance-distance spaces is a fundamentally new approach.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 7
EFFORT_SCORE: 7
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.3

```python
def init_mapping_resistance_distance(self):
    import numpy as np
    from scipy.optimize import linear_sum_assignment
    from collections import defaultdict
    
    interact = defaultdict(float)
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
        if len(qubits) == 2:
            q1, q2 = qubits
            interact[(q1,q2)] += 1.0
            interact[(q2,q1)] += 1.0
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    lq_idx = {q: i for i, q in enumerate(logical_qubits)}
    pq_idx = {p: i for i, p in enumerate(phys_qubits)}
    
    def effective_resistance_matrix(nodes, adj_weight_func, n):
        L = np.zeros((n, n))
        for i, u in enumerate(nodes):
            for j, v in enumerate(nodes):
                if i != j:
                    w = adj_weight_func(u, v)
                    L[i, j] -= w
                    L[i, i] += w
        # Pseudo-inverse
        Lp = np.linalg.pinv(L)
        R = np.zeros((n, n))
        for i in range(n):
            for j in range(n):
                R[i, j] = Lp[i,i] + Lp[j,j] - 2*Lp[i,j]
        return R
    
    def cmds_embed(D, d=3):
        n = D.shape[0]
        D2 = D**2
        J = np.eye(n) - np.ones((n,n))/n
        B = -0.5 * J @ D2 @ J
        vals, vecs = np.linalg.eigh(B)
        idx = np.argsort(-vals)
        vals, vecs = vals[idx], vecs[:, idx]
        k = min(d, (vals > 1e-10).sum())
        if k == 0: return np.zeros((n, 1))
        return vecs[:, :k] * np.sqrt(np.maximum(vals[:k], 0))
    
    if n_l < 2:
        # fallback
        self.mapping_dict = list(range(self.num_qubits))
        self.reverse_mapping_dict = list(range(self.num_qubits))
        return
    
    R_l = effective_resistance_matrix(logical_qubits,
        lambda u, v: interact.get((u,v), 0.0) + (0.01 if u != v else 0), n_l)
    R_p = effective_resistance_matrix(phys_qubits,
        lambda u, v: 1.0 if v in self.backend[u] else 0.0, n_p)
    
    E_l = cmds_embed(R_l, d=3)
    E_p = cmds_embed(R_p, d=3)
    
    # Pad to same dimension
    if E_l.shape[1] < E_p.shape[1]:
        E_l = np.hstack([E_l, np.zeros((n_l, E_p.shape[1]-E_l.shape[1]))])
    elif E_p.shape[1] < E_l.shape[1]:
        E_p = np.hstack([E_p, np.zeros((n_p, E_l.shape[1]-E_p.shape[1]))])
    
    cost = np.linalg.norm(E_l[:, np.newaxis, :] - E_p[np.newaxis, :, :], axis=2)
    if n_l < n_p:
        cost = np.vstack([cost, np.full((n_p-n_l, n_p), 1e9)])
    
    row_ind, col_ind = linear_sum_assignment(cost)
    lq_to_phys = {logical_qubits[r]: phys_qubits[c]
                  for r, c in zip(row_ind, col_ind) if r < n_l}
```

IDEA_NAME: Gate Parallelism Score Maximization (GPSM)
DESCRIPTION: Defines a scoring function directly counting how many gates in the initial front layer become immediately executable under a candidate mapping. Generates diverse mapping candidates and selects the one maximizing this "instant executability" score, breaking ties by the estimated weighted distance cost for non-executable gates. Since generating all n! permutations is infeasible, uses a targeted search: builds candidates by greedily assigning qubit pairs that appear in the initial front layer to adjacent hardware pairs, then BFS-expanding.
ALGORITHMIC_APPROACH:
  1. Extract the initial front layer (gates with no 2Q predecessors).
  2. Extract qubit pairs from front-layer gates: pairs_FL = [(q1,q2) for each 2Q gate in FL].
  3. Build a bipartite graph between front-layer logical pairs and hardware edge pairs.
  4. Find maximum weight matching between logical pairs and hardware edges (max 2Q gate pairs simultaneously executable).
  5. For each matched logical pair → hardware edge, assign the two logical qubits to the edge's endpoints.
  6. BFS-expand remaining qubits using interaction-weighted greedy.
  7. Bijection guarantee.
  8. Additionally, generate 5-10 perturbations and evaluate their instant-executability score; keep best.
COLLISION_PREVENTION: Pair matching can cause conflicts (same logical qubit in two pairs). Conflict resolution: build a conflict graph among pairs, find maximum independent set (or greedy), then resolve greedily. Bijection guarantee is always applied.
WHY_NOVEL: Directly optimizing for front-layer executability (zero-SWAP starts) is distinct from any known approach. SABRE and CCHPCR optimize for routing cost over the entire circuit, not specifically for maximizing the number of immediately executable gates. A "maximal flying start" is a compelling new objective.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 8
EFFORT_SCORE: 8
FEASIBILITY_SCORE: 9
AVERAGE_SCORE: 8.3

Reference implementation sketch:
```python
def init_mapping_gpsm(self):
    from collections import defaultdict, deque
    
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
    
    # Build 2Q sequential DAG to find initial front layer
    two_q = {g: q for g, q in self.access.items() if len(q) == 2}
    last_gate = {}
    dag_pred = defaultdict(set)
    for gate in sorted(two_q.keys()):
        q1, q2 = two_q[gate]
        for q in (q1, q2):
            if q in last_gate:
                dag_pred[gate].add(last_gate[q])
            last_gate[q] = gate
    
    # Full DAG front layer (no predecessors)
    front_2q = [g for g in two_q if len(dag_pred[g]) == 0]
    front_pairs = [(two_q[g][0], two_q[g][1]) for g in front_2q]
    
    # Build hardware edge set
    hw_edges = list(self.backend_connections)
    
    # Build bipartite matching: assign logical pairs to hardware edges
    # Greedy: for each logical pair by interaction weight, assign to best free hardware edge
    pair_weights = defaultdict(float)
    for gate, qubits in two_q.items():
        if len(qubits) == 2:
            pair_weights[(qubits[0], qubits[1])] += 1.0
    
    # Sort front pairs by total interaction weight (descending)
    front_pairs_sorted = sorted(front_pairs,
        key=lambda p: pair_weights.get(p, 0) + pair_weights.get((p[1],p[0]), 0),
        reverse=True)
    
    lq_to_phys = {}
    used_phys = set()
    used_hw_edges = set()
    
    for (lq1, lq2) in front_pairs_sorted:
        if lq1 in lq_to_phys or lq2 in lq_to_phys:
            continue  # skip if already placed
        # Find best free hardware edge
        best_edge = None
        best_cost = float('inf')
        for (p1, p2) in hw_edges:
            if p1 in used_phys or p2 in used_phys: continue
            # Cost: total distance to already-placed qubits
            cost = 0.0
            for alq, apq in lq_to_phys.items():
                for lq_new, pq_new in [(lq1, p1), (lq2, p2)]:
                    d = self.distance_matrix[pq_new][apq]
                    cost += pair_weights.get((lq_new, alq), 0) * (d if d != float('inf') else 1e9)
            if cost < best_cost:
                best_cost = cost
                best_edge = (p1, p2)
        
        if best_edge:
            p1, p2 = best_edge
            lq_to_phys[lq1] = p1
            lq_to_phys[lq2] = p2
            used_phys.add(p1); used_phys.add(p2)
    
    # BFS expansion for remaining qubits
    interact_wt = defaultdict(float)
    for gate, qubits in two_q.items():
        if len(qubits) == 2:
            q1, q2 = qubits
            interact_wt[(q1,q2)] += 1.0
            interact_wt[(q2,q1)] += 1.0
    
    logical_qubits = sorted(all_lq)
    physical_qubits = sorted(self.backend.keys())
    unplaced = [lq for lq in logical_qubits if lq not in lq_to_phys]
    
    while unplaced:
        next_lq = max(unplaced, key=lambda lq: sum(
            interact_wt.get((lq, p_lq), 0) for p_lq in lq_to_phys))
        candidates = list({nb for p in used_phys for nb in self.backend[p]
                          if nb not in used_phys})
        if not candidates:
            candidates = [p for p in physical_qubits if p not in used_phys]
        if not candidates: break
        best = min(candidates, key=lambda p: sum(
            interact_wt.get((next_lq, p_lq), 0) *
            (self.distance_matrix[p][p_pq] if self.distance_matrix[p][p_pq] != float('inf') else 1e9)
            for p_lq, p_pq in lq_to_phys.items()))
        lq_to_phys[next_lq] = best
        used_phys.add(best)
        unplaced.remove(next_lq)
    
    # Bijection guarantee
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))
    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys: continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq
    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict
    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```

IDEA_NAME: Dependency-Weighted Centroid Gravity Placement
DESCRIPTION: Assigns each logical qubit a "gravity mass" = total number of downstream dependent gates (transitive successor count in the DAG, analogous to dag_dependencies_count already computed in routing.py). High-mass qubits represent circuit bottlenecks and should be placed at hardware "gravity centers" (nodes minimizing sum of distances to all other nodes, i.e., hardware medians). Low-mass qubits are placed in the hardware periphery. Uses a mass-stratified placement: sort qubits by mass, sort hardware nodes by closeness centrality, match by rank.
ALGORITHMIC_APPROACH:
  1. Build 2Q sequential DAG; compute transitive successor count for each logical qubit: mass[lq] = sum over all 2Q gates g where lq is an operand, of dag_dependencies_count[g].
  2. Sort logical qubits by mass (descending).
  3. Compute closeness centrality for each physical qubit: cc[pq] = (n-1) / sum_over_other_pq(distance_matrix[pq][other]).
  4. Sort physical qubits by closeness centrality (descending).
  5. Rank-match: lq with rank k → pq with rank k.
  6. Tie-breaking by weighted interaction degree.
  7. Bijection guarantee.
COLLISION_PREVENTION: Rank matching on two independently sorted lists yields a bijection by construction. Ties are broken deterministically via a secondary comparator.
WHY_NOVEL: Using DAG transitive dependency count (a measure of how much of the circuit's future depends on a qubit) as a "mass" for gravity-driven placement is fundamentally new. This directly ties placement to the downstream routing impact of each qubit — the more a qubit's position affects future gates, the more central its hardware position should be.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 8
EFFORT_SCORE: 9
FEASIBILITY_SCORE: 10
AVERAGE_SCORE: 8.8

Reference implementation sketch:
```python
def init_mapping_gravity(self):
    from collections import defaultdict, deque
    
    all_lq = set()
    for qubits in self.access.values():
        for q in qubits: all_lq.add(q)
    
    two_q = {g: q for g, q in self.access.items() if len(q) == 2}
    
    # Build sequential 2Q DAG
    last_gate = {}
    dag_succ = defaultdict(set); dag_pred = defaultdict(set)
    for gate in sorted(two_q.keys()):
        q1, q2 = two_q[gate]
        for q in (q1, q2):
            if q in last_gate:
                pred = last_gate[q]
                dag_succ[pred].add(gate)
                dag_pred[gate].add(pred)
            last_gate[q] = gate
    
    # Transitive successor count per gate via topological DP
    in_deg = {g: len(dag_pred[g]) for g in two_q}
    topo_q = deque(g for g in two_q if in_deg[g] == 0)
    dep_count = {g: 0 for g in two_q}
    order = []
    while topo_q:
        node = topo_q.popleft()
        order.append(node)
        for s in dag_succ[node]:
            in_deg[s] -= 1
            if in_deg[s] == 0: topo_q.append(s)
    for node in reversed(order):
        for s in dag_succ[node]:
            dep_count[node] += dep_count[s] + 1
    
    # Mass per logical qubit = sum of dep_count for gates where lq is an operand
    lq_mass = defaultdict(float)
    for gate, dep in dep_count.items():
        for lq in two_q[gate]:
            lq_mass[lq] += dep + 1
    
    logical_qubits = sorted(all_lq)
    phys_qubits = sorted(self.backend.keys())
    n_l, n_p = len(logical_qubits), len(phys_qubits)
    
    # Hardware closeness centrality
    pq_closeness = {}
    for pq in phys_qubits:
        dists = [self.distance_matrix[pq][o] 
                 for o in phys_qubits 
                 if self.distance_matrix[pq][o] != float('inf') and o != pq]
        if dists:
            pq_closeness[pq] = (len(dists)) / sum(dists)
        else:
            pq_closeness[pq] = 0.0
    
    # Sort and rank-match
    lq_sorted = sorted(logical_qubits, key=lambda lq: -lq_mass.get(lq, 0))
    pq_sorted = sorted(phys_qubits, key=lambda pq: -pq_closeness.get(pq, 0))
    
    lq_to_phys = {}
    for i, lq in enumerate(lq_sorted):
        if i < n_p:
            lq_to_phys[lq] = pq_sorted[i]
    
    # Bijection guarantee
    mapping_dict = list(range(self.num_qubits))
    reverse_mapping_dict = list(range(self.num_qubits))
    for lq, target_phys in lq_to_phys.items():
        current_phys = mapping_dict[lq]
        if current_phys == target_phys: continue
        displaced_lq = reverse_mapping_dict[target_phys]
        mapping_dict[lq] = target_phys
        mapping_dict[displaced_lq] = current_phys
        reverse_mapping_dict[target_phys] = lq
        reverse_mapping_dict[current_phys] = displaced_lq
    self.mapping_dict = mapping_dict
    self.reverse_mapping_dict = reverse_mapping_dict
    if self.use_isl:
        self.isl_mapping = dict_to_isl_map(self.mapping_dict)
```
