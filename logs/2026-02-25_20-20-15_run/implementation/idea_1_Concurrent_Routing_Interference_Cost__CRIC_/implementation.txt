Here is the complete implementation:

```python
def qlosure_poly_heuristic(self, swap_gate):
    u, v = swap_gate[0], swap_gate[1]

    front_layer_size = len(self.front_layer)
    extended_layer_size = len(self.extended_layer)

    if front_layer_size == 0:
        return 0.0

    max_decay = max(self.decay_parameter[u], self.decay_parameter[v])

    # ------------------------------------------------------------------ #
    # Core CRIC primitive: "Is the candidate SWAP edge (u,v) on a         #
    # shortest path from Q1 to Q2?"                                        #
    #                                                                      #
    # An undirected edge {u,v} lies on SOME shortest path from Q1 to Q2  #
    # iff either of these holds:                                           #
    #   d(Q1,u) + 1 + d(v,Q2) == d(Q1,Q2)   (traverse u→v)              #
    #   d(Q1,v) + 1 + d(u,Q2) == d(Q1,Q2)   (traverse v→u)              #
    #                                                                      #
    # This is strictly broader than walking a single greedy path: it      #
    # captures every gate whose routing options include this edge, even   #
    # when multiple equally-short alternatives exist.                     #
    # ------------------------------------------------------------------ #
    def edge_on_shortest_path(Q1, Q2, dist):
        if Q1 < 0 or Q2 < 0 or dist == 0:
            return False
        return (
            self.distance_matrix[Q1][u] + 1 + self.distance_matrix[v][Q2] == dist
            or
            self.distance_matrix[Q1][v] + 1 + self.distance_matrix[u][Q2] == dist
        )

    # ------------------------------------------------------------------ #
    # Step 1: Front layer — routing distance & path-sharing count         #
    #                                                                      #
    # k  = number of gates whose shortest paths pass through (u,v).      #
    # Weighted by criticality (dep+1) so urgent gates count more.        #
    # ------------------------------------------------------------------ #
    f_distance = 0.0
    k_front = 0            # unweighted gate count sharing the edge

    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        if Q1 < 0 or Q2 < 0:
            continue

        dist = self.distance_matrix[Q1][Q2]
        deps = self.dag_dependencies_count[g]
        f_distance += (deps + 1) * dist

        if edge_on_shortest_path(Q1, Q2, dist):
            k_front += 1

    # ------------------------------------------------------------------ #
    # Step 2: Pairwise routing interference  C(k, 2) = k*(k-1)/2         #
    #                                                                      #
    # If k gates all route through (u,v), they form C(k,2) competing     #
    # pairs.  This SWAP resolves routing for at most ONE of them — the   #
    # remaining k-1 gates still need this edge in future rounds, meaning #
    # we have "locked in" congestion rather than relieved it.            #
    #                                                                      #
    # Normalise by the maximum possible pairs so the term is always in   #
    # [0, 1] regardless of front-layer size.                             #
    # ------------------------------------------------------------------ #
    pairwise_conflict = k_front * (k_front - 1) / 2
    max_pairs = front_layer_size * (front_layer_size - 1) / 2
    norm_conflict = pairwise_conflict / max(max_pairs, 1.0)

    # ------------------------------------------------------------------ #
    # Step 3: Extended layer — discounted distance & lookahead conflict   #
    # ------------------------------------------------------------------ #
    e_distance = 0.0
    e_conflict = 0.0  # fractionally discounted by layer depth

    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1 = self.temp_mapping_dict[q1]
        Q2 = self.temp_mapping_dict[q2]
        if Q1 < 0 or Q2 < 0:
            continue

        dist = self.distance_matrix[Q1][Q2]
        layer_factor = self.extended_layer_index.get(g, 0) + 1
        deps = self.dag_dependencies_count[g]
        e_distance += (deps + 1) * dist / layer_factor

        if edge_on_shortest_path(Q1, Q2, dist):
            e_conflict += 1.0 / layer_factor

    norm_e_conflict = e_conflict / max(extended_layer_size, 1.0)

    # ------------------------------------------------------------------ #
    # Step 4: CRIC cost assembly                                          #
    #                                                                      #
    # Base routing cost (mirroring the reference heuristic structure):   #
    #   f_cost  = weighted distance over front layer, per gate            #
    #   e_cost  = discounted weighted distance over extended layer        #
    #                                                                      #
    # Congestion amplifier:                                               #
    #   (1 + alpha * norm_conflict)  multiplies the routing cost so that #
    #   a SWAP on a contested edge is penalised even when it reduces      #
    #   distance — the multi-agent competition for this edge makes the   #
    #   routing plan globally less efficient.                             #
    #                                                                      #
    # Extended-layer lookahead conflict adds a secondary term to steer   #
    # away from edges that will be bottlenecks in upcoming rounds.       #
    #                                                                      #
    # cost = decay                                                        #
    #        × (1 + α·norm_conflict_front)                               #
    #        × ( f_cost/|F|  +  W·e_cost/|E| )                          #
    #        + decay × β·norm_conflict_extended                          #
    # ------------------------------------------------------------------ #
    f_cost = f_distance / front_layer_size
    e_cost = (e_distance / extended_layer_size) if extended_layer_size else 0.0

    ALPHA = 1.5   # how strongly front-layer pairwise conflict amplifies cost
    BETA  = 0.4   # additive penalty weight for future congestion
    W_EXT = 0.5   # relative weight of extended lookahead routing cost

    congestion_amplifier = 1.0 + ALPHA * norm_conflict

    cost = max_decay * (
        congestion_amplifier * (f_cost + W_EXT * e_cost)
        + BETA * norm_e_conflict
    )

    return cost
```

---

**How CRIC works — step by step:**

| Component | Role |
|---|---|
| `edge_on_shortest_path(Q1, Q2, dist)` | Mathematical check: is `(u,v)` on *any* shortest path (not just a greedy walk), using `d(Q1,u)+1+d(v,Q2)==dist` |
| `k_front` | Count of front-layer gates whose paths include the candidate SWAP edge |
| `C(k,2) = k(k-1)/2` | Pairwise interference: if `k` agents compete for one edge, there are `k(k-1)/2` conflicting pairs |
| `norm_conflict ∈ [0,1]` | Normalised by max possible pairs, making the penalty topology-independent |
| `congestion_amplifier = 1 + α·norm_conflict` | **Multiplicative** penalty — a contested edge amplifies the routing cost rather than just adding a flat term |
| `norm_e_conflict` | Lookahead: future gates that will also contend for this edge, depth-discounted |

**Key distinction from CAGRC:** CAGRC walks one greedy path per gate and sums edge weights. CRIC uses the exact algebraic condition `d(Q1,u)+1+d(v,Q2)==dist` to detect *all* gates whose routing is compatible with the SWAP edge, then computes the quadratic `C(k,2)` pairwise interference as a multiplicative amplifier — a fundamentally different mechanism rooted in multi-agent path-finding theory.
