### Soft Barrier Edge Accumulator (SBEA) — Design Rationale

**State detection without modifying other methods**

`apply_qlosure_heuristic` always increments `decay_parameter[p]` and `decay_parameter[q]` by `+0.001` for the winning swap `(p, q)`. SBEA snapshots `decay_parameter` between calls and diffs it — when exactly 2 indices change, those two physical qubits identify the committed edge. This gives us the committed edge for free.

**Mathematical structure**

```
barrier(p,q) = 1 + edge_barrier[(min(p,q), max(p,q))]

H = barrier(swap_gate) × ( f_distance/|FL| + W × e_distance/|EL| )

where:
  f_distance = Σ_{g ∈ FL} (deps_g + 1) × dist(Q1, Q2)   # front-layer weighted sum
  e_distance = Σ_{g ∈ EL} (deps_g + 1) × dist(Q1,Q2) / layer_depth_g  # lookahead

After each committed swap on edge (p,q):
  ∀ e: edge_barrier[e] ×= μ = 0.98    # global multiplicative decay
  edge_barrier[(p,q)] += η = 5.0       # accumulate on used edge
```

**Why this prevents ping-ponging**

| Scenario | Effect |
|---|---|
| Swap edge (p,q) for first time | `barrier = 1.0` — no penalty |
| Immediately reverse same edge (p,q) | `barrier = 6.0` — 6× cost inflation |
| Oscillate on (p,q) k times | `barrier ≈ 1 + η/(1−μ) = 251` — exponentially costly |
| Swap a different edge (r,s) | `barrier = 1.0` — completely unaffected |

**Key differences from baseline**

- Baseline penalizes individual **qubits** via `max(decay[p], decay[q])` — a qubit involved in any swap is penalized regardless of which edge
- SBEA penalizes specific **coupling edges** — only the exact `(p,q)` pair is penalized, leaving adjacent edges clean. Ping-pong on the same edge is maximally penalized; exploration of new edges is freely encouraged
