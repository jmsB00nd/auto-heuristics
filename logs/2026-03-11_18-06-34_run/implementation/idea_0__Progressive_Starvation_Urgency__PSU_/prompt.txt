Idea:  Progressive Starvation Urgency (PSU)
Desc: **
Each front-layer gate accumulates a starvation counter `starvation[g]` that increments by 1 every time a SWAP is applied without executing g. The urgency weight grows exponentially with starvation depth, guaranteeing that any gate left in `front_layer` for too long will eventually dominate the cost function and force the router to resolve it. Counters reset to 0 the moment a gate executes (is removed from `front_layer`). The exponential urgency replaces the linear dependency-count weight for the starvation-weighted distance, while the extended layer retains the baseline weight.

```

urgency(g) = w(g) · exp(α · starvation[g])

H(s) = max(γ_p, γ_q) · (f_score + W · e_score)

# State update after each swap (called outside the heuristic):
for g in front_layer:
    starvation[g] += 1
# Reset on gate execution:
```

**LOOP_PREVENTION_STRATEGY:**
The starvation counter is strictly monotonically non-decreasing while a gate remains in `front_layer`. Since `exp(α · starvation[g])` grows unboundedly, any stuck gate will eventually have urgency so large that it absolutely dominates the cost, forcing the router to choose the SWAP that most reduces its distance. This makes perpetual avoidance of any gate mathematically impossible. The standard `max(γ_p, γ_q)` decay additionally penalizes repeated use of the same physical qubits, breaking flip-flop oscillations.

**WHY_NOVEL:**
Existing urgency approaches (GPIUC) measure *spatial* parallelism isolation. PSU measures *temporal starvation* — how long a gate has been waiting — and converts this into an exponential weight that dynamically re-prioritizes the most neglected gate. No existing implemented heuristic uses a gate-level urgency accumulator that resets on execution. This provides a formal anti-starvation guarantee absent from SABRE and all variants.

```python
def qlosure_poly_heuristic(self, swap_gate):

        front_layer_size = len(self.front_layer)

        f_distance = 0

        for g in self.front_layer:
            q1, q2 = self.access2q[g]
            Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
            deps = self.dag_dependencies_count[g]

            f_distance += (deps+1) * self.distance_matrix[Q1][Q2]

        e_distance = 0
        for g in self.extended_layer:
            q1, q2 = self.access2q[g]
            Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
            layer_factor = self.extended_layer_index.get(g, 0) + 1

            deps = self.dag_dependencies_count[g]
            e_distance += (deps+1) * \
                self.distance_matrix[Q1][Q2] * 1/layer_factor

        H = max_decay * (f_distance / front_layer_size + W *
                        ((e_distance / extended_layer_size) if extended_layer_size else 0))
```
