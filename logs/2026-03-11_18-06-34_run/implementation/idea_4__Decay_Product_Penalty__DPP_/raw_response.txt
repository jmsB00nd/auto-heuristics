The key data structures are clear. The `decay_parameter` list starts at `1.0` per qubit and increments by `0.001` on each SWAP. The baseline uses `max` — DPP replaces this with the product `γ_p · γ_q`.

```python
def qlosure_poly_heuristic(self, swap_gate):
    W = 1
    front_layer_size = len(self.front_layer)
    extended_layer_size = len(self.extended_layer)

    # DPP: product aggregation instead of max
    # Both qubits pay proportionally; shared-pivot loops accumulate super-linearly
    product_decay = self.decay_parameter[swap_gate[0]] * self.decay_parameter[swap_gate[1]]

    f_distance = 0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        deps = self.dag_dependencies_count[g]
        f_distance += (deps + 1) * self.distance_matrix[Q1][Q2]

    e_distance = 0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        layer_factor = self.extended_layer_index.get(g, 0) + 1
        deps = self.dag_dependencies_count[g]
        e_distance += (deps + 1) * self.distance_matrix[Q1][Q2] / layer_factor

    H = product_decay * (f_distance / front_layer_size + W *
                         ((e_distance / extended_layer_size) if extended_layer_size else 0))

    return H
```

**Why this is correct and safe:**

| Property | Analysis |
|---|---|
| **No divide-by-zero** | `front_layer_size > 0` always (loop guard); `extended_layer_size` gated by `if` |
| **No zero-product** | `decay_parameter` starts at `1.0` and only increments — product is always `≥ 1.0` |
| **Convergence** | Ping-pong pattern: qubit `q` participates in every alternating SWAP, so `γ_q` grows fastest. Product `γ_p · γ_q` penalises both participants, making the oscillating pair progressively more expensive than any fresh qubit pair |
| **Complexity** | O(|FL| + |EL|) — identical to baseline |
| **Front layer dominance** | Preserved — `f_distance / front_layer_size` is the dominant term; `W=1` weight unchanged |

**The mathematical distinction from `max`:** With `max(γ_p, γ_q)`, a cold qubit `p` paired with a hot qubit `q` has the same penalty as two hot qubits. With the product, the cold qubit's low `γ_p` actively *reduces* the penalty, making fresh qubit paths cheaper and routing away from hot regions. This creates a smooth repulsion field around overused qubit pairs rather than a flat plateau.
