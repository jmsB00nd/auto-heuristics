IDEA_NAME: Commutator-Aware Non-Blocking Gate Liberation Cost (CANGLC)
DESCRIPTION: Exploits a quantum-specific algebraic property: two gates commute if their Pauli tensor product supports commute (i.e., [G_i, G_j] = 0). Non-commuting predecessors create true ordering constraints; commuting ones are phantom dependencies. The cost reweights effective depth using only *non-commuting predecessor chains*, giving a tighter lower bound on required SWAPs. A SWAP is scored by how much it reduces non-commuting dependency lengths across the front and extended layers simultaneously.
MATHEMATICAL_FORMULATION:
Let nc_depth(g) = |{g' : g' ≺ g ∧ [G_{g'}, G_g] ≠ 0}| (non-commuting predecessor count)
Let δ_nc(g, swap) = nc_depth_after(g, swap) - nc_depth_before(g, swap) ≤ 0 (reduction)

```
C_CANGLC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F}  (nc_depth(g)+1) · d(Q1(g), Q2(g))
  + W · (1/|E|) · Σ_{g∈E} (nc_depth(g)+1) · d(Q1(g), Q2(g)) / (idx(g)+1)
  - λ · Σ_{g∈F∪E} Δ_unblock(g, swap) · (nc_depth(g)+1)
]
```

where Δ_unblock counts gates newly executable after applying swap, weighted by non-commuting depth. λ is a tunable bonus coefficient.
WHY_NOVEL: All existing cost functions (SABRE, NASSC, TOQM, etc.) treat gate dependency as a classical ordering constraint counting *all* predecessors. This is the first to leverage the Lie-algebraic commutativity structure of quantum gates — a property that exists *only* in quantum circuits — to determine true ordering constraints. This allows the heuristic to "look through" commuting layers and correctly assess routing urgency.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 8
EFFORT_SCORE: 7
AVERAGE_SCORE: 7.7
STATUS: KEPT
ELIMINATION_REASON: N/A

IDEA_NAME: Stochastic DAG Activation Probability Cost (SDAPC)
DESCRIPTION: Instead of treating the extended layer as a fixed window, model the entire remaining DAG as a stochastic process. Compute P(g, k) = probability that gate g becomes executable within the next k routing steps, via dynamic programming on the DAG structure. Each gate's contribution to the cost is then weighted by its activation probability, giving a principled, globally-consistent lookahead that automatically degrades for gates blocked by many unresolved dependencies.
MATHEMATICAL_FORMULATION:
Via DAG DP (let pred(g) = immediate predecessors):

```
P(g, 0) = 1  if all pred(g) already executed, else 0
P(g, k) = Π_{g'∈pred(g)} [α·P(g', k-1) + (1-α)·P(g', k)]   (Markov approximation)
```

Cost:

```
C_SDAPC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F}  (dep(g)+1) · d(Q1(g), Q2(g))
  + W · Σ_{g∈DAG\F} P(g, K) · (dep(g)+1) · d(Q1(g), Q2(g)) / (E[level(g)]+1)
]
```

where K is the lookahead horizon, α∈(0,1) is a damping factor, and E[level(g)] is the expected DAG depth to activation.
WHY_NOVEL: SABRE uses a fixed-size extended layer with hard cutoffs. NASSC uses distance-scaled layers. This replaces the discrete window with a continuous probabilistic mass over the entire unexecuted DAG, naturally handling irregular DAG structures (long chains, wide parallelism) without hardcoded layer sizes. Convergence is guaranteed: as gates execute, P(g,k) values for remaining gates decrease monotonically toward a new steady state.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 7
EFFORT_SCORE: 7
AVERAGE_SCORE: 7.3
STATUS: KEPT
ELIMINATION_REASON: N/A

IDEA_NAME: Spectral Embedding Displacement Cost (SEDC)
DESCRIPTION: Embed each physical qubit into R^k using the k smallest non-trivial eigenvectors of the coupling graph Laplacian (spectral embedding). Physical proximity in the Euclidean spectral space predicts multi-hop routing efficiency better than hop count, because the spectral embedding is globally consistent and reflects the full graph topology. The cost measures squared spectral-space displacement between qubit pairs across the front and extended layers.
MATHEMATICAL_FORMULATION:
Let L = D - A (coupling graph Laplacian), with eigenvectors v_2,...,v_{k+1} for eigenvalues 0 < λ_2 ≤ ... ≤ λ_{k+1}.
Spectral position: φ(q) = (v_2(q)/√λ_2, v_3(q)/√λ_3, ..., v_{k+1}(q)/√λ_{k+1}) ∈ R^k

```
d_spec(q1, q2) = ||φ(q1) - φ(q2)||_2
              = sqrt( Σ_{i=2}^{k+1} (v_i(q1) - v_i(q2))^2 / λ_i )
```

Note: d_spec is related to the commute time distance via: d_commute(q1,q2)^2 = n·||φ(q1)-φ(q2)||^2

```
C_SEDC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F} (dep(g)+1) · d_spec(Q1(g), Q2(g))
  + W · (1/|E|) · Σ_{g∈E} (dep(g)+1) · d_spec(Q1(g), Q2(g)) / (idx(g)+1)
]
```

WHY_NOVEL: All existing routing cost functions use hop-count distance (BFS shortest path). Spectral distance encodes the global graph geometry: it is longer across graph bottlenecks (bridges, cut vertices) and shorter in highly connected regions, providing a fundamentally different signal about routing difficulty. The Fiedler vector (v_2) alone reveals the hardest-to-cross partition of the coupling graph.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
AVERAGE_SCORE: 7.3
STATUS: KEPT

IDEA_NAME: Effective Resistance (Commute Time) Routing Cost (ERCRC)
DESCRIPTION: Replace hop-count with the *electrical effective resistance* R_eff(i,j) = (e_i - e_j)^T L^+ (e_i - e_j), where L^+ is the Moore-Penrose pseudoinverse of the graph Laplacian. Effective resistance is the expected length of a random walk from i to j and back, and naturally accounts for all parallel paths — not just the shortest. Paths through graph bottlenecks have exponentially larger effective resistance, giving a theoretically grounded difficulty estimate.
MATHEMATICAL_FORMULATION:
Precompute: L^+ = (L + (1/n)·11^T)^{-1} - (1/n)·11^T

```
R_eff(i, j) = L^+_{ii} + L^+_{jj} - 2·L^+_{ij}  ∈ [1/n, n]
```

```
C_ERCRC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F} (dep(g)+1) · R_eff(Q1(g), Q2(g))
  + W · (1/|E|) · Σ_{g∈E} (dep(g)+1) · R_eff(Q1(g), Q2(g)) / (idx(g)+1)
]
```

R_eff is precomputed once (O(n^3)) and looked up in O(1). Convergence follows from R_eff ≥ d_hop/n (standard bound), so cost decreases as routing progresses.
WHY_NOVEL: Hop-count only sees the shortest path. Effective resistance integrates over all paths weighted by their conductance. On real coupling topologies (heavy-hex, falcon lattices), certain short paths are heavily congested; R_eff implicitly penalizes these without any explicit congestion tracking. This is the first use of the matrix-tree theorem / Kirchhoff laws for quantum routing difficulty estimation.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 8
AVERAGE_SCORE: 7.3
STATUS: KEPT
ELIMINATION_REASON: N/A

IDEA_NAME: Ollivier-Ricci Curvature Weighted Cost (ORCWC)
DESCRIPTION: Assign each coupling graph edge (p,p') a discrete Ricci curvature κ(p,p') via the Ollivier-Ricci definition: κ(p,p') = 1 - W_1(μ_p, μ_{p'}) / d(p,p'), where μ_p is the uniform distribution over p's neighbors and W_1 is the Wasserstein-1 (earth mover's) distance. Negative curvature edges are "bottleneck" edges that incur many SWAPs when crossed; positive curvature indicates richly connected regions. The cost penalizes routing paths through negatively curved edges.
MATHEMATICAL_FORMULATION:
For edge (p,p') in coupling graph G:
```
μ_p(q) = 1/(deg(p)+1) if q ∈ N(p)∪{p}, else 0
κ(p, p') = 1 - W_1(μ_p, μ_{p'}) / 1   [since d(p,p')=1 for adjacent nodes]
```

Path curvature cost:
```
κ_path(Q1, Q2) = Σ_{(p,p') ∈ shortest_path(Q1,Q2)} (1 - κ(p,p'))
```

```
C_ORCWC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F} (dep(g)+1) · κ_path(Q1(g), Q2(g))
  + W · (1/|E|) · Σ_{g∈E} (dep(g)+1) · κ_path(Q1(g), Q2(g)) / (idx(g)+1)
]
```

All κ values and path costs precomputed. Convergence: κ_path ≥ d_hop (for edges with κ ≤ 0), cost is bounded and decreasing.
WHY_NOVEL: Discrete Ricci curvature originates in differential geometry (Riemannian manifolds) and was adapted to graphs by Ollivier in 2009 for studying Markov chains. It has never been applied to quantum circuit routing. Unlike hop-count, κ_path detects whether a path traverses structural bottlenecks vs. rich subgraphs — a qualitatively different signal about routing difficulty.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 7
EFFORT_SCORE: 6
AVERAGE_SCORE: 7.3

IDEA_NAME: Heat Kernel Diffusion Distance Cost (HKDDC)
DESCRIPTION: Use the heat kernel K_t(i,j) = [e^{-tL}]_{ij} on the coupling graph to define a smooth, scale-parameterized distance measure. The heat kernel captures how "heat" (probability) diffuses from qubit i to qubit j over pseudo-time t. The diffusion distance d_t(i,j)^2 = K_t(i,i) + K_t(j,j) - 2K_t(i,j) is small when qubits are well-connected and large when separated by structural barriers. The parameter t controls the spatial scale of sensitivity.
MATHEMATICAL_FORMULATION:
Spectral decomposition: K_t = Σ_k e^{-λ_k t} v_k v_k^T

```
d_HK(i, j, t) = sqrt( Σ_k e^{-2λ_k t} · (v_k(i) - v_k(j))^2 )
```

Multi-scale version (robust to t selection):
```
d_HK_multi(i,j) = Σ_{t∈T} w_t · d_HK(i,j,t)    T = {t_1, ..., t_m}, w_t = 1/|T|
```

```
C_HKDDC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F} (dep(g)+1) · d_HK_multi(Q1(g), Q2(g))
  + W · (1/|E|) · Σ_{g∈E} (dep(g)+1) · d_HK_multi(Q1(g), Q2(g)) / (idx(g)+1)
]
```

WHY_NOVEL: Heat kernel distance is used in manifold learning (diffusion maps, Coifman & Lafon 2006) but never in quantum routing. Unlike hop-count, d_HK is scale-aware: at small t it behaves like geodesic distance; at large t it detects global graph clusters. The multi-scale version is stable and captures both local and global routing difficulty. Strongly related to spectral embedding but derived from a fundamentally different physical analogy.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 6
EFFORT_SCORE: 7
AVERAGE_SCORE: 7.0
STATUS: KEPT

IDEA_NAME: Wasserstein Qubit Displacement Transport Cost (WQDTC)
DESCRIPTION: Model the current logical-to-physical mapping as a discrete measure μ_current over physical qubit positions, and the "ideal" mapping (that minimizes front-layer gate distances) as μ_target. The Wasserstein-1 distance W_1(μ_current, μ_target) measures the minimum total transport cost to move logical qubits from their current positions to ideal positions. A SWAP that reduces W_1 is strongly favored. The ideal mapping is recomputed greedily at each routing step using bipartite matching.
MATHEMATICAL_FORMULATION:
Let π: logical → physical be current mapping.
For front layer, define ideal mapping π* = argmin_{bijection σ} Σ_{g∈F} d(σ(q1(g)), σ(q2(g)))

```
μ_current = (1/n) Σ_q δ_{π(q)}
μ_target  = (1/n) Σ_q δ_{π*(q)}

W_1(μ_current, μ_target) = min_{γ∈Γ(μ,ν)} Σ_{p,p'} d(p,p') · γ(p,p')
```

```
C_WQDTC(swap) = max_decay · [
    α · W_1(μ_current_after_swap, μ_target)
  + (1-α) · (1/|F|) · Σ_{g∈F} (dep(g)+1) · d(Q1(g), Q2(g))
]
```

The W_1 term is solved as a min-cost flow on the coupling graph (polynomial in n).
WHY_NOVEL: Existing cost functions measure per-gate distances independently. W_1 measures the *global redistribution cost* of the entire mapping simultaneously, capturing inter-gate interactions that localized distance sums miss. The optimal transport formulation has a unique decomposability property: W_1 is subadditive over routing steps, guaranteeing cost reduction convergence.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 6
EFFORT_SCORE: 6
AVERAGE_SCORE: 6.7
STATUS: KEPT
ELIMINATION_REASON: N/A

IDEA_NAME: Algebraic Connectivity Path Bottleneck Cost (ACPBC)
DESCRIPTION: For each gate g requiring qubits Q1(g), Q2(g), identify the induced subgraph S(Q1,Q2) formed by all shortest paths between Q1 and Q2. Compute the Fiedler value (algebraic connectivity) λ_2(S) of this subgraph. A low λ_2 indicates the routing corridor is a near-cut-vertex structure (bottleneck); a high λ_2 indicates robust multi-path connectivity. The cost penalizes routing through topological bottlenecks by dividing the standard distance by λ_2(S).
MATHEMATICAL_FORMULATION:
```
S(Q1, Q2) = subgraph induced by vertices on all shortest paths from Q1 to Q2
λ_2(S)    = second smallest eigenvalue of L(S)  [Fiedler value of routing corridor]
```

Bottleneck-weighted distance:
```
d_bottle(Q1, Q2) = d_hop(Q1, Q2) · exp(-β · λ_2(S(Q1,Q2)))
```

(λ_2→0 → bottleneck → cost approaches ∞; λ_2→large → well-connected → cost ≈ d_hop)

```
C_ACPBC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F} (dep(g)+1) · d_bottle(Q1(g), Q2(g))
  + W · (1/|E|) · Σ_{g∈E} (dep(g)+1) · d_bottle(Q1(g), Q2(g)) / (idx(g)+1)
]
```

WHY_NOVEL: The Fiedler value λ_2(S) of the routing corridor has never been used as a routing cost component. It encodes exactly the hardness of concurrent SWAP routing through a subgraph — a bridge subgraph (λ_2→0) forces sequential routing and thus more total SWAPs. This connects routing cost functions to algebraic graph theory in a fundamentally new way.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 6
EFFORT_SCORE: 6
AVERAGE_SCORE: 6.7
STATUS: KEPT
ELIMINATION_REASON: N/A

IDEA_NAME: Multi-Commodity Flow Congestion Cost (MCFCC)
DESCRIPTION: Model the entire front layer simultaneously as a multi-commodity flow problem: each gate g is a "commodity" requiring one unit of flow from Q1(g) to Q2(g) on the coupling graph. Solve the fractional LP relaxation to obtain edge flows f_e. Edges with high aggregate flow are congestion points. The routing cost for a SWAP is penalized by the congestion it resolves or creates, making it globally congestion-aware across simultaneous routing demands.
MATHEMATICAL_FORMULATION:
MCF-LP (fractional relaxation, O(|E|·|F|) via network simplex):
```
minimize   Σ_e c_e · Σ_k f_e^k
subject to  flow conservation for each commodity k
            0 ≤ f_e^k ≤ cap(e) = 1
```

Congestion at edge e: cong(e) = Σ_k f_e^k / cap(e)

```
C_MCFCC(swap) = max_decay · [
    (1/|F|) · Σ_{g∈F} (dep(g)+1) · d_hop(Q1(g), Q2(g)) · (1 + γ · max_{e∈path(Q1,Q2)} cong(e))
  + W · (1/|E|) · Σ_{g∈E} (dep(g)+1) · d_hop(Q1(g), Q2(g)) / (idx(g)+1)
]
```

WHY_NOVEL: Existing heuristics consider gates independently. MCFCC explicitly models that multiple routing paths compete for the same edges simultaneously. The LP relaxation provides a polynomial-time lower bound on total routing cost that accounts for inter-gate interference — a fundamentally different formulation from single-commodity, per-gate distance minimization.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 7
EFFORT_SCORE: 5
AVERAGE_SCORE: 6.3
STATUS: KEPT
ELIMINATION_REASON: N/A

IDEA_NAME: Token Swapping Theoretical Lower Bound Cost (TSTLBC)
DESCRIPTION: The token swapping problem — given a graph G and a permutation π of tokens on vertices, find the minimum number of adjacent swaps to sort π — is the exact combinatorial model of quantum routing. Known theoretical lower bounds exist: LB(π, G) ≥ Σ_q d(q, π(q)) / Δ(G), where Δ(G) is the maximum degree. The cost function uses this tighter lower bound per gate cluster, derived from the graph's specific structure (e.g., diameter, independence number).
MATHEMATICAL_FORMULATION:
For the front layer, define induced permutation π_F: logical qubit q must reach physical position p(q).

```
LB_TS(G, π) = max(
    Σ_{q∈F} d_hop(current(q), target(q)) / Δ(G),      [degree bound]
    max_{S⊆V} |π(S) \ S| / |δ(S)|,                     [vertex separator bound]
    (n_inversions(π, G)) / 2                            [inversion count bound]
)
```

```
C_TSTLBC(swap) = max_decay · LB_TS(G_coupling, π_{F∪E}) · (1 + dep_factor)
```

where dep_factor = (1/|F|)·Σ_g dep(g) normalizes by dependency weight.
WHY_NOVEL: Uses the provably tight lower bounds from theoretical computer science on the token swapping problem (Miltzow et al. 2016, Cayley distance). This is fundamentally different from heuristic distance sums: it gives a lower bound on the true minimum SWAP count, making the cost function quantitatively justified rather than empirically tuned. No existing routing heuristic uses formal token-swapping lower bound theory.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 6
EFFORT_SCORE: 6
AVERAGE_SCORE: 6.7
STATUS: KEPT
ELIMINATION_REASON: N/A

## ELIMINATED IDEAS

---

IDEA_NAME: Cayley Graph Geodesic Permutation Cost (CGPC)
DESCRIPTION: Embed the set of all logical-to-physical mappings as elements of S_n (symmetric group). The coupling graph defines a generating set S for S_n (adjacent transpositions). The cost of a mapping is its geodesic distance in the Cayley graph Cay(S_n, S), i.e., the minimum number of generators (SWAPs) to reach the identity permutation from the current mapping.
MATHEMATICAL_FORMULATION: C = |min word w in S* : w·π = id|, where π is current mapping relative to gate requirements.
WHY_NOVEL: Exact algebraic formulation of routing as word length in Cayley graph of the symmetric group, capturing the true combinatorial complexity.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 4
EFFORT_SCORE: 2
AVERAGE_SCORE: 5.0
STATUS: ELIMINATED
ELIMINATION_REASON: Computing geodesic distances in Cay(S_n, S) is #P-hard in general. Even approximations require exponential preprocessing. Fundamentally intractable for n > 10. Strong theoretical novelty does not translate to practical implementation.

IDEA_NAME: Persistent Homology Gate Interaction Cost (PHGIC)
DESCRIPTION: Build a filtered simplicial complex from the gate interaction graph (one simplex per gate dependency, filtered by distance). Use persistent homology to identify topological "holes" (H_1 cycles) in the interaction graph. Gates whose qubit pairs span a topological barrier (H_1 generator) are assigned higher cost, as their routing must break a cycle.
MATHEMATICAL_FORMULATION: C = Σ_{g∈F} w_g · β_1(subcomplex spanning Q1(g),Q2(g)), where β_1 is the first Betti number of the relevant subcomplex.
WHY_NOVEL: First application of algebraic topology (TDA) to quantum routing cost estimation.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 3
EFFORT_SCORE: 3
AVERAGE_SCORE: 5.0
STATUS: ELIMINATED
ELIMINATION_REASON: Coupling graphs for quantum hardware are planar or near-planar with trivial H_1. The topological signal would be near-zero for all common hardware topologies (heavy-hex, grid). Very high implementation complexity for essentially no practical signal.

IDEA_NAME: Quantum Walk Interference Amplitude Cost (QWIAC)
DESCRIPTION: Run a discrete quantum walk on the coupling graph starting from Q1 and measure the amplitude at Q2 after T steps. High amplitude = easy routing; low amplitude (destructive interference) = hard routing. Cost = 1 - |<Q2|U^T|Q1>|^2.
MATHEMATICAL_FORMULATION: C = Σ_{g∈F} (1 - |<Q2(g)|(U_walk)^T|Q1(g)>|^2) · dep(g), where U_walk = exp(-i·A·dt).
WHY_NOVEL: Uses quantum mechanical amplitude interference to assess routing difficulty — literally using quantum computation to plan quantum routing.
NOVELTY_SCORE: 9
PROBABILITY_SCORE: 4
EFFORT_SCORE: 5
AVERAGE_SCORE: 6.0
STATUS: ELIMINATED
ELIMINATION_REASON: Quantum walk amplitudes are oscillatory and non-monotone in T — the cost function would not converge reliably. Sensitivity to T parameter makes the cost unstable. The interference pattern bears no provable relationship to SWAP count. Intriguing but fundamentally non-convergent without heavy regularization.

IDEA_NAME: Tensor Network Bond Dimension Cost (TNBDC)
DESCRIPTION: Represent the unexecuted circuit as a tensor network (MPS/MERA). Model each SWAP as a contraction of two index tensors. Prefer SWAPs that minimize the bond dimension growth of the resulting tensor network. Low bond dimension = efficient simulation = low entanglement = fewer routing complications.
MATHEMATICAL_FORMULATION: C = max_decay · Σ_{g∈F} χ(g) · d(Q1(g),Q2(g)), where χ(g) = Schmidt rank of the bipartition across gate g's qubit cut.
WHY_NOVEL: Connects entanglement structure (tensor rank) to routing cost for the first time.
NOVELTY_SCORE: 8
PROBABILITY_SCORE: 4
EFFORT_SCORE: 4
AVERAGE_SCORE: 5.3
STATUS: ELIMINATED
ELIMINATION_REASON: Schmidt rank of individual gates is constant (2 for 2-qubit gates). The bond dimension signal is uniform across all two-qubit gates, providing no discrimination between routing choices. Would require full circuit simulation to extract meaningful entanglement structure, making it computationally intractable at routing time.

---

IDEA_NAME: Entropy Production Rate Cost (EPRC)
DESCRIPTION: Model the qubit mapping as a probability distribution p over physical positions (softmax of affinity). Each SWAP induces a transition; minimize KL-divergence between the current distribution and a target distribution derived from gate interaction frequencies.
MATHEMATICAL_FORMULATION: C = KL(p_current || p_target) = Σ_q p_current(q) · log(p_current(q) / p_target(q))
WHY_NOVEL: Information-theoretic / thermodynamic framing of routing as entropy minimization.
NOVELTY_SCORE: 7
PROBABILITY_SCORE: 4
EFFORT_SCORE: 6
AVERAGE_SCORE: 5.7
STATUS: ELIMINATED
ELIMINATION_REASON: The "target distribution" must be recomputed at every step, and its definition is ill-posed for general circuits. KL divergence between point masses (hard mappings) requires softmax regularization that introduces arbitrary hyperparameters. Convergence to the correct routing solution is not guaranteed — the KL landscape may have spurious local minima unrelated to SWAP count.

**Top 3 Recommendations for Implementation:**

1. **CANGLC** — Highest score; exploits a genuinely quantum-specific property (Lie algebra commutativity) that classical routing heuristics cannot capture. Low implementation overhead via Pauli decomposition.

2. **ORCWC / SEDC** — Both precomputed once from the coupling graph. Spectral/geometric distances are drop-in replacements for `self.distance_matrix` in the baseline, making integration trivial.

3. **SDAPC** — Replaces the hard extended-layer window with a probabilistic DAG mass — directly addresses SABRE's known weakness on irregular DAG structures (deep chains, wide parallelism).
