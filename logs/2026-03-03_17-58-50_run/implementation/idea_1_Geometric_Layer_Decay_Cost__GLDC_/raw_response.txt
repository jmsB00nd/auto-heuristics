```python
def qlosure_poly_heuristic(self, swap_gate):
    W = 1
    r = 0.5  # geometric decay base, r ∈ (0, 1)

    front_layer_size = len(self.front_layer)
    extended_layer_size = len(self.extended_layer)

    max_decay = max(self.decay_parameter[swap_gate[0]], self.decay_parameter[swap_gate[1]])

    f_distance = 0
    for g in self.front_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        deps = self.dag_dependencies_count[g]
        f_distance += (deps + 1) * self.distance_matrix[Q1][Q2]

    e_distance = 0
    for g in self.extended_layer:
        q1, q2 = self.access2q[g]
        Q1, Q2 = self.temp_mapping_dict[q1], self.temp_mapping_dict[q2]
        layer_index = self.extended_layer_index.get(g, 0)  # 0-based depth

        deps = self.dag_dependencies_count[g]
        e_distance += (deps + 1) * self.distance_matrix[Q1][Q2] * (r ** layer_index)

    H = max_decay * (f_distance / front_layer_size + W *
                     ((e_distance / extended_layer_size) if extended_layer_size else 0))

    return H
```

**Key difference from baseline:**

| | Baseline (Harmonic) | GLDC (Geometric) |
|---|---|---|
| Series | 1, 1/2, 1/3, 1/4, ... | 1, 0.5, 0.25, 0.125, ... |
| Decay rate | Sublinear (slow) | Exponential (fast) |
| Tail behavior | Long tail, distant gates still weighted | Near-zero weight for deep lookahead |

The substitution is `1/(layer_index + 1)` → `r^layer_index`. At `layer_index=0` both give weight 1 (consistent front-layer handling), but geometric decay drops to ~0 far faster — a gate at depth 6 gets weight `0.5^6 ≈ 0.016` vs `1/7 ≈ 0.14` harmonically. This prevents distant speculative gates from over-influencing the swap decision.
