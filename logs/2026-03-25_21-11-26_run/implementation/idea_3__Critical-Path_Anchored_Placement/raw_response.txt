    for g in sorted_gates:
        q1, q2 = two_q_gates[g]

        qubit_gate_order[q2].append(g)

    predecessors = defaultdict(set)
    all_2q_gate_set = set(two_q_gates.keys())

    for q, gates in qubit_gate_order.items():
        for i in range(len(gates) - 1):
            if gates[i + 1] not in successors[gates[i]]:
                successors[gates[i]].add(gates[i + 1])
                predecessors[gates[i + 1]].add(gates[i])

    in_degree = {g: len(predecessors[g]) for g in all_2q_gate_set}
    topo_queue = deque([g for g in all_2q_gate_set if in_degree[g] == 0])
    longest_dist = {g: 0 for g in all_2q_gate_set}
    back_pointer = {g: -1 for g in all_2q_gate_set}

        g = topo_queue.popleft()
        for s in successors[g]:
            if longest_dist[g] + 1 > longest_dist[s]:
                longest_dist[s] = longest_dist[g] + 1
                back_pointer[s] = g
            in_degree[s] -= 1
            if in_degree[s] == 0:
                topo_queue.append(s)

    critical_path_gates = []

        for q in (q1, q2):

                seen_q.add(q)

                    found = True

                    chain.append(nb)

        interaction_weight[q1][q2] += 1
        interaction_weight[q2][q1] += 1

    unplaced = [q for q in used_logical if self.mapping_dict[q] == -1]

    remaining_logical = [q for q in range(num_q) if self.mapping_dict[q] == -1]
    remaining_physical = sorted(available_physical)
    for lq, pq in zip(remaining_logical, remaining_physical):

        self.reverse_mapping_dict[pq] = lq

    if self.use_isl:

## Algorithm Summary

1. **Build 2Q DAG** (O(G)): Creates a dependency graph over 2-qubit gates by tracking per-qubit gate ordering from `self.access`.

2. **Find critical path** (O(G)): Topological sort + longest-path DP with backtracking to recover the full gate sequence.

3. **Extract critical qubits**: Ordered sequence of logical qubits appearing along the critical path (first-occurrence order).

4. **Find hardware path** (bounded DFS): Searches for a simple path of matching length in the coupling graph, with a 50K iteration cap per start node to guarantee termination. Falls back to a greedy chain if no exact path is found.

5. **Anchor placement**: Maps critical-path logical qubits 1-to-1 onto the physical path nodes.

6. **Greedy fill**: Remaining qubits are sorted by interaction weight with already-placed qubits, then each is assigned to the closest available physical qubit to its heaviest placed partner.

7. **Backfill**: Any unused logical qubits get assigned to remaining physical qubits, guaranteeing a complete 1-to-1 mapping.

**Validity guarantee**: The `occupied_physical` set and `available_physical` set shrink monotonically, ensuring no two logical qubits share a physical qubit. The final backfill ensures every logical qubit in `[0, num_q)` has a mapping.
