**IDEA_NAME:** Diffusion-Gradient Placement

**DESCRIPTION:** Model logical qubits as particles on the hardware graph that diffuse according to interaction strength. Start all qubits at the graph centroid, then iteratively "push" them apart along shortest-path gradients weighted by gate interaction frequency. High-interaction pairs resist separation (low diffusion coefficient), while low-interaction pairs diffuse freely. The process converges when particles settle on distinct physical qubits.

**ALGORITHMIC_APPROACH:**
1. Build interaction graph `W[i][j]` = number of 2-qubit gates between logical qubits i,j
2. Compute hardware graph centroid (min sum-of-distances node)
3. Initialize all logical qubits at centroid position (continuous coordinates via spectral embedding of hardware)
4. Iteratively: for each pair, apply repulsive force inversely proportional to `W[i][j]` and attractive force proportional to `W[i][j]`
5. After convergence, snap each logical qubit to nearest unoccupied physical qubit via greedy nearest-neighbor assignment
6. Build `mapping_dict` and `reverse_mapping_dict` from the assignment

**COLLISION_PREVENTION:** The final snap step uses a greedy assignment: sort logical qubits by distance to their target physical qubit, assign closest first, mark physical qubit as occupied. Guarantees 1-to-1 by construction. Unassigned logical qubits get remaining physical qubits.

**WHY_NOVEL:** Unlike spectral methods that align eigenvectors, this uses a physics-based force simulation on the actual hardware topology. The diffusion model respects the discrete graph structure while allowing continuous optimization before discretization.
