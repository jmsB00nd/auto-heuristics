The implementation follows the MLA-RB algorithm exactly:

1. **Weighted interaction graph** - Built from circuit gates with layer-decay weighting (earlier gates weighted more heavily)
2. **Fiedler vector computation** - Computes the 2nd-smallest eigenvector of the Laplacian for both logical and hardware graphs
3. **Ordering by Fiedler values** - Sorts qubits by their Fiedler vector components to get MLA-approximate orderings
4. **Recursive bisection alignment** - Splits both orderings at the median, tries both orientation assignments at each level, and recurses on halves
5. **Boundary refinement** - Full local search with pairwise swap improvements using efficient delta computation

Additional robustness:
- Tries multiple seeds: recursive bisection, direct Fiedler ordering, reversed ordering (sign ambiguity), and different hardware subsets
- Handles `n_lq < n_pq` by selecting center/edge subsets from the hardware ordering
- Guarantees valid bijective mapping via `make_mapping` which fills unassigned qubits
